# 大气散射系统 (Atmospheric Scattering System)

## 1. 概述

DerivativeMain 的大气散射系统基于 Eric Bruneton 的预计算大气散射模型（Precomputed Atmospheric Scattering），这是目前实时渲染领域最精确的大气光学模型之一。整个系统由以下核心组件构成：

- **预计算大气散射**（`lib/Atmosphere/Atmosphere.glsl`）——核心散射计算引擎
- **体积雾/体积光**（`lib/Atmosphere/VolumetricFog.glsl`）——基于步进的体积雾效
- **极光**（`lib/Atmosphere/Aurora.glsl`）——程序化极光效果
- **雾效系统**（`lib/Atmosphere/Fogs.glsl`）——通用雾效
- **预计算 LUT**（`texture/Atmosphere/`）——存储散射数据的查找表

## 2. 物理散射模型

### 2.1 大气参数

系统使用真实的地球大气物理参数，在 `AtmosphereParameters` 结构体中定义：

| 参数 | 值 | 说明 |
|------|-----|------|
| `solar_irradiance` | `(1.474, 1.850, 1.912)` | 太阳辐照度 (W/m^2/nm) |
| `rayleigh_scattering` | `(0.005802, 0.013558, 0.033100)` | Rayleigh 散射系数（蓝光散射最强） |
| `mie_scattering` | `(0.003996, 0.003996, 0.003996)` | Mie 散射系数（波长无关） |
| `ground_albedo` | `0.1` | 地面平均反照率 |
| `sun_angular_radius` | `0.012` | 太阳角半径（非物理值，用于增强视觉效果） |
| `mie_phase_g` | `0.77` | Mie 散射不对称参数 |

大气层几何结构：
- **行星半径**: `6371 km`（地球）
- **大气底层高度**: `ATMOSPHERE_BOTTOM_ALTITUDE`（可配置，默认 1000m）
- **大气顶层高度**: `ATMOSPHERE_TOP_ALTITUDE`（可配置，默认 100km）
- **最小太阳天顶角余弦**: `mu_s_min = -0.2`（对应约 102 度）

### 2.2 相函数

系统实现了三种散射相函数：

**Rayleigh 相函数**（分子散射）：
```glsl
float RayleighPhase(in float cosTheta) {
    const float c = 3.0 / 16.0 * rPI;
    return cosTheta * cosTheta * c + c;
}
```
这是简化的 Rayleigh 相函数，散射关于前向/后向对称。

**Henyey-Greenstein 相函数**（Mie 散射）：
```glsl
float HenyeyGreensteinPhase(in float cosTheta, in const float g) {
    float phase = 1.0 + g*g - 2.0*g*cosTheta;
    return (1.0 - g*g) / (4.0 * PI * phase * sqrt(phase));
}
```
用于 Mie 散射的前向峰值建模，`g=0.77` 时产生显著的前向散射。

**Cornette-Shanks 相函数**：
```glsl
float CornetteShanksPhase(in float cosTheta, in const float g) {
    float a = (1.0 - g*g) / (2.0 + g*g) * 3.0 * rPI;
    float b = (1.0 + cosTheta^2) * pow(1.0 + g*g - 2.0*g*cosTheta, -1.5);
    return a * b * 0.125;
}
```
比 Henyey-Greenstein 更物理精确的 Mie 相函数，主要用于云渲染中的前向峰值。

### 2.3 夜间视觉适应（暗视觉）

```glsl
vec3 DoNightEye(in vec3 color) {
    float luminance = GetLuminance(color);
    float rodFactor = exp2(-luminance * 6e2);
    return mix(color, luminance * vec3(0.72, 0.95, 1.2), rodFactor);
}
```
模拟人眼从明视觉（锥状细胞）到暗视觉（杆状细胞）的转换。在极低亮度下，色彩感知偏移至蓝绿色调 `(0.72, 0.95, 1.2)`，即 Purkinje 效应。

## 3. 预计算 LUT 系统

### 3.1 LUT 文件结构

系统使用四个预计算 LUT 文件，存储于 `texture/Atmosphere/` 目录：

| LUT 文件 | 尺寸 | 用途 |
|----------|------|------|
| `Transmittance.lut` | 256x64 | 透射率查找表 |
| `Scattering.lut` | 32x128x32x8 | 散射数据（4D 纹理） |
| `Irradiance.lut` | 64x16 | 天空辐照度 |
| `Final.lut` | — | 合成后的最终散射 LUT |

这些 LUT 存储在 `colortex4`（一个 `sampler3D` 纹理）中，格式为 `R11F_G11F_B10F`。

### 3.2 纹理坐标映射

LUT 使用精心设计的非线性坐标映射来最大化精度分布。关键映射函数：

```glsl
float GetTextureCoordFromUnitRange(float x, float texture_size) {
    return 0.5 / texture_size + x * (1.0 - 1.0 / texture_size);
}
```
此函数将 `[0,1]` 范围映射到纹理像素中心，避免边界采样问题。

### 3.3 透射率 LUT (Transmittance)

维度：`(r, mu)` -> 256x64 纹理

- `r`: 到地心的距离
- `mu`: 视线方向与天顶方向的余弦

映射策略：
- `u` 轴：基于到大气层顶边界的距离 `d`，在 `d_min`（正上方）和 `d_max`（地平线方向）之间线性映射
- `v` 轴：基于地平线距离 `rho / H`

```glsl
vec2 GetTransmittanceTextureUvFromRMu(float r, float mu) {
    float H = sqrt(atmosphere_top_radius_sq - atmosphere_bottom_radius_sq);
    float rho = SafeSqrt(r*r - atmosphere_bottom_radius_sq);
    float d = DistanceToTopAtmosphereBoundary(r, mu);
    float d_min = atmosphere_top_radius - r;
    float d_max = rho + H;
    return vec2(
        GetTextureCoordFromUnitRange((d - d_min) / (d_max - d_min), 256.0),
        GetTextureCoordFromUnitRange(rho / H, 64.0)
    );
}
```

透射率查找存储在 `colortex4` 的上半部分 `uv * vec2(1.0, 0.5)`，层索引 `32.5/33.0`。

### 3.4 散射 LUT (Scattering)

维度：`(r, mu, mu_s, nu)` -> 32x128x32x8 纹理

- `r`: 到地心的距离（32 步）
- `mu`: 视线天顶角余弦（128 步，上下半球各 64 步）
- `mu_s`: 太阳天顶角余弦（32 步）
- `nu`: 视线与太阳方向夹角余弦（8 步）

这是最复杂的 4D LUT。`nu` 维度通过在两个相邻 `nu` 切片之间线性插值来实现：

```glsl
float tex_coord_x = uvwz.x * (SCATTERING_TEXTURE_NU_SIZE - 1.0);
float tex_x = floor(tex_coord_x);
float lerp = tex_coord_x - tex_x;
vec3 uvw0 = vec3((tex_x + uvwz.y) / SCATTERING_TEXTURE_NU_SIZE, uvwz.z, uvwz.w);
vec3 uvw1 = vec3((tex_x + 1.0 + uvwz.y) / SCATTERING_TEXTURE_NU_SIZE, uvwz.z, uvwz.w);
vec4 combined_scattering = texture(colortex4, uvw0) * (1.0 - lerp) + texture(colortex4, uvw1) * lerp;
```

散射 LUT 使用联合存储策略：Rayleigh 散射存储在 RGB 通道，单次 Mie 散射编码在 Alpha 通道中。通过 `GetExtrapolatedSingleMieScattering` 函数从联合数据中提取 Mie 分量：

```glsl
vec3 GetExtrapolatedSingleMieScattering(AtmosphereParameters atmosphere, vec4 scattering) {
    if (scattering.r <= 0.0) return vec3(0.0);
    return scattering.rgb * scattering.a / scattering.r *
        (atmosphere.rayleigh_scattering.r / atmosphere.mie_scattering.r) *
        (atmosphere.mie_scattering / atmosphere.rayleigh_scattering);
}
```

### 3.5 辐照度 LUT (Irradiance)

维度：`(r, mu_s)` -> 64x16 纹理

存储在 `colortex4` 的下半部分，偏移 `vec2(0.0, 0.5)`，缩放 `vec2(0.25, 0.125)`。

## 4. 天空辐射度计算

### 4.1 天空辐射度（Sky Radiance）

`GetSkyRadiance` 函数计算给定视线方向的天空颜色：

1. **相机位置**：`(0, planetRadius + eyeAltitude, 0)`
2. **边界检测**：如果相机在大气层外，先将视线起点移至大气层顶
3. **参数计算**：
   - `mu = dot(camera, view_ray) / r`（视线天顶角余弦）
   - `mu_s = dot(camera, sun_direction) / r`（太阳天顶角余弦）
   - `nu = dot(view_ray, sun_direction)`（视线与太阳夹角余弦）
4. **地面相交检测**：`RayIntersectsGround(r, mu)`
5. **散射查询**：分别查询太阳和月球的散射贡献
6. **相函数应用**：
   - Rayleigh: `sun_scattering * RayleighPhase(nu) + moon_scattering * RayleighPhase(-nu) * MoonFlux`
   - Mie: `sun_single_mie_scattering * HenyeyGreensteinPhase(nu, 0.77) + ...`
7. **天气混合**：雨天时 Rayleigh 散射趋向灰色（去饱和），整体亮度乘以 `1 - wetness * 0.6`

### 4.2 月球光通量

```glsl
vec3 MoonFlux = vec3(abs(moonPhase - 4.0) * 0.25 + 0.2) * (NIGHT_BRIGHTNESS + nightVision * 0.02);
```
月球亮度取决于月相（`moonPhase`，0-7），满月（phase 4）最亮。`NIGHT_BRIGHTNESS`（默认 0.0005）控制夜间整体亮度。

### 4.3 到点散射（Aerial Perspective）

`GetSkyRadianceToPoint` 计算从相机到场景中某点之间的散射（空中透视）：

1. 查询相机位置和目标点位置的散射
2. 两者相减得到路径上的散射贡献
3. 同时输出路径透射率 `transmittance`
4. 日出/日落时的 Mie 散射 hack：`sun_single_mie_scattering *= smoothstep(0.0, 0.01, mu_s)`

### 4.4 太阳和天空辐照度

`GetSunAndSkyIrradiance` 计算场景中某点接收到的总光照：

```glsl
vec3 GetSunAndSkyIrradiance(atmosphere, point, sun_direction, out sun_irradiance, out moon_irradiance) {
    float r = length(point);
    float mu_s = dot(point, sun_direction) / r;
    sun_irradiance = atmosphere.solar_irradiance * GetTransmittanceToSun(r, mu_s);
    moon_irradiance = atmosphere.solar_irradiance * DoNightEye(GetTransmittanceToSun(r, -mu_s) * MoonFlux);
    vec3 sky_irradiance = GetIrradiance(r, mu_s) + GetIrradiance(r, -mu_s) * MoonFlux;
    sky_irradiance *= 1.0 + point.y / r;  // 高度修正
    return sky_irradiance;
}
```

### 4.5 太阳透射率（带日轮遮挡）

```glsl
vec3 GetTransmittanceToSun(float r, float mu_s) {
    float sin_theta_h = atmosphere_bottom_radius / r;
    float cos_theta_h = -sqrt(max0(1.0 - sin_theta_h^2));
    return GetTransmittanceToTopAtmosphereBoundary(r, mu_s) *
        smoothstep(-sin_theta_h * sun_angular_radius,
                    sin_theta_h * sun_angular_radius,
                    mu_s - cos_theta_h);
}
```
当太阳接近地平线时，通过 `smoothstep` 模拟大气折射造成的日轮逐渐消隐。

## 5. 天体渲染

### 5.1 太阳盘面

`RenderSun` 使用基于物理的太阳盘面模型：

```glsl
vec3 RenderSun(vec3 worldDir, vec3 sunVector) {
    const vec3 sunIlluminance = vec3(1.474, 1.850, 1.912) * 126.6e3;
    float cosTheta = dot(worldDir, sunVector);
    float centerToEdge = saturate(fastAcos(cosTheta) / sun_angular_radius);
    const vec3 alpha = vec3(0.429, 0.522, 0.614);  // AP1 primaries
    vec3 factor = pow(vec3(1.0 - centerToEdge^2), alpha * 0.5);
    vec3 finalLuminance = sunIlluminance / coneAngleToSolidAngle(sun_angular_radius) * factor;
    return min(finalLuminance, 1e4);
}
```

关键特征：
- 使用 ACES AP1 原色的 `alpha` 参数实现径向亮度渐变
- 太阳角半径 `0.012` 弧度（约为物理值的 2.6 倍），使太阳在画面中更大更明显
- 亮度上限 `1e4` 防止 HDR 溢出
- 独立的 `RenderSunReflection` 使用更大的角半径 `0.05` 用于水面反射

### 5.2 月球盘面

```glsl
vec3 RenderMoonReflection(vec3 worldDir, vec3 sunVector) {
    float cosTheta = dot(worldDir, -sunVector);
    float size = 5e-3;
    float hardness = 2e2;
    float disc = sqr(curve(saturate((cosTheta - 1.0 + size) * hardness)));
    return vec3(disc) * 4.0;
}
```
使用简单的圆形遮罩而非物理模型。`curve` 函数（smoothstep 等价）提供柔和边缘。

### 5.3 星空

`RenderStars` 实现程序化星空：

1. **坐标旋转**：将星图固定到太阳参考系，使星星随夜晚旋转
2. **网格哈希**：`256x256` 网格上的伪随机分布
3. **覆盖控制**：`STARS_COVERAGE`（默认 0.15）
4. **色温**：每颗星有随机色温 `4000K - 8000K`，通过 `Blackbody()` 函数转换为 RGB
5. **亮度**：`STARS_INTENSITY`（默认 0.1）

```glsl
float cov = remap(1.0 - coverage, 1.0, hash.x);
return maxLuminance * remap(0.25, 0.0, r) * cov * cov * Blackbody(mix(4000.0, 8000.0, hash.y));
```

## 6. 天空穹顶映射

### 6.1 天空捕获分辨率

```glsl
const ivec2 skyCaptureRes = ivec2(255, 256);
```
天空使用 `255x256` 的 equirectangular 映射。

### 6.2 投影/反投影

```glsl
vec2 ProjectSky(vec3 direction) {
    vec2 coord = vec2(
        atan(-direction.x, -direction.z) * rTAU + 0.5,
        fastAcos(direction.y) * rPI
    );
    coord.x = coord.x * (1.0 - 4.0/skyCaptureRes.x) + 2.0/skyCaptureRes.x;
    return saturate(coord * skyCaptureRes * screenPixelSize);
}

vec3 UnprojectSky(vec2 coord) {
    coord.x *= 256.0 / 255.0;
    coord.x = fract((coord.x - 2.0/skyCaptureRes.x) / (1.0 - 4.0/skyCaptureRes.x));
    coord *= vec2(TAU, PI);
    return vec3(sincos(coord.x) * sin(coord.y), cos(coord.y)).xzy;
}
```

`fastAcos` 是一个高性能的反余弦近似：
```glsl
float fastAcos(float x) {
    float a = abs(x);
    float r = 1.570796 - 0.175394 * a;
    r *= sqrt(1.0 - a);
    return x < 0.0 ? PI - r : r;
}
```

## 7. 极光实现

极光系统（`lib/Atmosphere/Aurora.glsl`）基于 nimitz 2017 的实现，使用体积光线步进与程序化噪声。

### 7.1 噪声函数

核心噪声是 `triNoise2d`，基于三角波的 FBM（分形布朗运动）：

```glsl
float triNoise2d(vec2 p, float spd) {
    // 5 次迭代的三角波噪声叠加
    // 每次迭代: 旋转坐标系、叠加三角波、缩放振幅
    // 使用 worldTimeCounter 实现动画
    for (uint i = 0u; i < 5u; ++i) {
        vec2 dg = tri2(bp * 1.85) * 0.75;
        dg *= mm2(worldTimeCounter * spd);
        p -= dg / z2;
        bp *= 1.3; z2 *= 0.45; z *= 0.42;
        p *= 1.21 + (rz - 1.0) * 0.02;
        p *= -m2;
        rz += tri(p.x + tri(p.y)) * z;
    }
    return clamp(pow(rz * 29.0, -1.3), 0.0, 0.55);
}
```

### 7.2 极光体渲染

```glsl
vec4 aurora(vec3 ro, vec3 rd) {
    vec4 col = vec4(0.0);
    vec4 avgCol = vec4(0.0);
    for (float i = 0.0; i < 40.0; i++) {
        float of = 0.006 * hash21(gl_FragCoord.xy) * smoothstep(0.0, 15.0, i);
        float pt = ((0.8 + pow(i, 1.4) * 0.002) - ro.y) / (rd.y * 2.0 + 0.4);
        pt -= of;
        vec3 bpos = ro + pt * rd;
        float rzt = triNoise2d(bpos.zx, 0.1883);
        vec4 col2 = vec4(0.0, 0.0, 0.0, rzt);
        col2.rgb = (sin(1.0 - vec3(2.15, -0.5, 1.2) + i * 0.043) * 0.5 + 0.5) * rzt;
        avgCol = mix(avgCol, col2, 0.5);
        col += avgCol * exp2(-i * 0.065 - 2.5) * smoothstep(0.0, 5.0, i);
    }
    col *= saturate(rd.y * 15.0 + 0.4);
    return col * 1.8;
}
```

关键技术点：
- **多项式步长**：`pow(i, 1.4) * 0.002` 使步长随距离增大，远处采样更稀疏
- **抖动**：基于哈希的随机偏移 `of` 减少条带感
- **颜色渐变**：`sin(1.0 - vec3(2.15, -0.5, 1.2) + i * 0.043)` 产生从绿色到紫色的渐变
- **累积混合**：`avgCol = mix(avgCol, col2, 0.5)` 平滑相邻样本
- **指数衰减**：`exp2(-i * 0.065 - 2.5)` 远处亮度快速衰减

### 7.3 极光集成

```glsl
vec3 NightAurora(vec3 worldDir) {
    if (worldDir.y < 0.0 && eyeAltitude < 2e4) return vec3(0.0);
    vec3 planeOrigin = vec3(0.0, planetRadius + eyeAltitude, 0.0);
    vec2 intersection = RaySphereIntersection(planeOrigin, worldDir, planetRadius + 2e4);
    float raylength = intersection.y;
    if (raylength <= 0.0 || raylength > 5e5) return vec3(0.0);
    vec3 rd = worldDir * raylength;
    float fade = fastExp(-raylength * 1e-5);
    vec4 aur = smoothstep(0.0, 2.5, aurora(vec3(0.0, 0.0, -6.7), rd * 1e-5));
    return aur.rgb * fade * auroraAmount;
}
```

极光位于 `planetRadius + 20km` 高度，仅在夜晚可见：
```glsl
float auroraAmount = smoothstep(0.0, 0.2, -worldSunVector.y) * AURORA_STRENGTH;
```

## 8. 雾效系统

### 8.1 通用雾效（Fogs.glsl）

**致盲/黑暗雾**：
```glsl
if (blindness + darknessFactor > 0.0)
    color *= fastExp(-dist * max(blindness, darknessFactor));
```

**岩浆中雾效**（`isEyeInWater == 2`）：
```glsl
color = mix(color, vec3(3.96, 0.68, 0.02), saturate(dist));
```

**密闭空间雾效**（`isEyeInWater == 3`）：
使用天空辐照度和直接辐照度混合，乘以天空光照修正因子。

### 8.2 下界雾效

下界使用生物群系加权的自定义雾色：
```glsl
vec3 NetherFogColor() {
    return vec3(0.99, 0.23, 0.03)  * BiomeNetherWastesSmooth
         + vec3(0.04, 0.24, 0.2)   * BiomeWarpedForestSmooth
         + vec3(0.3, 0.03, 0.01)   * BiomeCrimsonForestSmooth
```

### 8.3 体积雾（VolumetricFog.glsl）

体积雾是系统中最复杂的雾效，使用屏幕空间光线步进。

**雾密度计算**有 4 种模式（`FOG_TYPE` 0-3）：

| 类型 | 特征 |
|------|------|
| 0 (Low) | 简单指数高度衰减 |
| 1 (Medium) | 基于 3D 噪声的高度衰减，中午时密度最低 |
| 2 (High) | 多层 FBM 噪声（3 级叠加），产生丰富的体积细节 |
| 3 (Ultra) | 5 级 FBM 噪声，最高质量 |

以 Medium 模式为例：
```glsl
float CalculateFogDensity(vec3 rayPosition) {
    float fogDensity = exp2(min((SEA_LEVEL + 28.0 - rayPosition.y) * 0.15, 0.2));
    rayPosition *= 0.07;
    rayPosition += volFogWind;
    float noise = Get3DNoiseSmooth(rayPosition) * 4.0;
    noise -= Get3DNoiseSmooth(rayPosition * 4.0 + volFogWind);
    fogDensity = saturate(noise * 4.0 * fogDensity - 5.0) * 1.4;
    if (BiomeSandstorm < 5e-3) fogDensity = fogDensity * (1.0 - timeNoon) + timeNoon;
    return fogDensity;
}
```

**体积光**叠加在体积雾之上：
```glsl
float airDensity = VOLUMETRIC_LIGHT_STRENGTH + wetness * BiomeSandstorm;
airDensity *= RayleighPhase(LdotV) * (3.0 / far);
```

**步进循环**核心逻辑：
```glsl
while (++i < steps) {
    // 阴影采样
    vec3 shadow = step(shadowProjPos.z, texelFetch(shadowtex1, shadowTexel, 0).x);

    // 雾密度计算
    float fogDensity = airDensity + CalculateFogDensity(rayPosition) * mistDensity;

    // 高质量模式下的多重散射（4 次步进）
    for (uint j = 0u; j < 4u; ++j, checkPos += worldLightVector * stepSize) {
        sunlightOD += CalculateFogDensity(checkPos) * stepSize;
        stepSize *= 1.5;
    }

    // Powder Effect（粉末效应）
    float powder = (1.0 - exp(-density * 36.0)) * 0.82;
    powder /= 1.0 - powder;

    // Beer-Powder 散射能量
    float sunlightEnergy = exp(-sunlightOD * 2.0) * phases.x
                         + exp(-sunlightOD * 0.8) * phases.y
                         + exp(-sunlightOD * 0.3) * phases.z
                         + exp(-sunlightOD * 0.1) * phases.w;

    transmittance *= exp(-fogDensity);
}
```

**水下体积光**使用独立实现，基于水体吸收系数和折射光方向。

### 8.4 陆地大气散射（LAND_ATMOSPHERIC_SCATTERING）

当体积雾/体积光禁用时，使用简化的单次散射大气模型（来自 Spectrum shader）：

```glsl
const vec3 rayleighColor = vec3(6.43e+24, 1.09e+25, 2.49e+25);
const float rayleighK = 9.99e-31;
const vec3 atmosphere_coefficientRayleigh = rayleighK * rayleighColor;
const vec3 atmosphere_coefficientMie = vec3(4e-6);
const vec3 atmosphere_coefficientOzone = ozoneCrossSection * ozoneNumberDensity;

vec3 opticalDepth = baseAttenuationCoefficient * dist;
vec3 transmittance = exp(-opticalDepth);
vec3 scattering = atmosphere_coefficientsScattering
    * vec2(RayleighPhase(LdotV), HenyeyGreensteinPhase(LdotV, mie_phase_g))
    * directIlluminance;
```

这包含了 Rayleigh、Mie 和臭氧三种散射/吸收。

### 8.5 边界雾（Border Fog）

```glsl
float density = 1.0 - exp2(-sqr(pow4(length(worldPos.xz) * eyeSkylightFix / far)) * BORDER_FOG_FALLOFF);
density *= oneMinus(saturate(worldDir.y * 3.0));
vec3 skyRadiance = textureBicubic(colortex5, ProjectSky(worldDir)).rgb;
sceneData = mix(sceneData, skyRadiance, density);
```
边界雾在渲染距离边缘将场景渐变为天空颜色，向上的视线方向雾效减弱。

## 9. 延迟渲染管线集成

### 9.1 管线概览

大气散射通过多 Pass 延迟渲染管线集成：

```
deferred (vsh) ──> 计算 directIlluminance, skyIlluminance, sunIlluminance, moonIlluminance
                    通过 GetSunAndSkyIrradiance() 从预计算 LUT 查询

deferred0 (fsh) ──> 渲染天空穹顶到 colortex5
                    - 原始天空图：GetSkyRadiance() * 20.0
                    - 带云天空图：RenderSkybox()
                    - 太阳/月球叠加
                    - 辐照度数据存储在特定像素位置

deferred1 (fsh) ──> 渲染云层（带时间超采样）
                    - 体积云 + 平面云
                    - 极光叠加
                    - 大气透视混合

deferred2 (fsh) ──> 时间累积（天空 + 光照）
                    - 棋盘格渲染降采样
                    - Catmull-Rom 重投影滤波
                    - 历史帧混合（最大 40-256 帧）

deferred5 (vsh) ──> SH 球谐光照计算
                    - 25 个方向采样天空穹顶
                    - 生成 skySHR, skySHG, skySHB

composite1 (fsh) ──> 最终合成
                    - 折射
                    - 反射
                    - 大气散射（LAND_ATMOSPHERIC_SCATTERING 或简化雾）
                    - 体积雾合成
                    - 通用雾效
```

### 9.2 光照数据存储

光照度数据存储在 `colortex5` 的特殊像素位置（`skyCaptureRes.x` 列）：

| 行索引 | 数据 |
|--------|------|
| 0 | `directIlluminance`（直接光照 = 太阳 + 月球） |
| 1 | `skyIlluminance`（天空辐照度） |
| 2 | `sunIlluminance`（太阳辐照度） |
| 3 | `moonIlluminance`（月球辐照度） |
| 5 | `cloudDynamicWeather`（云动态天气） |

### 9.3 时间超采样

天空渲染使用时间超采样（`TEMPORAL_UPSCALING`，2-4 倍）：

- 云层以降采样分辨率渲染
- 使用棋盘格模式（`checkerboardOffset`）分配每帧渲染的像素
- 历史帧通过 Catmull-Rom 滤波重采样
- 混合权重基于：
  - 历史帧计数（`MAX_BLENDED_FRAMES`，默认 40）
  - 相机移动距离
  - 像素速度（边缘衰减）

### 9.4 球谐光照

天空辐照度通过球谐函数（SH）编码为漫反射环境光：

```glsl
vec4 ToSH(float value, vec3 dir) {
    const vec2 foo = vec2(0.5 * PI * sqrt(rPI), 0.3849 * PI * sqrt(0.75 * rPI));
    return vec4(foo.x, foo.y * dir.yzx) * value;
}
```

在 25 个方向（5x5 网格）上采样天空穹顶，计算 L0 和 L1 阶球谐系数。

## 10. 独特技术与设计决策

### 10.1 非物理太阳角半径

太阳角半径设置为 `0.012` 弧度，约为真实值（0.004675）的 2.6 倍。注释中标注 "Unphysical"，这是一个有意的美学选择，使太阳在天空中更加显著。

### 10.2 散射缩放因子

天空辐射度乘以 `20.0`：
```glsl
vec3 skyRadiance = GetSkyRadiance(atmosphereModel, worldDir, worldSunVector, transmittance) * 20.0;
```
这是一个全局缩放因子，将预计算散射的物理单位转换为渲染管线的工作范围。

### 10.3 月球双重散射

月球使用 `-mu_s` 和 `-nu` 参数查询散射，这意味着月球被视为太阳的"镜像"散射源。月球光通量通过 `MoonFlux` 加权，其亮度远低于太阳（由 `NIGHT_BRIGHTNESS` 控制）。

### 10.4 Powder Effect

云和雾渲染中使用 Powder Effect 模拟光线在散射介质中的前向增强：

```glsl
float powder = (1.0 - fastExp(-density * 36.0)) * 0.82;
powder /= 1.0 - powder;
```

这是一种 Beer 定律的修正，当光学深度较大时，单次散射能量趋向饱和，模拟多次散射的宏观效果。

### 10.5 多 Lobbe 云相函数

云渲染使用 4 个不同参数的 Henyey-Greenstein + Cornette-Shanks 混合相函数，每个 lobe 对应不同的光学深度衰减（`2.0, 0.8, 0.3, 0.1`），模拟真实云层中的多次散射能量分布。

### 10.6 球形行星曲率

体积云渲染考虑了行星曲率：
```glsl
void GetPlanetCurvePosition(inout vec3 p) {
    p.y = length(p + vec3(0.0, planetRadius, 0.0)) - planetRadius;
}
```
这使得远处的云层看起来"低于"地平线，增强了空间感。

### 10.7 雨天去饱和

雨天时 Rayleigh 散射被部分去饱和为灰白色调：
```glsl
rayleigh = mix(rayleigh, GetLuminance(rayleigh) * vec3(1.026, 0.988, 1.016), wetness * 0.7);
```
同时整体天空亮度降低 `(1 - wetness * 0.6)`，模拟阴天效果。

### 10.8 空间上采样

体积雾使用半分辨率渲染后，通过深度感知的空间上采样恢复全分辨率：
```glsl
vec4 SpatialUpscale(sampler2D tex, vec2 coord, float linearDepth) {
    // 4 个邻居采样，基于深度差异加权
    float sigmaZ = 64.0 / linearDepth;
    float weight = exp2(-abs(sampleDepth - linearDepth) * sigmaZ);
}
```
使用 `frameCounter % 2` 交替采样偏移，进一步减少带宽。

## 12. 总结

DerivativeMain 的大气散射系统是一个多层次、高精度的实现：

1. **核心层**：Eric Bruneton 的预计算大气散射，通过 3D 纹理 LUT 存储，提供物理精确的 Rayleigh + Mie 散射
2. **天体层**：太阳、月球、星空的程序化渲染，月球光通量与月相关联
3. **特效层**：极光（基于三角波噪声的体积渲染）、多种雾效（体积雾/体积光/边界雾/简化大气散射）
4. **管线层**：延迟渲染多 Pass 架构，时间超采样、棋盘格渲染、SH 环境光编码

系统在物理精确性和视觉效果之间取得了良好的平衡，通过非物理参数调整（如太阳角半径、散射缩放因子）增强了画面表现力，同时保持了底层物理模型的正确性。
