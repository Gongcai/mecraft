## 一、总体概述

Mecraft 是一个使用 C++17 编写的 Minecraft 风格体素引擎。世界生成与地形系统负责从世界种子确定性生成无限地形，并管理区块的流式加载、存储、光照、流体等全部生命周期。

系统的核心特征：

- **确定性过程化生成**：所有地形特征（高度、生物群系、洞穴、矿石、树木、植被）完全由种子与坐标推导，无需存储生物群系图，运行时实时计算。任意世界坐标的方块可通过 `sampleBlock()` 直接采样，即使所在区块尚未加载。
- **自研噪声系统 + SIMD 优化**：未使用第三方噪声库（`third_party/FastNoise/FastNoiseLite.h` 虽存在但未接入核心管线），自研 Value Noise + FBM，并实现 SSE2（2 路并行）与 AVX2（4 路并行）批量加速。
- **分层异步管线**：区块生成在工作线程执行，主线程以时间预算逐步 finalize；光照计算独立异步并带背压机制；存档异步序列化 + 异步文件写入。
- **懒加载 + 语义类型**：SubChunk 初始为 `nullptr`（零内存），首次写入才创建；`SubChunkType`（Air/Solid/Normal）实现零成本跳过。
- **调色板 + 位压缩存储**：`Palette` + `BitPackedArray` 组合实现方块 ID 的紧凑存储，磁盘上用 `NamespacedId` 字符串保证跨版本兼容。

### 3.3 噪声系统

Mecraft **没有使用** FastNoiseLite 第三方库（该库文件存在于 `third_party/` 但未被核心管线包含），而是实现了**自研的 Value Noise + FBM（分形布朗运动）系统**，并带有 SSE2/AVX2 SIMD 优化。

#### 3.3.1 基础哈希函数

```cpp
// TerrainGenerator.cpp:45-52
MECRAFT_FORCEINLINE uint32_t hash32(uint32_t x) {
    x ^= x >> 16;
    x *= 0x7feb352dU;
    x ^= x >> 15;
    x *= 0x846ca68bU;
    x ^= x >> 16;
    return x;
}
```

这是一个低偏移、雪崩性质良好的整数哈希，使用 `0x7feb352d` 与 `0x846ca68b` 两个魔数做乘法混淆。

#### 3.3.2 格点哈希

```cpp
// TerrainGenerator.cpp:93-106
double lattice2D(int x, int z, uint32_t seed);   // 2D 格点 -> [0,1]
double lattice3D(int x, int y, int z, uint32_t seed);  // 3D 格点 -> [0,1]
```

通过对整数坐标做乘法混淆后异或种子，再经 `hash32` 映射到 `[0,1]` 区间。

#### 3.3.3 Value Noise

```cpp
// TerrainGenerator.cpp:108-164
double valueNoise2D(double x, double z, double cellSize, uint32_t seed);
double valueNoise3D(double x, double y, double z, double cellSize, uint32_t seed);
```

经典 Value Noise 实现：
1. 将坐标除以 `cellSize` 得到缩放坐标
2. 取四个（2D）或八个（3D）格点角的哈希值
3. 用 `smoothStep(t) = t²(3-2t)` 做双线性/三线性插值

#### 3.3.4 FBM 分形布朗运动

```cpp
// TerrainGenerator.cpp:166-196
double fbm2D(double x, double z, double firstCell, int octaves, uint32_t seed);
double fbm3D(double x, double y, double z, double firstCell, int octaves, uint32_t seed);
```

每个倍频：
- 振幅 `amplitude` 减半（`*= 0.5`）
- 单元大小 `cell` 减半（`*= 0.5`）
- 种子叠加偏移（2D 用 `+1013`，3D 用 `+2053`）
- 最终结果归一化（`sum / weight`）

#### 3.3.5 SIMD 优化版本

| 函数 | 指令集 | 并行度 | 用途 |
|------|--------|--------|------|
| `valueNoise2D2()` | SSE2 | 2 路 | 一次处理 2 个 X 坐标 |
| `fbm2D2()` | SSE2 | 2 路 | 2 路 FBM |
| `hash32_4()` | AVX2 | 4 路 | 4 路并行哈希 |
| `lattice2D4()` | AVX2 | 4 路 | 4 路格点哈希 |
| `smoothStep4()` | AVX2 | 4 路 | 4 路 smoothStep |
| `valueNoise2D4()` | AVX2 | 4 路 | 4 路 Value Noise |
| `fbm2D4()` | AVX2 | 4 路 | 4 路 FBM |
| `sampleSurfaceAndMoisture4()` | AVX2 | 4 路 | 4 路地表采样 |
| `sampleSurfaceAndMoisture2()` | SSE2 | 2 路 | 2 路地表采样 |

宏开关：


### 3.4 地形高度合成

#### 3.4.1 多层噪声叠加

`sampleSurfaceAndMoistureScalar()` 函数使用了 **6 层独立噪声**，每层用不同的种子异或常量（取自 SHA-256 初始哈希值）：

| 噪声名称 | 噪声类型 | 单元大小 | 倍频数 | 种子异或 | 作用 |
|---------|---------|---------|--------|---------|------|
| continental | fbm2D | 320.0 | 4 | `0x6a09e667` | 大陆轮廓（宏观高度） |
| detail | fbm2D | 64.0 | 4 | `0xbb67ae85` | 中等地形细节 |
| rough | fbm2D | 28.0 | 3 | `0x3c6ef372` | 粗糙度 |
| ridgeBase | fbm2D | 96.0 | 4 | `0x510e527f` | 山脊噪声 |
| mountainNoise | fbm2D | 220.0 | 3 | `0x1f83d9ab` | 山区分布 |
| moisture | fbm2D | 420.0 | 3 | `0xa54ff53a` | 湿度（决定生物群系） |

#### 3.4.2 高度合成公式

`finalizeSurfaceSample()` 函数（`TerrainGenerator.cpp:466-509`）：

```
ridge = 1.0 - |ridgeBase * 2 - 1|                    // 脊线噪声（绝对值反转）
mountainMask = smoothRange(continental, 0.50, 0.66)   // 大陆性过渡到山地的掩码
highMountainMask = mountainMask
                 * smoothRange(ridge, 0.58, 0.88)
                 * smoothRange(mountainNoise, 0.45, 0.75)  // 高山掩码（三重交集）

height = seaLevel                                     // 基准 = 海平面 (63)
       + (continental - 0.5) * 42                     // 大陆偏移 ±21
       + (detail - 0.5) * 20                          // 细节起伏 ±10
       + (rough - 0.5) * 18                           // 粗糙度 ±9
       + max(0, rough - 0.52) * 20                    // 粗糙峰值增强
       + mountainMask * 22                            // 山地抬升
       + ridge * mountainMask * 10                    // 山脊叠加
       + highMountainMask * 34                        // 高山抬升

if (moisture < 0.32) height -= 3                      // 干旱气候降低高度

surfaceY = clamp(round(height), 8, 248)               // 限制在 [8, 248]
```

其中 `smoothRange(v, lo, hi)` 将 `[lo, hi]` 区间的值平滑映射到 `[0, 1]`：

```cpp
// TerrainGenerator.cpp:38-43
double smoothRange(double v, double lo, double hi) {
    if (hi <= lo) return v >= hi ? 1.0 : 0.0;
    return smoothStep(saturate((v - lo) / (hi - lo)));
}
```

`outRuggedness = 0.45 * rough + 0.55 * ridge` —— 粗糙度指标，用于后续地表方块选择。

#### 3.4.3 生物群系判定

```
if (highMountainMask > 0.42)      -> HighMountain
else if (mountainMask > 0.48)      -> Mountain
else if (moisture < 0.34)          -> Arid
else                               -> Temperate
```

### 3.5 洞穴生成

**算法**：3D FBM 噪声 + 深度相关阈值

```cpp
// TerrainGenerator.cpp:198-201
double sampleCaveNoise(int worldX, int y, int worldZ, uint32_t seed) {
    return fbm3D(x, y, z, 44.0, 3, seed ^ 0x510e527fU);
}

// TerrainGenerator.cpp:203-207
bool shouldCarveCaveFromNoise(double cave, int y, int surfaceY) {
    const double depthFactor = (surfaceY - y) / 256.0;
    const double threshold = 0.77 - depthFactor * 0.18;  // 越深阈值越低
    return cave > threshold;
}
```

- 单元大小 44.0，3 个倍频
- 深度因子 `(surfaceY - y) / 256`：越深 `depthFactor` 越大，`threshold` 越低，越容易挖洞
- 洞穴范围：`y ∈ [10, surfaceY - 5]`

#### 优化：`buildCaveMaskColumn()`

`TerrainGenerator.cpp:220-285` 对整列 Y 值一次性计算所有倍频噪声，避免逐 Y 重复采样。关键优化是 **Y 轴格点缓存**：

```cpp
bool hasCachedSlice = false;
int cachedYCell = 0;
double slice0 = 0.0, slice1 = 0.0;

for (int y = caveStartY; y <= caveEndY; ++y) {
    const int y0 = static_cast<int>(std::floor(sy));
    if (!hasCachedSlice || y0 != cachedYCell) {
        cachedYCell = y0;
        slice0 = interpolateNoiseXZSlice(x0, x1, y0, z0, z1, tx, tz, octaveSeed);
        slice1 = interpolateNoiseXZSlice(x0, x1, y0 + 1, z0, z1, tx, tz, octaveSeed);
        hasCachedSlice = true;
    }
    // 只需对 Y 做插值，XZ 切片已缓存
}
```

### 3.6 矿石生成

**算法**：基于坐标的确定性哈希 + 高度分层概率

| 矿石 | Y 范围 | 概率 | Salt 常量 | Cutoff 常量 |
|------|-------|------|---------|------------|
| 钻石矿 | y ≤ 16 | 0.45% | `0x89abcdef` | `kOreCutoffDiamond` |
| 金矿 | y ≤ 32 | 0.80% | `0x13572468` | `kOreCutoffGold` |
| 铁矿 | y ≤ 64 | 1.60% | `0xfedcba98` | `kOreCutoffIron` |
| 煤矿 | y ≤ 128 | 2.40% | `0x2468ace0` | `kOreCutoffCoal` |

哈希方式（`TerrainGenerator.cpp:899-919`）：

```cpp
uint32_t h = m_seed;
h ^= hash32(worldX * 0x9e3779b9U);   // kOreXMul
h ^= hash32(y * 0x7f4a7c15U);        // kOreYMul
h ^= hash32(worldZ * 0x94d049bbU);   // kOreZMul
// 然后与矿石 Salt 异或后哈希，与概率 Cutoff 比较
if (hash32(h ^ kOreSaltDiamond) < kOreCutoffDiamond) id = DIAMOND_ORE;
```

**逐层判定**（注意优先级，低层优先）：
```
y <= 16  -> 钻石矿判定
y <= 32  -> 金矿判定
y <= 64  -> 铁矿判定
y <= 128 -> 煤矿判定
```

`generateChunk()` 中进一步优化：列级预计算 `oreColumnSeed`（仅 X、Z 分量），Y 分量在循环内逐层叠加，避免重复哈希。

### 3.7 树木生成

#### 3.7.1 树候选判定 `sampleTreeCandidate()`

`TerrainGenerator.cpp:609-644`：

1. **生物群系检查**：只有 `Temperate` 和 `Mountain` 可以种树（`Arid` 和 `HighMountain` 不可）
2. **湿度要求**：`moisture >= 0.38`，且 `surfaceY >= seaLevel`（不在水下）
3. **密度概率**：
   - Temperate：`0.012 + moisture * 0.018`（1.2% ~ 3.0%）
   - Mountain：`0.004 + moisture * 0.008`（0.4% ~ 1.2%）
4. **树种**：42% 概率为白桦（`BIRCH_LOG` + `BIRCH_LEAVES`），其余为橡木（`WOOD` + `OAK_LEAVES`）
5. **树高**：`4 + hash % 3`（4 ~ 6 格）
6. **高度上限检查**：`surfaceY + height + 1 < 256`

Salt 常量：
```cpp
kTreeSaltDensity  = 0x7b9d3f25U;
kTreeSaltSpecies  = 0x2f4c8a91U;
kTreeSaltHeight   = 0x5e6b1c37U;
```

#### 3.7.2 树叶形状 `sampleTreeBlockFromCandidate()`

```
if (dx==0 && dz==0 && trunkMinY <= y <= trunkMaxY)  -> LOG（树干）
```

### 3.8 植被生成 `sampleVegetationBlock()`

`TerrainGenerator.cpp:711-749`：

- **前置条件**：`surfaceY >= seaLevel` 且 `moisture >= 0.36`
- **密度**：

### 3.9 方块放置逻辑 `sampleBlock()`

`TerrainGenerator.cpp:758-837`，单方块采样主逻辑：

```
y == 0              -> BEDROCK (基岩层)
y <= surfaceY:
    y == surfaceY       -> topBlock (顶层)
    y >= surfaceY-cover -> fillBlock (填充层)
    else                -> STONE
    洞穴区域             -> AIR
    STONE 且 y <= 128    -> 矿石判定
surfaceY < y <= seaLevel -> WATER (水)
其余                     -> AIR

AIR 时判定:
    -> 树木方块判定
    -> 植被判定 (仅当 y == surfaceY+1 且 topBlock == GRASS)
```

#### 顶层方块选择规则

| 条件 | topBlock | fillBlock | coverDepth |
|------|----------|-----------|------------|
| 海平面以下 / Arid / moisture<0.34 | SAND | SAND | 4 |
| HighMountain（泥土斑块） | GRASS | DIRT | 2 |
| HighMountain（岩石） | GRASS | STONE | 1 |
| Mountain（岩石顶） | GRASS | STONE | 2 |
| Mountain（普通） | GRASS | DIRT | 3 |
| Temperate（soilNoise>0.74） | GRASS | DIRT | 4 |
| Temperate（soilNoise<0.30） | GRASS | DIRT | 2 |

**文件**：`src/world/World.h:162-165`

### 5.3 区块生成完整流程

1. `ChunkTicketManager::getChunksToLoad()` 根据玩家位置确定待加载区块（按距离排序）
2. `World::submitChunkLoad(cx, cz)` 将生成任务提交到线程池
3. 工作线程先尝试从磁盘加载（`SaveManager::tryLoadChunk()`），失败则调用 `TerrainGenerator::generateChunk()`
4. 生成完成后推入 `m_completedGenQueue`（互斥锁保护）
5. 主线程在 `updateStreaming()` 中以 1ms 时间预算逐步 `finalizeChunkLoad()`
6. `finalizeChunkLoad()` 完成：
   - 邻居指针链接（Chunk 级 4 方向 + SubChunk 级 6 方向）
   - 边界 SubChunk dirty 标记（触发网格重建）
   - `LightService::onChunkLoaded()` 提交光照任务

### 5.4 区块卸载流程

1. `ChunkTicketManager::getChunksToUnload()` 返回超出 `unloadRadius` 的区块
2. `World::unloadChunk()`：
   - 脏区块异步保存（`SaveManager::submitSaveChunk()`）
   - `LightService::onChunkUnloaded()` 通知光照服务
   - 清理邻居指针（双向断开）
   - 从 `m_chunks` 移除

## 十五、关键设计亮点

### 15.1 自研噪声系统 + SIMD 优化

- 不依赖第三方库，使用自研 Value Noise + FBM
- SSE2（2 路并行）和 AVX2（4 路并行）批量计算
- `sampleSurfaceYBatch()` 自动选择最优 SIMD 路径
- 列级 Y 轴格点缓存避免重复采样

### 15.2 确定性生成

- 所有地形特征完全由种子和坐标确定性生成
- `sampleBlock()` 可在区块未加载时直接采样任意位置方块
- 无需存储生物群系数据，运行时实时计算
- 同一种子下，任意位置的地形可独立复现

### 15.3 懒加载 + 自动回收

- SubChunk 初始为 `nullptr`（零内存），首次写入才创建
- 方块修改后自动检查是否可以回收为 `nullptr`
- `SubChunkType` 语义类型实现零成本跳过（Air 跳过网格化/渲染）

### 15.4 异步管线

- 区块生成在工作线程执行
- 完成后在主线程以 1ms 时间预算逐步 finalize（避免帧率抖动）
- 光照计算独立异步，带背压机制
- 区块保存异步序列化 + 异步文件写入

### 15.5 双层流体

- 方块层 + 独立流体层支持 waterlogged 方块
- 纯水位置存储在方块层，waterlogged 位置存储在流体层

### 15.6 跨区块特征生成

- 树木扫描范围超出区块边界（`kTreeScanRadius=2`），确保边界树木正确生成
- 邻居指针双向链接保证边界连续性
- 区块序列化保存调色板 + 位压缩数据，使用 NamespacedId 保证跨版本兼容

### 15.7 滞后卸载

- `unloadRadius = loadRadius + 2`，形成 2 区块宽缓冲带
- 避免玩家在边界来回移动时频繁加载/卸载

## 十七、总结

Mecraft 的世界生成与地形系统采用了清晰的分层架构：

1. **底层存储**：`BitPackedArray` + `Palette` 实现紧凑的方块数据存储，`SubChunkType` 语义类型实现零成本跳过。
2. **中层结构**：`SubChunk`（16³）与 `Chunk`（16×256×16）组织方块数据，懒加载 + 自动回收控制内存占用。
3. **上层生成**：`TerrainGenerator` 通过 6 层 FBM 噪声合成地形高度，结合洞穴、矿石、树木、植被生成完整世界。
4. **流式管理**：`ChunkTicketManager` 多级半径 + 滞后卸载，`World` 异步管线 + 时间预算控制加载节奏。
5. **子系统协调**：`LightService` 异步光照、`FluidSystem` 流体模拟、`WeatherSystem`/`DayNightSystem` 环境模拟。

设计上注重**性能**（SIMD 优化、懒加载、异步管线、位压缩）、**确定性**（种子驱动、实时采样）、**可扩展性**（IWorldView 抽象、调色板压缩、NamespacedId 跨版本兼容）和**稳定性**（滞后卸载、背压机制、原子写入）。
