# 区块加载回放压测

本轮针对高速移动时的慢帧，使用 `chunk-threading-1` 的主线程热点定位，并用同一操作录像对比优化前后的完整回放。进入游戏时的单次 250 ms 尖峰不作为优化指标。

## 实现改动

- 光照任务的方块快照按子区块读取。每个调色板条目只转换一次方块类型；缺失子区块和单条目调色板批量填充。位压缩读取的掩码计算内联，保留跨 64 位存储字的读取规则。
- 已有子区块的光照数组直接复制。缺失子区块按照高度图恢复隐式天空光，不会把实际保存了光照的空气子区块当作空存储。
- 初始基础光照缓存复用一次方块类型快照，天空光和发光源扫描共享这份数据。
- 活跃区块集合变化时保留相同区块对象的渲染列缓存，只对轻量条目排序。区块对象引用保留到下一次同步，避免同坐标重新加载时因地址复用误用旧缓存；两个渲染列数组交换并复用容量。
- RTGI 关闭时，网格任务跳过 CPU 光追几何生成。重新开启时递增现有子区块网格版本，在处理结果之前使旧任务失效，并按正常预算重新生成所需几何。光追关闭时，暂停的 BLAS 任务不阻止网格状态收敛。

## 复现方法

本轮优化前的可执行文件已保留为 `cmake-build-vtune/mecraft-perf-baseline`。构建最终版本后进入构建目录：

```sh
cmake --build cmake-build-vtune --target mecraft -j20
cd cmake-build-vtune
```

在构建完全结束后分别运行以下命令；两次回放不能并行运行，也不能与编译重叠。保持 `assets/config/settings.json`、世界文件、窗口大小与操作录像一致。本轮设置为 Vulkan、Deferred、RTGI 关闭。

```sh
./mecraft-perf-baseline \
  --benchmark-world chunk-vtune-run-01 \
  --benchmark-no-save \
  --replay-input captures/chunk-load.json \
  --benchmark-report vtune-results/chunk-perf-before-1.json

./mecraft \
  --benchmark-world chunk-vtune-run-01 \
  --benchmark-no-save \
  --replay-input captures/chunk-load.json \
  --benchmark-report vtune-results/chunk-perf-after-2.json
```

从构建目录运行，录像和运行时资源路径均相对于该目录。第二轮更换报告文件名并交换新旧版本的运行顺序。

用于本轮测量的录像 SHA-256：`bb81c915ac7331fa3a1acd8d622ea9f58ca842dfdf1a15e15880810afd307bd8`。

## 2026-10-11 测量结果

新旧版本各独立运行两次。以下数值来自 `cmake-build-vtune/vtune-results/` 下的原始 JSON：

| 报告 | 平均 FPS | P50（ms） | P95（ms） | P99（ms） |
| --- | ---: | ---: | ---: | ---: |
| `chunk-perf-before-1.json` | 163.14 | 4.750 | 16.092 | 20.958 |
| `chunk-perf-before-2.json` | 160.70 | 4.749 | 16.497 | 21.540 |
| `chunk-perf-after-2.json` | 177.90 | 4.783 | 11.040 | 15.684 |
| `chunk-perf-after-3.json` | 177.77 | 4.779 | 11.114 | 15.986 |

对两次运行的各项指标取算术平均：平均帧率从 161.92 提升到 177.83 FPS，约提升 9.8%；P95 从 16.29 降到 11.08 ms，约减少 32.0%；P99 从 21.25 降到 15.83 ms，约减少 25.5%。P50 从 4.75 变为 4.78 ms，基本持平。这里的分位数平均值不是合并所有帧后重新计算的分位数。

主要改善出现在慢帧，而非典型帧。最终版本两次回放的末尾统计窗口内，`TerrainBLAS.Build`、`TerrainBLAS.Compaction`、`SceneTLAS` 操作次数均为 0。

## 测量范围

`frame_ms` 覆盖完整回放；本录像约 77.35 秒。P95/P99 用于观察区块流式加载造成的慢帧。`complete_gpu_frame_ms`、渲染图阶段与加速结构统计仅保留最后 1000 帧，不能当作全程统计，也不能直接与某个 CPU 时间区间等同。

构建为 Release，性能对比期间未开启 VTune。首次与编译重叠的 `chunk-perf-baseline.json` 不参与比较；`chunk-perf-after-1.json` 属于尚未跳过 CPU 光追几何生成的中间版本。

性能回放验证了 RTGI 关闭的加载路径。运行中关闭再开启 RTGI 的画面恢复仍需实际交互验证；本轮没有新增或运行单元测试。
