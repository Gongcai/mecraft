# 导入 Minecraft 原版音效

项目参考 Minecraft Java Edition 1.21.1 的声音事件。原版音效从 Mojang 官方版本清单和资源 CDN 获取，不使用第三方搬运站：

- 版本清单：`https://piston-meta.mojang.com/mc/game/version_manifest_v2.json`
- 资源文件：`https://resources.download.minecraft.net/<hash-prefix>/<hash>`

运行以下命令会读取原版 `sounds.json`，按 Mecraft 的事件映射仅下载当前玩法用到的 OGG 文件，并生成 `assets/sounds/vanilla/sounds.json` 覆盖清单：

```sh
python3 scripts/import_minecraft_sounds.py
```

默认目标版本为 `1.21.1`，可通过 `--version` 指定 Mojang 版本清单中的 Java 版版本号。音频和覆盖清单保存在 `assets/sounds/vanilla/`，该目录已加入 `.gitignore`；原版音频二进制不随项目提交，使用者需要从自己的 Minecraft 安装或 Mojang 官方 CDN 导入。脚本会校验资源索引中的 SHA-1 与文件大小。游戏先载入仓库内的基础音效，再应用本地覆盖清单；未导入原版资源时仍使用项目基础音效。

导入的项目事件覆盖玩家脚步、坠落与受伤，方块材质破坏/放置，沙子坠落，音符方块，桶与锄头交互，投掷物，以及僵尸、苦力怕、牛、猪和羊的受伤/死亡音效。背景音乐不在本次导入范围内。
