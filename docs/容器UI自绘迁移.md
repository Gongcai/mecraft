# 容器 UI 自绘迁移

背包、创造模式、工作台和数据驱动容器已统一使用游戏自建 UI。面板复用 `UIPanel` 的主题和背景模糊，槽位使用主题中的输入框颜色，标题经过现有本地化系统处理。物品图标、数量文字、玩家预览和物品操作继续使用原有实现；游戏底部物品栏继续使用原版纹理和选中框。

`assets/config/container_ui/*.json` 只声明容器行为、标题键、设计尺寸、锚点、槽位组和进度条。`titleKey` 对应 `assets/config/locale/*` 中的 `ui` 键。已移除背景纹理路径、图集尺寸及进度条 UV 坐标，不再预加载原版背包或创造模式 GUI 贴图。

槽位组的 `x/y` 保持左上角设计坐标，绘制和命中检测使用同一转换。面板缩放同时计入新增标题区或创造模式标签区，避免窗口缩小时标题被裁剪。原有槽位索引和容器玩法保持兼容。

创造模式顶部提供“全部物品”和“背包”两个有效标签，列表仍使用鼠标滚轮翻行。熔炉的燃料和烧炼进度使用自绘轨道与填充；进度为零时轨道仍可见。工作台和生存背包的合成输入与输出之间使用自绘箭头。

验证：Linux 主程序通过 `build.sh` 增量构建；背包、创造模式、容器注册、容器创建、物品拖拽、UI 调度和主题解析共 7 项测试通过。Vulkan 虚拟显示器实测确认了中文背包标题、合成箭头、玩家预览、物品图标及原版物品栏同时正常显示。
