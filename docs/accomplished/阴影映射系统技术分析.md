# 阴影映射系统 (Shadow Mapping System)

## 1. 概述

DerivativeMain 的阴影映射系统是一套多层次、多技术融合的复杂实现，涵盖了从基础的 Shadow Map 到 PCSS 软阴影、屏幕空间阴影、彩色阴影、水下焦散、次表面散射、体积雾阴影、Distant Horizons 远景阴影以及全局光照（RSM）等多个子系统。整个系统围绕着将世界空间坐标投影到阴影空间、采样阴影贴图、并最终与基于物理的光照管线集成这一核心流程展开。

---

## 2. 阴影贴图分辨率与配置

### 2.1 分辨率

阴影贴图分辨率在 `lib/Lighting/SunLighting.glsl` 中定义：

```glsl
const int shadowMapResolution = 2048;  // [1024 2048 4096 8192 16384 32768]
const float realShadowMapRes = shadowMapResolution * MC_SHADOW_QUALITY;
```

默认分辨率为 2048，支持从 1024 到 32768 的范围。`realShadowMapRes` 乘以了 Iris 的 `MC_SHADOW_QUALITY` 系数，用于在不同渲染质量设置下自适应调整实际采样分辨率。

### 2.2 阴影距离

```glsl
const float shadowDistance = 192.0; // [64.0 ... 65536.0]
```

默认阴影绘制距离为 192 格，可配置至 65536 格。超出此距离的片段会通过 `distanceFade` 参数平滑过渡到无阴影状态：

```glsl
float distanceFade = saturate(pow16(rcp(shadowDistance * shadowDistance) * dotSelf(worldPos)));
```

使用 `pow16` 实现了非常陡峭的衰减曲线，确保在阴影距离边缘产生清晰但不突兀的过渡。

### 2.3 用户可配置选项

在 `Settings.glsl` 中暴露了以下阴影相关设置：

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `SHADOW_MAP_BIAS` | 0.9 | 阴影畸变偏移强度 |
| `COLORED_SHADOWS` | 启用 | 彩色阴影（彩色玻璃） |
| `SCREEN_SPACE_SHADOWS` | 启用 | 屏幕空间阴影 |
| `SHADOW_BACKFACE_CULLING` | 禁用 | 阴影背面剔除 |
| `DH_SHADOW` | 禁用 | Distant Horizons 阴影 |
| `PCF_SAMPLES` | 16 | PCF 采样数 [4-64] |

### 2.4 阴影缓冲区配置

在 `shaders.properties` 中：

```properties
shadow.culling = false  # 仅在 GI 启用时禁用，确保 RSM 采样完整性
blend.shadow = off      # 阴影 pass 关闭混合
dhShadow.enabled = false # 默认禁用 DH 阴影
```

阴影 pass 使用两个输出缓冲区：
- `shadowcolor0` (rgb): 存储反照率颜色，用于彩色阴影和 GI
- `shadowcolor1` (xyzw): 存储编码法线 (xy)、光照贴图天空光 (z)、水面高度 (w)

## 3. 阴影畸变函数

### 3.1 核心畸变算法

阴影畸变在 `lib/Lighting/ShadowDistortion.glsl` 中实现，其目的是将近裁剪面附近的阴影贴图分辨率集中分配，而远处则降低精度，从而在有限的贴图分辨率下最大化近处的阴影质量。

```glsl
float DistortionFactor(in vec2 shadowClipPos) {
    #if defined DISTANT_HORIZONS && defined DH_SHADOW
        return 1.0;
    #else
        return quarticLength(shadowClipPos * 1.165) * SHADOW_MAP_BIAS + 1.0 - SHADOW_MAP_BIAS;
    #endif
}
```

**四次方长度函数** (`quarticLength`)：
```glsl
float quarticLength(in vec2 v) {
    return sqrt2(pow4(v.x) + pow4(v.y));
}
```

这是一个独特的设计。与传统的对数畸变或简单除法畸变不同，这里使用了四次方范数的平方根。与欧几里得长度相比，四次方长度在过渡区域产生了更平滑的畸变梯度，在中心区域保持接近线性，而在边缘区域畸变更强。参数 `1.165` 是一个经过调优的缩放因子，用于匹配标准阴影投影矩阵的范围。

### 3.2 阴影空间变换

```glsl
vec3 DistortShadowSpace(in vec3 shadowClipPos, in float DistortionFactor) {
    #if defined DISTANT_HORIZONS && defined DH_SHADOW
        return shadowClipPos * vec3(vec2(1.0), 0.05);
    #else
        return shadowClipPos * vec3(vec2(rcp(DistortionFactor)), 0.2);
    #endif
}
```

标准模式下：
- XY 方向：除以畸变因子（非线性压缩）
- Z 方向：乘以 0.2（深度范围压缩到 1/5）

DH 阴影模式下：
- XY 方向：不畸变（`1.0`），因为 DH 使用独立的正交投影
- Z 方向：乘以 0.05（更激进的深度压缩，适应 DH 的超远距离）

### 3.3 法线偏移防痤疮

在 `deferred5.fsh` 中，阴影投影位置计算包含法线偏移：

```glsl
vec3 normalOffset = worldNormal * (dotSelf(worldPos) * 8e-5 + 3e-2) * (2.0 - saturate(NdotL));
vec3 shadowProjPos = WorldPosToShadowProjPosBias(worldPos + normalOffset, distortFactor);
```

这个偏移策略非常精巧：
- `dotSelf(worldPos) * 8e-5`：随距离线性增加偏移，补偿远距离的精度损失
- `3e-2`：基础偏移量，防止近距离痤疮
- `(2.0 - saturate(NdotL))`：当表面背对光源时偏移增大（NdotL 小 → 偏移大），因为背对光源的面更容易出现痤疮

### 3.4 PCF 中的深度偏移

```glsl
shadowProjPos.z -= 1e-4 - dither * 5e-5;
```

在 PCF 采样前，使用抖动的深度偏移（1e-4 ± 5e-5），既防止痤疮又通过抖动减少了带状伪影。

## 4. 阴影过滤

### 4.1 PCSS（Percentage Closer Soft Shadows）

系统实现了完整的 PCSS 流程，包含遮挡物搜索和自适应 PCF。

**遮挡物搜索** (`BlockerSearch`)：

```glsl
vec2 BlockerSearch(in vec3 shadowProjPos, in float dither) {
    float searchRadius = 2.0 * shadowProjection[0].x;
    // 8 个采样点，旋转采样模式
    for (uint i = 0u; i < 8u; ++i, rot *= rotStep) {
        vec2 sampleCoord = shadowProjPos.xy + rot * sqrt(fi * 0.125);
        float depthSample = texelFetch(shadowtex0, ivec2(sampleCoord * realShadowMapRes), 0).x;
        float weight = step(depthSample, shadowProjPos.z);
        sssDepth += max0(shadowProjPos.z - depthSample);
        searchDepth += depthSample * weight;
        sumWeight += weight;
    }
    // 返回: (归一化的遮挡物深度, SSS 深度)
    return vec2(searchDepth * shadowProjection[0].x, sssDepth * shadowProjectionInverse[2].z);
}
```

关键设计：
- 使用 `sqrt(fi * 0.125)` 的螺旋采样分布，近处密集、远处稀疏
- 旋转矩阵 `rotStep` 基于 45 度角步进（`TAU * 0.125`），覆盖 8 个方向
- 同时计算 SSS 深度，复用于次表面散射
- 搜索半径基于投影矩阵的缩放因子 `shadowProjection[0].x`，自适应于阴影空间

**自适应 PCF** (`PercentageCloserFilter`)：

```glsl
vec3 PercentageCloserFilter(in vec3 shadowProjPos, in float dither, in float penumbraScale) {
    // PCF_SAMPLES 个采样点（默认16）
    for (uint i = 0u; i < PCF_SAMPLES; ++i, rot *= rotStep) {
        vec2 sampleCoord = shadowProjPos.xy + rot * sqrt(fi * rSteps);
        // 使用 sampler2DShadow 进行硬件比较
        float sampleDepth1 = textureLod(shadowtex1, vec3(sampleCoord, shadowProjPos.z), 0).x;
        // 彩色阴影分支
        #ifdef COLORED_SHADOWS
            ivec2 sampleTexel = ivec2(sampleCoord * realShadowMapRes);
            float sampleDepth0 = step(shadowProjPos.z, texelFetch(shadowtex0, sampleTexel, 0).x);
            if (sampleDepth0 != sampleDepth1) {
                result += pow4(texelFetch(shadowcolor0, sampleTexel, 0).rgb) * sampleDepth1;
            }
        #endif
    }
    return result * rSteps;
}
```

**半影缩放**计算：
```glsl
float penumbraScale = max(blockerSearch.x / distortFactor, 2.0 / realShadowMapRes);
```

- `blockerSearch.x / distortFactor`：遮挡物深度除以畸变因子，得到正确的半影大小
- `2.0 / realShadowMapRes`：最小半影为 2 个纹素，防止点采样伪影
- `penumbraScale` 作为 PCF 采样半径，实现了距离相关的软阴影

### 4.2 采样模式

PCF 和 Blocker Search 都使用了相同的旋转螺旋采样模式：
- 旋转矩阵步进：`cossin(TAU * 0.125)` = 45 度
- 径向分布：`sqrt(fi * rSteps)`，产生均匀的面积覆盖
- 逐帧旋转：`dither * TAU` 提供时域抖动

这种模式比规则网格采样更高效，能用更少的采样点产生更均匀的覆盖。

## 5. 彩色阴影（透明阴影）

### 5.1 阴影 Pass 写入

在 `program/Shadow/Shadow.frag` 中：

```glsl
if (isWater > 0.5) {
    // 水面处理（见焦散章节）
} else {
    vec4 albedo = texture(tex, texcoord);
    if (albedo.a < 0.1) discard;
    if (albedo.a > 254.0 / 255.0) {
        shadowcolor0Out = albedo.rgb * tint;  // 不透明物体
    } else {
        shadowcolor0Out = albedo.rgb * tint;  // 半透明物体（彩色玻璃等）
    }
}
```

### 5.2 阴影 Pass 读取

在 PCF 采样过程中，比较 `shadowtex0`（不透明深度）和 `shadowtex1`（含透明深度）：

```glsl
float sampleDepth0 = step(shadowProjPos.z, texelFetch(shadowtex0, sampleTexel, 0).x);
float sampleDepth1 = textureLod(shadowtex1, vec3(sampleCoord, shadowProjPos.z), 0).x;

if (sampleDepth0 != sampleDepth1) {
    // 当前采样点被半透明物体遮挡
    result += pow4(texelFetch(shadowcolor0, sampleTexel, 0).rgb) * sampleDepth1;
}
```

- `shadowtex0` 只包含不透明物体的深度
- `shadowtex1` 包含所有物体（含半透明）的深度
- 当两者不一致时，说明采样点被半透明物体遮挡，从 `shadowcolor0` 读取颜色
- 阴影颜色经过 `pow4()` 色调映射，增强对比度

## 6. 屏幕空间阴影

### 6.1 算法实现

```glsl
float ScreenSpaceShadow(vec3 viewPos, vec3 viewNormal, float dither) {
    vec3 stepVec = worldLightVector * (0.25 / gbufferProjection[1][1]);
    vec3 rayPos = viewPos + viewNormal * 0.05;  // 法线偏移防自阴影

    for (uint i = 0u; i < 12u; ++i, rayPos += stepVec) {
        vec3 screenPos = ViewToScreenSpace(rayPos);
        float depthSample = GetDepthLinear(ivec2(screenPos.xy * viewResolution));
        float zTolerance = 0.025;

        if (abs(rayPos.z - depthSample) < zTolerance && depthSample < rayPos.z) {
            return 0.0;  // 被遮挡
        }
    }
    return 1.0;  // 未被遮挡
}
```

- 12 步光线步进，步长自适应于投影矩阵的 `gbufferProjection[1][1]`
- 使用 `zTolerance = 0.025` 防止远处物体的自阴影
- 法线偏移 `0.05` 进一步减少自阴影伪影

### 6.2 SSS 吸收衰减

```glsl
#ifdef SCREEN_SPACE_SHADOWS
    float sssShadow = ScreenSpaceShadow(viewPos, viewNormal, dither);
    if (sssAmount > 0.0) {
        vec3 absorption = pow(sssAmount, sqrt(length(viewPos)) * 0.5);
        sssShadow *= mix(1.0, exp(-absorption * 2.0), sssAmount);
    }
#endif
```

对于次表面散射材质，屏幕空间阴影不仅检查遮挡，还计算光线通过材质时的吸收衰减。

## 7. 次表面散射（SSS）

### 7.1 双层散射模型

```glsl
vec3 CalculateSubsurfaceScattering(vec3 albedo, float sssAmount, float sssDepth, float LdotV) {
    vec3 coeff = albedo * inversesqrt(GetLuminance(albedo) + 1e-6);
    coeff = oneMinus(0.75 * saturate(coeff)) * (28.0 / sssAmount);

    // 外层：前向散射
    vec3 sss = fastExp(0.375 * coeff * sssDepth) * HenyeyGreensteinPhase(-LdotV, 0.6);

    // 内层：深层扩散
    sss += fastExp(0.125 * coeff * sssDepth) * (0.33 * HenyeyGreensteinPhase(-LdotV, 0.35) + 0.17 * rPI);

    return sss * sssAmount * PI;
}
```

- 散射系数基于 albedo 的亮度归一化，模拟不同颜色的散射深度差异
- **外层**：较大衰减系数（0.375）+ 高各向异性（g=0.6）的 Henyey-Greenstein 相位函数 —— 模拟前向散射
- **内层**：较小衰减系数（0.125）+ 低各向异性（g=0.35）+ 各向同性分量（0.17/π）—— 模拟深层扩散
- SSS 深度来自 blocker search 的深度差

### 7.2 SSS 与阳光的耦合

```glsl
// 有 SSS 的表面阳光强度降低 50%
sunlightMult *= 1.0 - sssAmount * 0.5;
```

避免 SSS 材质在直射光下过度明亮。

## 8. 全局光照（RSM）

### 8.1 Reflective Shadow Map 方法

```glsl
vec3 GlobalIllumination(vec3 worldPos, vec3 worldNormal, float dither) {
    vec3 gi = vec3(0.0);
    vec3 shadowPos = WorldToShadow(worldPos);

    for (uint i = 0u; i < GI_SAMPLES; ++i, rot *= rotStep) {
        vec2 sampleCoord = shadowPos.xy + rot * sqrt(fi * rSteps) * GI_RADIUS / realShadowMapRes;

        // 从阴影贴图重建采样点位置
        float sampleDepth = texelFetch(shadowtex1, ivec2(sampleCoord * realShadowMapRes), 0).x;
        vec3 samplePos = ShadowToWorld(sampleCoord, sampleDepth);

        // 距离检查
        float sampleDist = distance(samplePos, worldPos);
        if (sampleDist > GI_RADIUS) continue;

        // 入射方向和漫反射
        vec3 sampleDir = normalize(samplePos - worldPos);
        float NdotL = max0(dot(worldNormal, sampleDir));

        // 采样点法线和弹射方向
        vec3 sampleNormal = DecodeNormal(texelFetch(shadowcolor1, sampleTexel, 0).xy);
        float bounce = max0(dot(sampleNormal, -sampleDir));

        // 采样点反照率
        vec3 sampleAlbedo = texelFetch(shadowcolor0, sampleTexel, 0).rgb;

        // 天空光照图加权
        float skylight = texelFetch(shadowcolor1, sampleTexel, 0).z;
        float weight = exp2(-abs(skylight - mcLightmap.g) * 8.0);

        // 衰减
        float falloff = rcp(sampleDist + radiusAdd);

        gi += sampleAlbedo * NdotL * bounce * weight * falloff;
    }

    return gi * GI_BRIGHTNESS * rSteps;
}
```

- 使用阴影贴图作为反射阴影映射
- 螺旋采样模式，与 PCF 一致
- 距离衰减 `1/(dist + step)`
- 天空光照图加权确保只有光照条件相似的区域才贡献 GI

### 8.2 空间滤波

在 `deferred5.fsh` 中对 GI 结果进行双边空间滤波：

- 16 个采样点的 4x4 偏移模式
- 距离权重：`exp2(-distance * 4.0 * NdotV)`
- 法线权重：`pow16(max0(dot(prevNormal, normal)))`
- 空间权重：`exp2(-dotSelf(offset) * 0.1)`

## 9. 云阴影

### 9.1 体积云阴影

```glsl
float CloudShadow(vec3 worldPos, CloudProperties cloudProperties) {
    float cloudDensity = 0.0;
    vec3 checkOrigin = vec3(0.0, planetRadius + eyeAltitude, 0.0);
    float checkRadius = planetRadius + eyeAltitude;

    // 在云层底部 15% 处采样
    vec3 checkPos = RaySphereIntersection(checkOrigin, worldLightVector,
        checkRadius + 0.15 * cloudProperties.thickness).y * worldLightVector + worldPos;
    cloudDensity += CloudVolumeDensitySmooth(cloudProperties, checkPos);

    // 在云层中部 50% 处采样
    checkPos = RaySphereIntersection(checkOrigin, worldLightVector,
        checkRadius + 0.5 * cloudProperties.thickness).y * worldLightVector + worldPos;
    cloudDensity += CloudVolumeDensitySmooth(cloudProperties, checkPos);

    // 平面云阴影
    vec2 checkPos1 = RaySphereIntersection(checkOrigin, worldLightVector,
        planetRadius + CLOUD_PLANE_ALTITUDE).y * worldLightVector.xz + worldPos.xz;
    cloudDensity += CloudPlanarDensity(checkPos1) * 10.0;

    return exp2(-cloudDensity * cloudDensity * 2e2);
}
```

- 在云层两个高度层采样密度
- 平面云阴影单独叠加
- 使用 `exp2(-density^2 * 200)` 产生锐利的阴影边缘
- 天气湿度过高时阴影变深：`mix(1.0, 0.03, wetness)`

## 11. 光照集成

### 11.1 阴影合成顺序

在 `deferred5.fsh` 中：

```glsl
// 1. PCSS 软阴影
vec2 blockerSearch = BlockerSearch(shadowProjPos, dither);
float penumbraScale = blockerSearch.x / distortFactor;
vec3 shadow = PercentageCloserFilter(shadowProjPos, dither, penumbraScale);

// 2. 屏幕空间阴影
#ifdef SCREEN_SPACE_SHADOWS
    shadow *= ScreenSpaceShadow(viewPos, viewNormal, dither);
#endif

// 3. 云阴影
shadow *= CloudShadow(worldPos, cloudProperties);

// 4. 距离衰减
shadow *= oneMinus(distanceFade);

// 5. SSS 处理
if (sssAmount > 0.0) {
    vec3 sss = CalculateSubsurfaceScattering(albedo, sssAmount, blockerSearch.y, LdotV);
    sunlightMult *= 1.0 - sssAmount * 0.5;
}

// 6. 最终光照
vec3 directLight = shadow * diffuse * directIlluminance * sunlightMult;
```

## 12. 性能优化

| 优化策略 | 描述 |
|---------|------|
| 四次方畸变 | 将更多分辨率分配给近处，远处自动降低精度 |
| 旋转螺旋采样 | 比规则网格更高效，更少采样点产生更均匀覆盖 |
| 时域抖动 | dither 旋转采样模式，减少空间伪影 |
| SSS 深度复用 | blocker search 同时计算 SSS 深度，无需额外采样 |
| 屏幕空间阴影 | 近距离接触阴影，比增加阴影贴图分辨率更高效 |
| DH 阴影回退 | 远距离使用 DH 阴影，避免原版阴影距离不足的问题 |
| 法线偏移自适应 | 基于距离和 NdotL 的动态偏移，减少痤疮同时最小化 peter-panning |
| 条件编译 | GI、SSS、彩色阴影等功能独立开关，按需启用 |

## 13. 独特技术亮点

1. **四次方长度畸变**：独特的畸变函数，比传统对数畸变在中心区域更线性，边缘更平滑。

2. **PCSS + SSS 深度复用**：blocker search 同时输出遮挡深度和 SSS 深度，一次采样完成两个任务。

3. **法线偏移自适应**：`worldNormal * (dotSelf(worldPos) * 8e-5 + 3e-2) * (2.0 - saturate(NdotL))`，三因子联合调优。

4. **彩色阴影的 pow4 映射**：对彩色阴影颜色进行色调映射，增强对比度同时防止过亮。

5. **云阴影双层采样**：在云层底部和中部各采样一次，捕捉不同高度的云密度变化。

6. **DH 阴影平滑过渡**：原版阴影距离不足时，使用 DH 阴影平滑过渡，避免硬边界。

7. **RSM 全局光照**：复用阴影贴图进行 GI 采样，无需额外的渲染 pass。

8. **屏幕空间阴影的 SSS 吸收**：不仅检查遮挡，还计算光线通过 SSS 材质时的吸收衰减。
