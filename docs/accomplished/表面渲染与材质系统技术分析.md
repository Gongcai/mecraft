# 表面渲染与材质系统 (Surface Rendering and Material System)

## 1. 概述

DerivativeMain 的表面渲染系统涵盖 PBR 材质解码、视差遮蔽映射（POM）、法线映射、屏幕空间反射（SSR）、反射滤波、雨天湿润效果、折射以及植物动画等多个子系统。所有表面渲染逻辑集中在 `lib/Surface/` 目录下，通过 `program/Gbuffers/Terrain.frag` 和 `program/Gbuffers/Water.frag` 写入 G-Buffer，再由延迟通道统一处理。

## 2. 材质系统

### 2.1 材质 ID 映射

`block.properties` 文件将 Minecraft 方块 ID 映射到材质 ID，通过 `mc_Entity.x - 10000` 提取。约 30+ 种材质类别：

| ID | 方块类型 | 特殊处理 |
|----|---------|---------|
| 1-5 | 草/植物 | 顶点摆动动画 |
| 6 | 草方块 | 强制法线朝上 |
| 7 | 树叶 | SSS 默认 0.7 |
| 10 | 花/双层植物 | SSS 默认 0.7 |
| 12 | 冷光源 | 直接添加 12.0 亮度 |
| 15 | 火焰 | 自发光 + 发光源 |
| 16 | 彩色玻璃 | 透明折射 |
| 17 | 水 | 完整水体渲染管线 |
| 18 | 冰 | 特殊折射和雾效 |
| 20-34 | 各类发光方块 | 多种发光模式 |
| 57 | 主世界矿石 | 颜色空间检测发光 |
| 58 | 下界矿石 | 颜色空间检测发光 |

### 2.2 LabPBR 材质解码

支持 LabPBR 标准的 specular 纹理解码：

```glsl
// 格式 0: LabPBR
float smoothness = specTex.r;
material.roughness = sqr(1.0 - smoothness);
material.isMetal = float(specTex.g > 229.0 / 255.0);
material.f0 = material.isMetal > 0.5 ? 0.91 : specTex.g;
material.emissiveness = specTex.a == 1.0 ? 0.0 : pow(specTex.a, 2.2);

// 格式 1: 简化 PBR
material.roughness = specTex.r;
material.isMetal = specTex.g;
material.f0 = specTex.g * 0.96 + 0.04;
material.emissiveness = specTex.b;
```

### 2.3 Material 结构体

```glsl
struct Material {
    float roughness;       // 粗糙度 [0, 1]
    float isMetal;         // 金属标志 (0.0 或 1.0)
    float f0;              // 基础反射率
    float emissiveness;    // 自发光强度
    bool  hasReflections;  // 是否有反射
    bool  isRough;         // 是否为粗糙表面
};
```

## 3. 视差遮蔽映射 (POM)

文件：`lib/Surface/Parallax.glsl`

### 3.1 自适应步长光线步进

```glsl
vec2 ParallaxOcclusionMapping(vec3 viewVector, vec2 texCoord) {
    const uint steps = 60;
    vec3 stepSize = viewVector / max(-viewVector.z, 0.0) * 0.2;
    vec3 samplePos = vec3(texCoord, 0.0);
    float sampleHeight = 0.0;

    for (uint i = 0u; sampleHeight < samplePos.z && i < steps; ++i) {
        samplePos += stepSize;
        sampleHeight = texture(normals, samplePos.xy).a;
    }
```

- 默认 60 步，步长自适应于视角方向
- 从切线空间视角方向步进直到找到高度场交点

### 3.2 二分细化

```glsl
    // 二分细化（8 步）
    for (uint i = 0u; i < 8u; ++i) {
        stepSize *= 0.5;
        if (sampleHeight < samplePos.z) {
            samplePos -= stepSize;
        } else {
            samplePos += stepSize;
        }
        sampleHeight = texture(normals, samplePos.xy).a;
    }
```

命中后进行 8 步二分搜索，精度提升 256 倍（2^8）。

### 3.3 视差自阴影

```glsl
float ParallaxSelfShadow(vec3 lightVector, vec2 texCoord, float height) {
    vec3 stepSize = lightVector / max(-lightVector.z, 0.0) * 0.05;
    vec3 samplePos = vec3(texCoord, height);

    for (uint i = 0u; i < 12u; ++i, samplePos += stepSize) {
        float sampleHeight = texture(normals, samplePos.xy).a;
        if (sampleHeight > samplePos.z) return 0.0;
    }
    return 1.0;
}
```

沿光线方向步进 12 步，检查是否有遮挡。

### 3.4 高度图法线重建

从高度场通过中心差分重建法线：

```glsl
vec3 ParallaxNormal(vec2 texCoord) {
    float h = texture(normals, texCoord).a;
    float hL = texture(normals, texCoord + vec2(-step, 0.0)).a;
    float hR = texture(normals, texCoord + vec2(step, 0.0)).a;
    float hU = texture(normals, texCoord + vec2(0.0, step)).a;
    float hD = texture(normals, texCoord + vec2(0.0, -step)).a;
    return normalize(vec3(hL - hR, hD - hU, 2.0 * step));
}
```

## 4. 法线映射与 TBN

### 4.1 顶点级 TBN

在 `Terrain.vert` 中，从 `at_tangent` 属性构建 TBN 矩阵：

```glsl
vec3 tangent = normalize(at_tangent.xyz);
vec3 normal = normalize(gl_Normal);
vec3 bitangent = cross(normal, tangent) * at_tangent.w;
tbnMatrix = mat3(tangent, bitangent, normal);
```

### 4.2 手动 TBN 回退

对于没有 `at_tangent` 属性的方块（如实体），使用屏幕空间导数构建 TBN：

```glsl
mat3 manualTBN(vec3 normal) {
    vec3 dp1 = dFdx(viewPos);
    vec3 dp2 = dFdy(viewPos);
    vec2 duv1 = dFdx(texCoord);
    vec2 duv2 = dFdy(texCoord);

    vec3 T = normalize(dp1 * duv2.y - dp2 * duv1.y);
    vec3 B = normalize(dp2 * duv1.x - dp1 * duv2.x);
    return mat3(T, B, normal);
}
```

## 5. 屏幕空间反射 (SSR)

文件：`lib/Surface/ScreenSpaceReflections.glsl`

### 5.1 光线行进

```glsl
vec4 ScreenSpaceRayTrace(vec3 viewPos, vec3 viewDir, float dither) {
    vec3 stepVec = viewDir * (0.25 / gbufferProjection[1][1]);
    vec3 rayPos = viewPos;

    for (uint i = 0u; i < RAYTRACE_SAMPLES; ++i, rayPos += stepVec) {
        vec3 screenPos = ViewToScreenSpace(rayPos);
        float depthSample = GetDepthLinear(ivec2(screenPos.xy * viewResolution));
        float currentDepth = -rayPos.z;

        if (abs(depthSample - currentDepth) / currentDepth < 0.2 && depthSample < currentDepth) {
            // 命中，进行二分细化
            #ifdef RAYTRACE_REFINEMENT
                for (uint j = 0u; j < 6u; ++j) {
                    stepVec *= 0.5;
                    if (depthSample < currentDepth) rayPos -= stepVec;
                    else rayPos += stepVec;
                    depthSample = GetDepthLinear(ivec2(ViewToScreenSpace(rayPos).xy * viewResolution));
                    currentDepth = -rayPos.z;
                }
            #endif
            return vec4(texture(colortex4, screenPos.xy).rgb, 1.0);
        }
    }
    return vec4(0.0);  // 未命中
}
```

- 默认 16 步，可选 4~512 步
- 步长自适应于投影矩阵
- 6 步二分细化，精度提升 64 倍
- 支持 Distant Horizons 深度缓冲

### 5.2 GGX VNDF 重要性采样

对于粗糙表面，使用 GGX VNDF 采样微表面法线：

```glsl
vec3 sampleGGXVNDF(vec3 viewDir, float roughness, vec2 xy) {
    xy.y = clamp(xy.y * 0.25, 1e-3, 0.25);  // SPECULAR_TAIL_CLAMP
    viewDir = normalize(vec3(roughness * viewDir.xy, viewDir.z));
    // ... 半球采样 ...
    return normalize(vec3(roughness * halfway.xy, halfway.z));
}
```

### 5.3 反射合成

1. **屏幕空间命中**：优先采样 `colortex4`（已光照场景）
2. **天空反射回退**：未命中时采样预计算天空盒
3. **日月反射**：额外叠加太阳/月亮盘面反射
4. **菲涅尔混合**：`reflection * specular` 作为反射贡献

## 6. 反射滤波

文件：`lib/Surface/ReflectionFilter.glsl`

### 6.1 双边滤波

```glsl
vec4 ReflectionFilter(sampler2D tex, ivec2 texel, Material material) {
    vec4 result = vec4(0.0);
    float totalWeight = 0.0;

    for (int i = -1; i <= 1; i++) {
        for (int j = -1; j <= 1; j++) {
            vec4 sampleData = texelFetch(tex, texel + ivec2(i, j), 0);
            float normalWeight = pow16(max0(dot(prevNormal, normal)));
            float depthWeight = exp2(-abs(sampleDepth - depth) * 64.0 / depth);
            float spatialWeight = exp2(-dotSelf(vec2(i, j)) * 0.1);
            float weight = normalWeight * depthWeight * spatialWeight;
            result += sampleData * weight;
            totalWeight += weight;
        }
    }
    return result / totalWeight;
}
```

三重权重：
- **法线权重**：`pow16(dot(N1, N2))`，法线越接近权重越大
- **深度权重**：`exp2(-|Δz| * 64/z)`，深度越接近权重越大
- **空间权重**：`exp2(-|offset|² * 0.1)`，距离越近权重越大

### 6.2 亮度-色度分离锐化

滤波前后在亮度空间进行锐化，避免色彩偏移。

## 7. 雨天湿润效果

文件：`lib/Surface/RainEffect.glsl`

### 7.1 湿度分布

```glsl
float wetnessDistribution = texture(noisetex, worldPos.xz * 0.01).r;
wetnessDistribution = wetnessDistribution * 0.5 + 0.5;
wetnessDistribution *= wetnessCustom;
```

使用噪声纹理生成非均匀的湿度分布。

### 7.2 反照率变暗

```glsl
#ifdef RAIN_PUDDLES
    float porosity = 1.0 - material.f0;  // 多孔性
    albedo *= 1.0 - wetness * porosity * 0.3;
#endif
```

多孔材质（如石头）在湿润时反照率降低，模拟水分吸收。

### 7.3 高光增强

```glsl
material.roughness = mix(material.roughness, 0.0, wetness * 0.8);
material.f0 = mix(material.f0, 0.02, wetness * 0.5);
```

湿润表面变得更光滑（粗糙度降低），F0 增加（水膜反射）。

### 7.4 表面方向依赖

```glsl
float surfaceSlope = 1.0 - max0(normal.y);  // 法线朝上时为 0
wetness *= 1.0 - surfaceSlope * 0.5;  // 垂直表面湿度降低
```

水平表面（如地面）湿度最高，垂直表面（如墙壁）湿度较低。

### 7.5 雨滴飞溅法线

```glsl
vec2 GetRainNormal(vec3 position) {
    pos *= 0.6;
    pos.x = (pos.x + floor(fract(frameTimeCounter) * 64.0)) / 64.0;  // 64 帧动画
    vec2 normal = texture(tex, pos).rg * 2.0 - 1.0;
    normal /= 1.0 + lod;  // LOD 衰减
    return normal * 0.75;
}
```

使用 `RippleNormal.png` 作为 64 帧动画法线纹理。

## 8. 折射实现

文件：`lib/Surface/Refraction.glsl`

### 8.1 水体折射

```glsl
vec3 wavesNormal = GetWavesNormal(worldPos.xz - worldPos.y).xzy;
refractCoord = nv.xy - wavesNormalView.xy;
refractCoord *= saturate(refractionDepth) * 0.5 / (waterDepth + 1e-4);
refractCoord += screenCoord;
```

使用水面波浪法线的 XY 分量作为折射偏移方向。

### 8.2 玻璃折射

```glsl
vec3 refractDir = fastRefract(normalize(viewPos), normal, 1.0 / GLASS_REFRACT_IOR);
refractDir /= saturate(dot(refractDir, -normal));
refractDir *= saturate(refractionDepth * 2.0) * 0.25;
```

使用 Snell 定律的精确折射计算。

### 8.3 光线追踪折射（可选）

启用 `RAYTRACED_REFRACTION` 后，使用与 SSR 相同的屏幕空间光线追踪。支持 `REFRACTIVE_DISPERSION`（色散），RGB 三通道使用不同 IOR。

## 9. 植物动画

在 `Terrain.vert` 中，对材质 ID 1-5 的植物和 ID 7 的树叶进行顶点摆动：

```glsl
if (materialIDs >= 1u && materialIDs <= 5u) {
    float windStrength = mcLightmap.g * 0.2;  // 天空光照驱动
    float height = max0(position.y - 0.5);     // 高度驱动
    vec2 wind = vec2(sin(worldTimeCounter * 2.0 + position.x * 0.5),
                     cos(worldTimeCounter * 1.5 + position.z * 0.5));
    position.xz += wind * windStrength * height;
}
```

- 天空光照越强，摆动越大（露天区域）
- 越高的顶点摆动越大
- 雨天时摆动增强

## 10. BRDF 实现

文件：`lib/Surface/BRDF.glsl`

### 10.1 菲涅尔

三种实现：
1. **Schlick 近似**：`F = f0 + (1-f0) * (1-cosθ)^5`
2. **精确电介质菲涅尔**（基于 f0）
3. **精确电介质菲涅尔**（基于 IOR），处理全内反射

### 10.2 GGX 法线分布

```glsl
float DistributionGGX(float NdotH, float alpha2) {
    return alpha2 * rPI / sqr(1.0 + (NdotH * alpha2 - NdotH) * NdotH);
}
```

### 10.3 Smith GGX 几何遮蔽

```glsl
float V2SmithGGX(float NdotV, float NdotL, float alpha2) {
    float ggxl = NdotL * sqrt(alpha2 + (NdotV - NdotV * alpha2) * NdotV);
    float ggxv = NdotV * sqrt(alpha2 + (NdotL - NdotL * alpha2) * NdotL);
    return 0.5 / (ggxl + ggxv);
}
```

### 10.4 Hammon 漫反射

```glsl
vec3 DiffuseHammon(LdotV, NdotV, NdotL, NdotH, roughness, albedo) {
    float facing = max0(LdotV) * 0.5 + 0.5;
    float singleSmooth = 1.05 * (1 - (1-NdotL)^5) * (1 - (1-NdotV)^5);
    float singleRough = facing * (0.45 - 0.2 * facing) * (rcp(NdotH) + 2.0);
    float single = mix(singleSmooth, singleRough, roughness) * rPI;
    float multi = 0.1159 * roughness;
    return (multi * albedo + single) * NdotL;
}
```

考虑了粗糙表面的次表面多次散射。

## 12. 技术亮点总结

1. **自适应 POM**：60 步光线步进 + 8 步二分细化，在质量和性能间取得平衡。

2. **GGX VNDF 重要性采样**：使用 2023 年的最新采样方法，配合 SPECULAR_TAIL_CLAMP 抑制噪点。

3. **三重权重反射滤波**：法线 + 深度 + 空间三重权重，保持边缘清晰的同时平滑噪声。

4. **颜色空间矿石检测**：通过颜色通道对比度自动识别矿石，兼容未打标的资源包。

5. **多孔性驱动的湿润效果**：基于 F0 的多孔性模型，不同材质湿润程度不同。

6. **Hammon 漫反射 BRDF**：比 Lambert 更准确的粗糙表面漫反射模型。

7. **精确菲涅尔**：使用完整 Fresnel 方程而非 Schlick 近似，保证掠射角物理正确性。

8. **距离自适应波浪**：通过屏幕空间导数自动衰减远处波浪，无需手动 LOD。
