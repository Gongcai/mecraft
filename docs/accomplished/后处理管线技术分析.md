# 后处理管线 (Post-Processing Pipeline)

## 概述

DerivativeMain 的后处理管线由多个阶段组成，依次为：景深 (DoF)、时间抗锯齿 (TAA)、运动模糊 (Motion Blur)、Bloom 下采样与模糊链、最终色调映射与色彩分级 (Grade)、锐化与抖动输出 (Final)。整个管线使用 `colortex0`-`colortex7` 多个浮点纹理作为中间缓冲，最终写入 `colortex3` 输出到屏幕。

---

## 1. 色调映射 (Tone Mapping)

色调映射在 `Grade.glsl` 中通过宏 `TONEMAP` 选择，提供四种实现：`AcademyFit`、`AcademyFull`、`AgX_Minimal`、`AgX_Full`，默认为 `AcademyFit`。

### 1.1 ACES 实现 (`lib/Post/ACES.glsl`)

#### 1.1.1 AcademyFit (简化版)

`AcademyFit` 是经过简化的 ACES 色调映射，使用多项式拟合替代完整的 RRT+ODT 流程：

1. **亮度缩放**：输入乘以 1.4 的曝光系数
2. **RRT 甜化器 (Sweeteners)**：
   - **Glow 模块**：根据饱和度和亮度代理值 `YC` 计算增益
   - **红色修正**：对色相在 0 度附近的高饱和红色区域进行修正
   - **AP0 到 AP1 色彩空间转换**
   - **全局去饱和**：以 0.96 的因子混合亮度与原始颜色
3. **RRTAndODTFit**：使用 MJP 的多项式拟合将 HDR 值映射到 [0,1] 范围
4. **ODT 去饱和**：以 0.93 的因子再次去饱和

#### 1.1.2 AcademyFull (完整版)

`AcademyFull` 实现了完整的学院管线：

1. **sRGB 到 ACES AP0 转换**
2. **RRT (参考渲染转换)**：使用分段样条 `segmented_spline_c5_fwd`
3. **ODT (输出设备转换)**：使用 9 段样条 `segmented_spline_c9_fwd`
4. **暗环绕到暗环境补偿**
5. **D60 到 D65 色温适应转换 (CAT)**

### 1.2 AgX 实现 (`lib/Post/AgX.glsl`)

#### 1.2.1 AgX_Minimal (简化版)

1. **输入矩阵变换**：使用 AgX 专用的 3x3 矩阵，乘以 8.0 的曝光增益
2. **Log2 编码**：`clamp(log2(val), -8.0, 6.0)`，归一化到 [0,1]
3. **S 曲线拟合**：使用 7 阶多项式（均方误差 1.86e-06）
4. **逆矩阵变换**恢复到 sRGB 线性空间

#### 1.2.2 AgX_Full (完整版)

1. **sRGB 到 Rec.2020 转换**
2. **原色压缩**：通过对 sRGB 原色在 CIE xy 色度图上的旋转和缩放
3. **双曲线色调曲线**：分离 toe (power=3.0) 和 shoulder (power=3.25) 部分
4. **Rec.2020 到 sRGB 转换**

### 1.3 色彩分级管线 (`#ifdef COLOR_GRADING`)

所有色调映射器共享统一的色彩分级流程：

- **对比度**：基于 log2 空间的中点缩放
- **亮度**：乘以 `BRIGHTNESS` 参数
- **伽马**：`pow(color, rcp(GAMMA))`
- **饱和度**：以亮度为锚点混合
- **白平衡**：使用 Bradford 色适应变换

## 2. 景深 (Depth of Field) - `DoF.glsl`

### 2.1 物理模型

基于薄透镜模型的 Circle of Confusion (CoC) 计算：

```
CoC = (1 - p/z) * a * f / (p - f)
```

其中 `p` 为对焦距离，`z` 为像素深度，`a` 为光圈直径，`f` 为焦距。

### 2.2 对焦模式

- **自动对焦** (`FOCUS_MODE=0`)：使用 `centerDepthSmooth`，通过指数平滑混合
- **手动对焦** (`FOCUS_MODE=1`)：用户指定距离

### 2.3 采样策略

- 使用 **Golden Angle 旋转**进行螺旋采样
- **蓝噪声抖动**：基于 R1 准随机序列
- **非均匀采样分布**：`sqrt((noise + i) / samples)` 产生从中心向外扩散的分布
- 默认 48 个采样点

### 2.4 变形镜头模拟

`DOF_ANAMORPHIC_RATIO` 控制水平/垂直散景比例，产生椭圆形散景。

### 2.5 倍率色差 (Magnification CA)

RGB 通道使用不同偏移进行采样，偏移量与像素到屏幕中心的距离成正比。

---

## 3. 运动模糊 (Motion Blur) - `MotionBlur.glsl`

### 3.1 速度计算

速度向量存储在 `colortex2.xy` 中，由 `Temporal.frag` 计算。

### 3.2 模糊实现

1. **速度缩放**：对高速运动进行非线性压缩防止过度模糊
2. **交错梯度噪声抖动**：用于采样起始点的抖动
3. **采样**：沿速度方向均匀采样 `MOTION_BLUR_SAMPLES` 次（默认 6 次）
4. **边界钳制**：防止越界

---

## 4. 时间抗锯齿 (TAA) - `Temporal.frag` / `Temporal.vert`

### 4.1 曝光计算 (`Temporal.vert`)

- **自动曝光**：遍历低分辨率 mipmap 层，计算加权平均对数亮度
- 变暗速度 (1.5x) 快于变亮速度 (1.0x)，模拟人眼特性

### 4.2 速度缓冲计算 (`Temporal.frag`)

1. **最近片段搜索**：3x3 邻域中找到深度最小的像素
2. **速度计算**：当前像素位置与重投影位置的差值

### 4.3 时间重投影 (`TemporalReprojection`)

1. **YCoCgR 色彩空间**：亮度和色度分离处理
2. **方差裁剪**：3x3 邻域均值和方差，裁剪历史帧到 AABB 包围盒
3. **锐化重投影**：CatmullRom 快速近似插值
4. **Reinhard 域混合**：在压缩亮度域中混合避免闪烁

---

## 5. Bloom 实现

### 5.1 下采样链 (`DownSample0.glsl`)

初始下采样：使用 2x2 box filter 将全分辨率下采样到多个 mip level。

### 5.2 高斯模糊 (`BlurH.glsl` / `BlurV.glsl`)

可分离的双向高斯模糊，使用 9-tap 核，权重为二项式分布。

### 5.3 多级下采样 (`DownSample.glsl`)

为 LOD 1-7 分别执行下采样，使用 tiled mipmap 方案将所有级别打包到单个纹理。

### 5.4 上采样与合成 (`Grade.glsl`)

- **Bloom 权重**：LOD 1-7 递减
- **雾 Bloom 权重**：LOD 1-7 递增，专门用于大气散射和雾效的光散射模拟
- **曝光补偿**：防止暗场景 Bloom 过强

---

## 6. 最终输出 (Final.glsl)

### 6.1 CAS 锐化

实现 AMD FidelityFX CAS（Contrast Adaptive Sharpening）。

### 6.2 抖动 (Dithering)

Bayer 16x16 有序抖动，幅度为 `1/255`，消除色带伪影。

---

## 7. 色彩空间转换

管线中涉及多次色彩空间转换：

| 转换 | 用途 |
|------|------|
| sRGB Linear / sRGB | 伽马编码/解码 |
| RGB / XYZ | 白平衡和色度操作 |
| AP0 / AP1 | ACES 色彩空间转换 |
| RGB / YCoCgR | TAA 中的亮度/色度分离 |
| sRGB / Rec.2020 | AgX Full 的色域扩展 |

---

## 8. 噪声与抖动技术

- **Bayer 有序抖动矩阵**：从 2x2 递归构建到 64x64
- **蓝噪声时间抖动**：R1 准随机序列与噪声纹理组合
- **交错梯度噪声 (IGN)**：用于运动模糊的采样抖动
- **哈希函数**：`triple32` 使用三轮位移和乘法的高质量整数哈希

---

## 9. 独特技术与设计亮点

### 9.1 Purkinje 偏移

在暗环境下模拟人眼的 Purkinje 效应：杆状细胞在暗视觉下对蓝绿光更敏感。

### 9.2 双 Bloom 通道设计

- **标准 Bloom**：权重随 LOD 递减
- **雾 Bloom**：权重随 LOD 递增，专门用于大气散射和雾效

### 9.3 21:9 宽银幕模式

通过 step 函数在上下边缘添加黑色遮幅。

### 9.4 自适应曝光的非对称速度

变暗时 `speed = 1.5`，变亮时 `speed = 1.0`，模拟人眼生理特性。

### 9.5 TAA 中的 Reinhard 域混合

在 Reinhard 压缩亮度域中进行时间混合，避免 HDR 亮度值上的过曝或闪烁。

### 9.6 Bloom 图块布局优化

使用 Spectrum 着色包的图块偏移算法，将 7 个 LOD 级别紧凑地打包到单个纹理中。

---

## 管线流程总结

```
场景渲染 (colortex4/colortex5)
    |
    v
[TAA] Temporal.frag -- 速度缓冲(colortex2) + 时间重投影(colortex5)
    |
    v
[DoF] DoF.glsl -- 物理散景 + 倍率色差 -> colortex4
    |
    v
[Motion Blur] MotionBlur.glsl -- 基于速度缓冲的定向模糊 -> colortex2
    |
    v
[Bloom Down] DownSample0 -> BlurH/BlurV -> DownSample -> colortex4 (多LOD)
    |
    v
[Grade] Grade.glsl -- Bloom合成 + Purkinje + 曝光 + 色调映射 + 色彩分级 -> colortex3
    |
    v
[Final] Final.glsl -- CAS锐化 + Bayer抖动 -> 屏幕输出
```

### 纹理分配

| 纹理 | 格式 | 用途 |
|------|------|------|
| `colortex0` | RGBA16F | 场景数据 (法线、深度等) |
| `colortex1` | RGBA16F | 场景数据 |
| `colortex2` | RGBA16F | 速度缓冲 / 运动模糊输出 |
| `colortex3` | RGBA16 | 最终输出 (Final pass 写入) |
| `colortex4` | R11F_G11F_B10F | Bloom 图块 / DoF 中间缓冲 |
| `colortex5` | RGBA16F | TAA 历史帧 / 曝光 / 对焦深度 |
| `colortex6` | RGB8 | 雾透射率 |
| `colortex7` | RGB8 | 附加数据 |
