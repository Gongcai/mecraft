# 水体渲染系统 (Water Rendering System)

## 1. 概述

DerivativeMain 的水体渲染系统是一套多阶段、多层次的管线，涵盖从顶点级别的海浪位移到片段级别的法线计算、菲涅尔反射、屏幕空间折射/反射、水下体积光和雾效等功能。系统同时支持 **PhysicsOceans 模组兼容**（基于 Gerstner 波的物理海浪）和**内置噪声波浪**两种模式，并通过材质 ID（`materialID == 17u`）在渲染管线中区分水体与其他半透明材质（`TranslucentMask` 结构体中的 `mask.water`、`mask.ice`、`mask.stainedGlass`）。

## 2. 水面波浪模拟

### 2.1 PhysicsOceans 物理海浪（Gerstner 波变体）

文件：`lib/Water/PhysicsOceans.glsl`

这是对 afl_ext 的 Physics Mod 的着色器端实现，采用**迭代式非线性叠加**方法，而非经典线性 Gerstner 波。核心函数 `physics_waveHeight()` 的工作原理：

```
for each iteration i:
    direction = vec2(sin(iter), cos(iter))     // 伪随机方向
    x = dot(direction, position) * frequency + time * speed
    wave = exp(sin(x) - 1.0)                   // 非线性波形压缩
    result = wave * cos(x)
    force = result * weight * direction
    position -= force * PHYSICS_DRAG_MULT       // 位置拖拽（非线性反馈）
    height += wave * weight
    weight *= PHYSICS_WEIGHT                    // 0.8 衰减
    frequency *= PHYSICS_FREQUENCY_MULT         // 1.18 频率递增
    speed *= PHYSICS_SPEED_MULT                 // 1.07 速度递增
```

关键特性：
- **迭代次数可控**：顶点阶段使用 `PHYSICS_ITERATIONS_OFFSET = 13`，片段阶段使用 `physics_iterationsNormal`（13~48，对应用户设置中的 Surface Detail）
- **频率/速度/权重的几何级数递增**，产生从低频大浪到高频细节的自然频谱分布
- **位置拖拽**（`PHYSICS_DRAG_MULT = 0.048`）：每次迭代将采样点位置沿波浪力方向偏移，产生非线性波形折叠效果
- **waviness 纹理**：通过 `physics_waviness` 采样纹理确定海岸线附近的浅水区衰减因子 `factor`，实现波浪从深水到岸边的自然衰减

`physics_wavePixel()` 是片段阶段的完整计算入口，返回 `WavePixelData` 结构体，包含：
- `direction`：波浪水平位移方向
- `worldPos`：经波浪偏移后的世界坐标
- `height`：波浪高度
- `normal`：包含涟漪的最终法线
- `foam`：浪花强度

### 2.2 内置噪声波浪（WaterHeight）

文件：`lib/Water/WaterWave.glsl`

当 PhysicsOceans 模组不可用时，使用基于噪声纹理的四层叠加波浪：

```glsl
float WaterHeight(vec2 p) {
    wave += textureSmooth((p + vec2(0.0, p.x - wavesTime)) * 0.8);
    wave += textureSmooth((p - vec2(-wavesTime, p.x)) * 1.6) * 0.5;
    wave += textureSmooth((p + vec2(wavesTime*0.6, p.x - wavesTime)) * 2.4) * 0.2;
    wave += textureSmooth((p - vec2(wavesTime*0.6, p.x - wavesTime)) * 3.6) * 0.1;
    // 距离衰减:
    return wave / (0.8 + dot(abs(dFdx(p) + dFdy(p)), vec2(80.0 / far)));
}
```

- 使用 `textureSmooth()` 函数对 Minecraft 的 `noisetex` 进行 Hermite 插值（`curve(x) = x*x*(3-2*x)`），避免硬边界
- 四层分别使用 0.8/1.6/2.4/3.6 的缩放和 1.0/0.5/0.2/0.1 的权重，构成伪分形布朗运动
- 通过屏幕空间导数 `dFdx/dFdy` 实现**距离自适应衰减**：远处波浪自动降低幅度，避免摩尔纹
- 支持 Distant Horizons 模组（`DISTANT_HORIZONS` 宏），使用 `dhFarPlane` 替代 `far` 进行衰减计算
- 波浪速度由 `WATER_WAVE_SPEED` 设置控制，波浪高度由 `WATER_WAVE_HEIGHT` 控制

## 3. 水面法线计算

### 3.1 内置波浪法线

`GetWavesNormal()` 通过中心差分法计算法线：

```glsl
vec3 GetWavesNormal(vec2 position) {
    float wavesCenter = WaterHeight(position);
    float wavesLeft   = WaterHeight(position + vec2(0.04, 0.0));
    float wavesUp     = WaterHeight(position + vec2(0.0, 0.04));
    vec2 wavesNormal = vec2(wavesCenter - wavesLeft, wavesCenter - wavesUp);
    return normalize(vec3(wavesNormal * WATER_WAVE_HEIGHT, 0.5));
}
```

- 步长为 0.04（世界坐标单位），XY 分量由高度差乘以 `WATER_WAVE_HEIGHT` 缩放
- Z 分量固定为 0.5，作为法线强度的基准

### 3.2 水面视差（Water Parallax）

当启用 `WATER_PARALLAX` 时，使用视差映射增强波浪的立体感：

```glsl
vec2 GetWaterParallaxCoord(vec3 position, vec3 tangentViewVector) {
    // 步进式视差
    for (uint i = 0u; sampleHeight < samplePos.z && i < 60u; ++i) {
        samplePos += stepSize;
        sampleHeight = WaterHeight(samplePos.xy);
    }
    return samplePos.xy;
}
```

- 最多 60 步迭代，从切线空间视角方向步进直到找到波浪高度交点
- 使用修正后的 UV 坐标重新采样 `GetWavesNormal()`，使法线贴图与波浪几何形状一致

### 3.3 PhysicsOceans 法线 + 涟漪

`physics_waveNormal()` 函数结合了两种法线：
1. **波浪法线**：由 `physics_waveDirection()` 返回的水平位移方向经 `oceanHeightFactor` 缩放后构建
2. **涟漪法线**：从 `physics_ripples` 纹理（由 CPU 端物理模组生成的 bump map）通过中心差分计算

```glsl
vec3 rippleNormal = normalize(vec3(left - right, 1.0, top - bottom));
return normalize(mix(waveNormal, rippleNormal, pow(totalEffect, 0.5)));
```

混合权重为涟漪纹理总采样值的平方根，涟漪越强越偏向涟漪法线。

### 3.4 雨滴涟漪法线

文件：`lib/Surface/RainEffect.glsl`

`GetRainNormal()` 从 `colortex7`（绑定到 `RippleNormal.png` 纹理）采样雨滴动画法线：

```glsl
vec2 GetRainNormal(vec3 position) {
    pos *= 0.6;
    pos.x = (pos.x + floor(fract(frameTimeCounter) * 64.0)) / 64.0;  // 64 帧动画
    vec2 normal = texture(tex, pos).rg * 2.0 - 1.0;
    normal /= 1.0 + lod;  // LOD 衰减
    return normal * 0.75;
}
```

- 使用 `RippleNormal.png` 作为 64 帧动画纹理，通过 `frameTimeCounter` 驱动帧索引
- LOD 由 `fwidth(position)` 计算，远处自动降低法线强度
- 在 `Water.frag` 中仅当 `wetnessCustom > 1e-2` 且天空光照充足时叠加到水面法线上

## 4. 水面 BRDF 与菲涅尔

### 4.1 菲涅尔方程

文件：`lib/Surface/BRDF.glsl`

水面使用精确的**电介质-电介质菲涅尔**方程 `FresnelDielectricN()`，而非 Schlick 近似：

```glsl
float FresnelDielectricN(float cosTheta, float n) {
    float cosR = sqr(n) + sqr(cosTheta) - 1.0;
    if (cosR < 0.0) return 1.0;  // 全反射
    cosR = sqrt(cosR);
    float a = n * cosTheta;
    float b = n * cosR;
    float r1 = (a - cosR) / (a + cosR);
    float r2 = (b - cosTheta) / (b + cosTheta);
    return saturate(0.5 * (r1 * r1 + r2 * r2));
}
```

- IOR 默认 `WATER_REFRACT_IOR = 1.33`，可通过设置调整（0.1~1.6）
- 水下视角时使用 `1.0 / WATER_REFRACT_IOR` 作为 IOR，并检测全反射条件
- 输出 `vec4(reflection * specular, 1.0 - specular)`，alpha 通道存储透射率，用于后续混合

### 4.2 GGX VNDF 重要性采样

`sampleGGXVNDF()` 函数实现了 2023 年的 GGX VNDF 采样方法，用于粗糙反射的方向采样：

```glsl
vec3 sampleGGXVNDF(vec3 viewDir, float roughness, vec2 xy) {
    xy.y = clamp(xy.y * 0.25, 1e-3, 0.25);  // SPECULAR_TAIL_CLAMP
    viewDir = normalize(vec3(roughness * viewDir.xy, viewDir.z));
    // ... 半球采样 ...
    return normalize(vec3(roughness * halfway.xy, halfway.z));
}
```

`SPECULAR_TAIL_CLAMP` 将采样的 Y 分量钳制在 `[0, 0.25]`，抑制高粗糙度下的噪点尾巴。

## 5. 屏幕空间反射（SSR）

文件：`lib/Surface/ScreenSpaceReflections.glsl`

### 5.1 光线行进

`ScreenSpaceRayTrace()` 实现了 Hi-Z 风格的屏幕空间光线追踪：

- **步长自适应**：根据深度差动态调整步长 `stepLength = abs(depth - rayPos.z) * stepWeight`
- **命中判定**：使用线性深度比较，阈值为 `abs(linearSample - currentDepth) / currentDepth < 0.2`
- **二分细化**（`RAYTRACE_REFINEMENT`）：命中后进行 6 步二分搜索精确定位交点，性能开销极低
- 支持 Distant Horizons 深度缓冲（`ScreenSpaceRayTraceDH`）
- 默认 16 步，可选 4~512 步（`RAYTRACE_SAMPLES`）

### 5.2 反射合成

`CalculateSpecularReflections()` 在 `Water.frag` 中执行：

1. **屏幕空间命中**：优先采样 `colortex4`（场景颜色缓冲）
2. **天空反射回退**：未命中时采样预计算天空盒 `colortex5`，通过 `ProjectSky()` 投影到球面坐标
3. **日月反射**：`REAL_SKY_REFLECTION` 模式下额外叠加太阳/月亮盘面反射
4. **水下回退**：水下时使用青色 `vec3(0.05, 0.7, 1.0)` 作为反射颜色
5. **维度适配**：末地使用独立的反射颜色方案，支持 `DARK_END` 变体

### 5.3 反射滤波

文件：`lib/Surface/ReflectionFilter.glsl`

`ReflectionFilter()` 对粗糙表面的反射进行空间滤波：

- 8 邻域加权采样，权重由法线相似度、深度连续性和反射强度共同决定
- 使用**亮度-色度分离**的锐化策略：先转换到亮度空间锐化，滤波后再转换回来
- `coordOffset` 由粗糙度、深度和反射强度共同控制采样范围

在 `composite1.fsh` 中，反射数据最终与场景颜色混合：
```glsl
sceneData = sceneData * reflectionData.a + reflectionData.rgb;
```
其中 `reflectionData.a = 1.0 - specular`（透射率），`reflectionData.rgb` 为反射颜色。

## 6. 折射实现

文件：`lib/Surface/Refraction.glsl`

### 6.1 非光线追踪模式（默认）

`CalculateRefractCoord()` 对水体和玻璃分别处理：

**水体折射**：
```glsl
vec3 wavesNormal = GetWavesNormal(worldPos.xz - worldPos.y).xzy;
vec3 waterNormal = mat3(gbufferModelView) * wavesNormal;
refractCoord = nv.xy - wavesNormalView.xy;
refractCoord *= saturate(refractionDepth) * 0.5 / (waterDepth + 1e-4);
refractCoord += screenCoord;
```

- 使用水面波浪法线的 XY 分量作为折射偏移方向
- 偏移量与水体深度和不透明物体深度差成正比
- 最终通过深度测试验证折射坐标的有效性（防止采样到水面之前的物体）

**玻璃折射**：
```glsl
vec3 refractDir = fastRefract(normalize(viewPos), normal, 1.0 / GLASS_REFRACT_IOR);
refractDir /= saturate(dot(refractDir, -normal));
refractDir *= saturate(refractionDepth * 2.0) * 0.25;
```

- 使用 Snell 定律的精确折射计算 `fastRefract()`
- 折射方向归一化后按深度缩放

### 6.2 光线追踪模式（可选）

启用 `RAYTRACED_REFRACTION` 后，使用与 SSR 相同的屏幕空间光线追踪精确定位折射采样点。还支持 `REFRACTIVE_DISPERSION`（色散），对 RGB 三通道使用不同 IOR（1.45/1.5/1.55）分别追踪。

### 6.3 Distant Horizons 支持

提供 `CalculateRefractCoordDH()` 变体，使用 `dhDepthTex1` 和 `GetDepthLinearDH()` 处理远距离地形的折射。

## 7. 水雾与深度效果

### 7.1 水体雾（WaterFog）

文件：`lib/Water/WaterFog.glsl`

`WaterFog()` 处理从水面上方看向水底时的雾效：

```glsl
void WaterFog(inout vec3 color, TranslucentMask mask, float waterSkylight, float LdotV, float waterDepth) {
    float fogDensity = mix(WATER_FOG_DENSITY * fma(0.1, wetness*fix, 0.16), 0.5, mask.ice) * waterDepth;
    vec3 waterFogColor = mix(skyIlluminance * 0.4, vec3(luminance * 0.1), 0.8*wetness*fix) * rPI;
    float scatter = HenyeyGreensteinPhase(LdotV, 0.65) + 0.1 * rPI;
    waterFogColor *= 1.0 + 28.0 * oneMinus(wetness*0.8) * directIlluminance * scatter;
    vec3 transmittance = fastExp(-(waterAbsorption * 8.0 + 0.03) * fogDensity);
    color *= transmittance;
    color += waterFogColor * waterSkylight * oneMinus(transmittance);
}
```

关键物理模型：
- **Beer-Lambert 吸收衰减**：`fastExp(-(waterAbsorption * 8.0 + 0.03) * fogDensity)`，使用预设的 RGB 吸收系数
- **Henyey-Greenstein 相位函数**：`HenyeyGreensteinPhase(LdotV, 0.65)`，模拟水中前向散射
- **天空光照调制**：雾色受 `skyIlluminance` 和天空光照图控制
- **天气影响**：雨天时水雾颜色偏暗（`wetnessCustom` 混合），密度增加
- **冰面覆盖**：冰的雾密度更高（`0.5` 替代 `WATER_FOG_DENSITY`）

### 7.2 水下雾（UnderwaterFog）

```glsl
void UnderwaterFog(inout vec3 color, TranslucentMask mask, float waterDepth) {
    float fogDensity = mix(WATER_FOG_DENSITY * fma(0.05, wetness*fix, 0.1), 0.5, mask.ice) * waterDepth;
    vec3 transmittance = fastExp(-(waterAbsorption * 8.0 + 0.03) * max(fogDensity, 2.0) + 0.4);
    color *= transmittance;
    color += waterFogColor * saturate(eyeSkylightFix + 0.2) * oneMinus(transmittance);
}
```

- 水下雾的最小密度为 `2.0`，确保即使很近处也有水下感
- 雾色受 `eyeSkylightFix` 控制（水面以上天空光占比），反映水面深度对光线的遮挡
- `+0.4` 偏移使衰减曲线在近处更柔和

### 7.3 水体吸收系数

`waterAbsorption` 是 CPU 端传递的 `uniform vec3`，代表 RGB 三通道的吸收系数。在 `fastExp()` 中使用 `exp2(x * rLOG2)` 实现高效指数运算。标准纯水对红光吸收最强、蓝光最弱，因此远距离水体呈现蓝绿色。

## 8. 水下体积光

文件：`lib/Atmosphere/VolumetricFog.glsl`

`UnderwaterVolumetricLight()` 实现水下光束效果：

```glsl
vec3 UnderwaterVolumetricLight(vec3 worldPos, vec3 worldDir, float dither) {
    // 12~22 步阴影采样
    const vec3 coeff = waterAbsorption + 0.02;
    vec3 stepTransmittance = fastExp(-coeff * stepLength);

    // 阴影贴图采样 + 水深衰减
    float waterDepth = abs(shadowcolor1.w * 512.0 - 128.0 - shadowPosition.y - eyeAltitude);
    sampleShadow *= fastExp(-coeff * 0.4 * max(waterDepth, 8.0));

    // 折射光方向 + Henyey-Greenstein 相位函数
    vec3 lightVector = refract(worldLightVector, vec3(0, -1, 0), 1.0 / WATER_REFRACT_IOR);
    float phase = HenyeyGreensteinPhase(LdotV, 0.8) + HenyeyGreensteinPhase(LdotV, 0.6);

    fogColor = 8.0 / coeff * directIlluminance * scattering * phase;
}
```

- 通过阴影贴图追踪光线在水中的传播
- `waterDepth` 从 `shadowcolor1.w` 中解码（存储为 `minecraftPos.y * rcp(512.0) + 0.25`）
- 使用双 Henyey-Greenstein 相位函数（`0.8` 和 `0.6` 双峰）模拟水中光束的散射特性
- 折射光方向使用 `WATER_REFRACT_IOR` 计算，模拟阳光进入水面后的弯曲

## 9. 水下焦散（Caustics）

文件：`program/Shadow/Shadow.frag`

在阴影贴图的渲染阶段，水面像素会计算焦散图案：

```glsl
#ifdef WATER_CAUSTICS
    vec3 wavesNormal = GetWavesNormal(minecraftPos.xz - minecraftPos.y);
    vec3 normal = tbnMatrix * wavesNormal;
    vec3 oldPos = viewPos;
    vec3 newPos = oldPos + fastRefract(vec3(0,0,-1), normal, 1.0/WATER_REFRACT_IOR) * 6.0;

    float oldArea = dotSelf(dFdx(oldPos)) * dotSelf(dFdy(oldPos));
    float newArea = dotSelf(dFdx(newPos)) * dotSelf(dFdy(newPos));
    float caustics = inversesqrt(oldArea / newArea) * 0.3;

    shadowcolor0Out = vec3(sqrt2(caustics));
    shadowcolor1Out.w = minecraftPos.y * rcp(512.0) + 0.25;  // 存储水深
#endif
```

原理：
- 将光线方向 `(0,0,-1)` 通过水面法线折射，计算折射后的位置偏移
- 通过 `dFdx/dFdy` 计算折射前后的微分面积比
- **面积收缩 = 焦散聚焦**：`inversesqrt(oldArea / newArea)` 当折射使光束汇聚时值大于 1
- `sqrt2()`（四次根）压缩动态范围
- 结果存储在 `shadowcolor0` 中，在光照阶段通过阴影贴图采样读取

在 `VolumetricFog.glsl` 的水下体积光中，焦散通过阴影颜色采样间接使用：
```glsl
sampleShadow = sqr(cube(texelFetch(shadowcolor0, shadowTexel, 0).rgb));
```

## 10. 浪花（Foam）

文件：`lib/Water/PhysicsOceans.glsl` 中的 `physics_wavePixel()`

```glsl
float waveAmplitude = data.height * pow(max(data.normal.y, 0.0), 4.0);

vec2 s1 = textureLod(physics_foam, vec3(waterUV * 0.26, globalTime / 360.0), 0).rg;
vec2 s2 = textureLod(physics_foam, vec3(waterUV * 0.02, globalTime / 360.0 + 0.5), 0).rg;
vec2 s3 = textureLod(physics_foam, vec3(waterUV * 0.1,  globalTime / 360.0 + 1.0), 0).rg;

float waterSurfaceNoise = s1.r * s2.r * s3.r * 2.8 * physics_foamAmount;
waterSurfaceNoise = (1.0 - waveAmplitude) * waterSurfaceNoise + waveAmplitude * physics_foamAmount;

float worleyNoise = 0.2 + 0.8 * s1.g * (1.0 - s2.g);
waterSurfaceNoise = smoothstep(0.45, 1.0, waterSurfaceNoise) * worleyNoise;
data.foam = clamp(2.0 * waterSurfaceNoise * physics_foamOpacity, 0.0, 1.0);
```

- 使用三层 3D 噪声纹理 `physics_foam`（不同缩放和时间偏移）的乘积
- 波浪振幅越大（`waveAmplitude`），浪花越密集
- Worley 噪声（`s1.g`, `s2.g`）用于打破浪花的均匀性
- `physics_foamAmount` 和 `physics_foamOpacity` 由用户设置控制

## 11. 雨滴涟漪

文件：`lib/Surface/RainEffect.glsl` + `Water.frag`

- `RippleNormal.png` 绑定到 `colortex7`，作为 64 帧动画法线纹理
- `GetRainAnimationTex()` 通过 `fract(frameTimeCounter) * 64.0` 计算当前帧索引
- 在 `Water.frag` 中，雨滴法线仅在以下条件下叠加到水面法线：
  - `wetnessCustom > 1e-2`（正在下雨）
  - `lightmap.y * 10.0 - 9.0 > 0`（天空光照充足，即露天区域）
- 雨滴法线通过 `xy += rainNormal * wetnessCustom * skylightFactor` 直接叠加到切线空间法线上

## 12. 与光照/阴影系统的集成

### 12.1 材质识别

通过 `mc_Entity` 属性识别水方块：
```glsl
materialIDs = max(uint(mc_Entity.x - 1e4), 16u);
```
水的 `materialID = 17`，在 `TranslucentMask` 中对应 `mask.water`。

### 12.2 阴影系统

- **水面阴影**：在 `Shadow.frag` 中，水面像素不丢弃，而是写入焦散数据和法线
- **彩色阴影**：`COLORED_SHADOWS` 启用时，半透明物体的阴影颜色通过 `shadowcolor0` 传递
- **屏幕空间阴影**：`SCREEN_SPACE_SHADOWS` 为水面上方物体提供额外阴影精度
- **水深编码**：`shadowcolor1.w = minecraftPos.y * rcp(512.0) + 0.25` 存储水面 Y 坐标，用于体积光中计算水深

### 12.3 光照计算

在 `deferred5.fsh` 中：
- 水下时天空光照图强制设为 `0.75`（模拟水面上方的天空光衰减）
- 水下阳光被 `waterTint = vec3(0.6, 0.9, 1.2) / max(3.0, opaqueDepth * 0.1 * WATER_FOG_DENSITY)` 调制
- 金属度在水下降低：`isMetal *= 0.2 * smoothstep(0.3, 0.8, mcLightmap.g) + 0.8`

### 12.4 后处理集成

在 `composite1.fsh` 中按顺序处理：
1. 折射坐标计算（采样不透明场景）
2. 彩色玻璃吸收 / 冰面色调调制
3. 反射数据混合（`sceneData = sceneData * (1-specular) + reflection`）
4. 水体雾（水面视角）
5. 水下雾（水下视角）
6. 体积雾/体积光
7. 膨胀雾（Bloom Fog），水下密度为 `0.06 * WATER_FOG_DENSITY`

## 14. 技术亮点与总结

1. **双模式波浪系统**：PhysicsOceans 提供与 CPU 端物理模组同步的高质量 Gerstner 波变体，内置噪声波浪作为轻量级回退方案，两者共享相同的法线计算框架。

2. **焦散的面积比方法**：通过折射前后微分面积的变化来计算焦散强度，这是一种简洁高效的屏幕空间焦散近似，避免了复杂的光路追踪。

3. **层次化折射策略**：默认使用波浪法线偏移的近似折射，可选光线追踪折射和色散，平衡了质量和性能。

4. **精确菲涅尔**：使用完整的 Fresnel 方程而非 Schlick 近似，保证了掠射角附近的物理正确性。

5. **距离自适应波浪**：通过屏幕空间导数自动衰减远处波浪，无需手动 LOD 切换。

6. **多维度适配**：系统完整支持主世界、末地、下界三个维度，以及 Distant Horizons 远景模组。

7. **水下体积光的双重散射模型**：使用双 Henyey-Greenstein 相位函数模拟水中光束的各向异性散射，结合阴影贴图中的焦散数据实现逼真的水下光照。
