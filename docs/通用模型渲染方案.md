# 通用模型渲染方案(OBJ/FBX/glTF 导入与 PBR 展示)

**目的**:在体素世界中渲染通用 PBR 模型资产(Damaged Helmet / Sponza 等),
直观展示渲染管线的技术能力,服务于求职作品集与毕业设计。
**状态**:待启动。**前置条件:Render Graph 落地**(见
`未修复项TODO.md` 第四节第 5 项)——模型渲染的新 pass 直接注册进图,

(2026-07-24 调研定稿)

## 一、现有 PBR 材质链盘点(调研结论)

结论:材质链已是完整的现代延迟管线,加通用模型只需补"资产入口",
光照侧零改动即可全量生效。

### G-buffer 契约(`src/renderer/targets/DeferredRenderTargets.h:291-296`)

| 附件 | 格式 | 内容 |
|---|---|---|
| 0 | RGBA8 | 线性 albedo.rgb + emissive 提示.a |
| 1 | RGBA16F | 世界空间法线.rgb + 顶点 AO.a |
| 2 | RG8 | 天光.r / 方块光.g(体素光照) |
| 3 | RGBA8 | roughness.r + f0.g + emission.b + subsurface.a |
| 4 | RGBA8 | 材质 ID.r + wetness.g + porosity.b + metalness.a |

另有:深度、相机速度(RG16F)、逐物体速度(实体 gbuffer MRT 写入,
供 TAA/FSR 使用)。

### 材质模型

- **LabPBR 约定**:f0 标量 0-229 为电介质、230-255 为金属 ID
  (`chunk_gbuffer.frag:216` 的 229.5/255 smoothstep 即金属判定);
- 方块法线/高光贴图数组:`uBlockNormalTex` / `uBlockSpecularTex`
  (`src/resource/BlockTextureLibrary` 加载);
- 整套管线对齐 Iris shaderpack 契约(代码注释中的 "DerivativeMain"
  colortex/shadowcolor 对应关系)。

### 光照与后处理链(全部已实现)

- BRDF:Cook-Torrance GGX + Schlick Fresnel(`derivative_brdf.glsl`);
- 环境漫反射:天空球谐 `evaluateSkySH` + Fresnel;
- CSM 4 级联,含**彩色透明阴影**(depth-all + shadowcolor0/1);
- SSAO(半分辨率 + 空间滤波 + 时域累积);
- SSGI(带 moments 历史的 SVGF 式降噪);
- **体素 GI clipmap**(`src/renderer/gi/VoxelGiClipmap`,相机中心、
  增量位移更新、多级 mip);
- SSR + 时域;体积雾;程序云;
- 物理大气(256×128×33 预计算 LUT + 带光度元数据的 256×514 天空捕获);
- TAA + FSR 3.1;天气湿度/孔隙度材质响应。

### 现有非地形几何路径(通用网格的接入模板)

- `block_entity_gbuffer_rhi.*` / `block_entity_forward_rhi.*` /
  `block_entity_shadow_rhi.*` 三件套;
- 顶点格式:aPosition/aUv/aNormal + 实例化模型矩阵(iModel0-3)+
  每实例光照 iLight(天光/方块光);
- 已写逐物体速度,TAA/FSR 兼容。

## 二、差距清单(按缺口从大到小)

1. **资产导入库**:vcpkg 当前无任何模型加载库。建议 assimp
   (OBJ/FBX/glTF 全覆盖);轻量替代组合:fastgltf + ufbx +
   tinyobjloader。**格式优先级:glTF 2.0 > OBJ > FBX**——glTF 的
   metallic-roughness 与现有 G-buffer 几乎直接对映,标准展示资产
   (Damaged Helmet / Sponza / Bistro)全有 glTF 版;FBX 为导入完整性。
2. **网格资产系统**:任意 indexed mesh 的 VB/IB 上传与生命周期管理。
   RHI 层已具备全部能力:`drawIndexed`、`generateMipmaps`、bind group。
   现有实体路径为盒体+实例化专用,不可直接复用,但结构可照抄。
3. **切线空间**:实体顶点格式无 tangent。通用网格需 P/N/T/UV 顶点格式 +
   mikktspace 切线生成 + 新 mesh_gbuffer 着色器中做法线贴图
   (地形法线贴图为面对齐 TBN,不通用)。
4. **材质映射**(工作量小):glTF metallic-roughness → 现有编码:
   roughness 直写 material.r;metallic 高于阈值 → f0 编码为金属段
   (230+),否则按 IOR ≈ 0.04 编码;AO → 顶点 AO 通道;
   emissive → emission.b。
5. **管线接入**:新增 `mesh_gbuffer` / `mesh_shadow` pass(照抄
   block_entity 三件套结构),写同一套 MRT + 逐物体速度。**做到即
   全量生效**:CSM、SSAO、SSGI、体素 GI、SSR、体积雾、大气、TAA/FSR
   对模型免费可用(延迟管线红利,亦是展示核心卖点)。
6. **场景放置**:entt 已在依赖中。加 StaticMeshComponent + Transform,
   游戏内命令/UI 放置展示模型。

### 观感提升补充项

- **镜面环境预滤波**:当前镜面环境为 SSR + 天空采样;需确认是否有
  按 roughness 的预滤波。若无,从 sky capture 生成 mip 预滤波链 +
  split-sum BRDF LUT——金属/粗糙度扫描阵列的观感会明显上档次,
  也是面试中最直观的一张图。
- **骨骼动画**(FBX skinning):放 Phase 2,静态网格先落地。
- **网格体素化注入 GI clipmap**(让模型也反弹光):选做,加分项。
