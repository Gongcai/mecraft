### 设计要点

**FrameContext** — 统一帧数据
```cpp

    CameraData camera;
    CameraData prevCamera;
    uint64_t frameIndex;
    float deltaTime;
    glm::vec2 jitter, prevJitter;
    SkyColorsData skyColors;
    SkyIlluminanceData skyIlluminance;

    FogData fog;
    VolumetricData volumetric;

```

**FrameOutput** — 管线输出契约
```cpp
struct FrameOutput {
    GLuint sceneColorTex;
    GLuint sceneDepthTex;
    GLuint gbufferDepthTex;
    GLuint weatherMaskTex;
    bool hasDeferredInputs;
    bool hasDebugView;

```

**RenderPipeline** — 管线接口
```cpp
class RenderPipeline {
public:
    virtual void init(SharedRenderResources& shared) = 0;
    virtual void shutdown() = 0;
    virtual FrameOutput renderFrame(const FrameContext& ctx) = 0;
    virtual const char* name() const = 0;
    virtual bool supportsDeferred() const = 0;
    virtual bool supportsDebugView() const = 0;
};
```

**RenderSettings** — 分层配置
```cpp

## Phase 2：Render target 分层

**目标**：把"前向也要用的资源"和"延迟专属资源"从 `DeferredRenderTargets` 中分离出来。

### 新增文件

| 文件 | 说明 | 实现状态 |
|------|------|----------|
| `src/renderer/targets/CommonFrameTargets.h` | 共享资源：scene color/depth | 完整实现 |
| `src/renderer/targets/CommonFrameTargets.cpp` | | 完整实现 |

| `src/renderer/targets/DeferredFrameTargets.cpp` | | 骨架实现（TODO 标记） |
| `src/renderer/targets/ShadowTargets.h` | 阴影资源：CSM shadow map array | 完整实现 |
| `src/renderer/targets/ShadowTargets.cpp` | | 完整实现 |

### 设计要点

**CommonFrameTargets** — 两条管线共享
- Scene color (RGBA16F HDR)
- Scene depth (DEPTH32F)
- Fullscreen VAO

**DeferredFrameTargets** — 延迟专属
- GBuffer (5 MRT: albedo, normalAo, voxelLight, material, materialAux)
- SSAO (raw, filtered, half-res, temporal, history)
- Scene HDR buffers (lighting, composite, resolved)
- Reflection, Cloud, Velocity, History ping-pong
- Sky capture, Atmosphere LUT

**ShadowTargets** — 阴影资源
- CSM shadow depth array (4 cascade)
- CSM shadow depth comparison view
- CSM transparent shadow (depth-all + color0 + color1)

### 资源对比

| 资源 | 前向管线 | 延迟管线 |
|------|----------|----------|
| GBuffer FBO (5 MRT) | ❌ 不需要 | ✅ |
| CSM Shadow Map | ❌ 不需要 | ✅ |
| SSAO (半分辨率 + temporal) | ❌ | ✅ |
| SSR + Reflection temporal | ❌ | ✅ |
| Volumetric Fog (半分辨率) | ❌ | ✅ |
| TAA (history + velocity) | ❌ | ✅ |
| Sky Capture (256×514) | ⚠️ 可选 | ✅ |
| Scene Lighting/Composite/Resolved | ❌ | ✅ |
| Bloom / exposure mip chain | ✅ 共享 | ✅ 共享 |
| Post-process scene FBO | ✅ | ✅ |
| Terrain mesh (MDI buffer) | ✅ 共享 | ✅ 共享 |

**显存节省**：前向管线不分配延迟管线的 GBuffer/SSAO/SSR/VFog/TAA/History 资源，1080p 下大约节省 ~200-300MB 显存。

## Phase 5：批量 Pass 拆分 — 场景渲染 + 共享后处理

**目标**：从 Renderer 提取场景渲染相关 Pass，并将 PostProcessRenderer 吸收为 RenderScene 共享 Pass。

### 新增文件

| 文件 | 说明 | 来源方法 |
|------|------|---------|
| `src/renderer/passes/DebugPass.h/cpp` | Debug 可视化 Pass，渲染所有中间纹理检查 | `renderDeferredDebugView()` + `renderDeferredDebugOverlay()` |
| `src/renderer/passes/PostProcessPass.h/cpp` | 共享后处理 Pass（bloom/exposure/tonemap/grade/underwater） | 吸收 `PostProcessRenderer` 的全部逻辑 |

### 修改文件

| 文件 | 变更 |
|------|------|
| `src/renderer/core/Renderer.cpp` | `renderDeferredDebugView()` 委托到 `DebugPass::execute()`，移除 `m_deferredDebugShader` |
| `src/renderer/core/Renderer.h` | 移除 `Shader* m_deferredDebugShader` 成员 |
| `src/renderer/core/DeferredPipeline.h/cpp` | 新增 `DebugPass` 生命周期和访问器，注入 `ShadowRenderer` |
| `src/renderer/core/RenderScene.h/cpp` | 新增 `PostProcessPass m_postProcessPass` 成员，init/shutdown 管理 |
| `CMakeLists.txt` | 添加 `DebugPass.cpp` 和 `PostProcessPass.cpp` |

### 设计要点

**DebugPass** — 从 `Renderer::renderDeferredDebugView()` 提取的 ~170 行代码
- 消费 `FrameContext`（camera/sky/weather）和 `RenderSettings`（debug view mode/shadow params）
- 依赖 `ShadowRenderer`（通过 `setShadowRenderer()` 注入）
- 绑定 17 个纹理单元（GBuffer/SSAO/lighting/volumetric/cloud/reflection/shadow/temporal 等）
- 纹理单元 13/14/15 按 debugViewMode 多路复用（materialAux/historyDepth/historyScene/reflection/cloud/composite 等）

**PostProcessPass** — 吸收 `PostProcessRenderer` 的全部后处理逻辑
- 继承 `RenderPass` 基类，归 `RenderScene` 管理而非 `DeferredPipeline`
- 提供**新 API**：`execute(ctx, settings, output, frameTime)` — 从 FrameOutput 读取管线输出
- 提供**Legacy API**：`beginScene()`/`endSceneAndComposite()`/`blitSceneToBackbuffer()` — 兼容当前 Game.cpp 调用
- 内部管理 scene capture FBO、bloom chain（7 mip ping-pong）、auto-exposure chain（13 级 downsample）
- `PostProcessEffects` 结构体保留为 legacy bridge，Phase 10 将替换为 `RenderSettings`

## 事故记录：Pass 拆分后的体积光/水下回归

**时间**：2026-05-26  
**范围**：VolumetricPass / WaterCompositePass / ShadowPass / FrameContext / RenderSettings  
**状态**：已修复，陆上体积光、水下颜色、skylight 和水下体积光已恢复。

### 现象

- 陆上体积雾被点亮，但缺少正确的体积光光束。
- 水下曾缺少水体颜色、固定 skylight、水下雾和 UW_VOLUMETRIC_LIGHT。
- 基础水下链路恢复后，水下体积光仍只显示均匀光圈，遮挡和水面调制失效。

### 根因

- `buildRenderFrameData()` 漏写 `frame.eyeInWater = m_eyeInWater`，新 pass 看到的相机水下状态错误。
- `buildFrameContextFromRenderFrameData()` 只拷贝了部分字段，漏掉 `skyIlluminance`、完整 sky colors、storm、fog、cloud 等数据。
- `RenderSettings` 没完整映射 shadow resolution/distance/cloud shadow 参数，ShadowPass 与 UI/旧管线设置可能不一致。
- `WaterCompositePass` 从 `TerrainRenderer` 当前透明状态读取水面批次，可能读到 ShadowPass 临时重建后的透明计划；主视角透明批次必须由 Renderer 显式传入。
- `VolumetricPass` 绑定了 CSM raw/all/color 纹理，但漏设对应 sampler uniform；陆上体积光只依赖主 shadow map，水下 UW VL 会读错 raw depth/color0/color1。
- `uUnderwaterVolumetricLightStrength` 曾误用普通 `fogStrength`，volumetric composite 的 active 条件也漏掉水下独立开关。

### 预防规则

- 新 pass 消费 `FrameContext`/`RenderSettings` 时，必须逐字段对照 legacy `RenderFrameData`/`RenderPipelineSettings` 检查映射。
- texture unit 绑定必须同时检查“纹理绑定”和“sampler uniform 设置”，尤其是 `mecraft_shadow.glsl` 的 raw/compare/color 成对资源。
- 水下链路验收必须覆盖 `uIsEyeInWater` 进入 deferred lighting、scene composite、water composite、volumetric fog、volumetric composite 五个 pass。
- ShadowPass 可以内部重建透明批次，但主视角透明计划必须由 Renderer 保存并显式传给后续 pass。
- 回归排查优先使用 debug view 72-77：UW scatter、UW shadow、UW phase、Depth gap、Color0、Color1。

## 注意事项

1. **编译约束**：编译需由用户在 IDE 中进行，每个 Phase 结束时编译一次验证
2. **渐进式重构**：每阶段独立可编译可运行，不破坏现有功能
3. **管线切换语义**：切换时会重新初始化/销毁对应管线的 GPU 资源
4. **DeferredFrameTargets**：Phase 2 只建立了接口骨架，完整实现将在后续 Phase 中从 DeferredRenderTargets 迁移
