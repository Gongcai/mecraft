# 体积云渲染系统 (Volumetric Cloud Rendering System)

## 一、系统概述

DerivativeMain Shader Pack 实现了一套多层次的云渲染系统，包含三种云层类型：

| 云层类型 | 定义宏 | 高度 | 特征 |
|---------|--------|------|------|
| 积云 (Cumulus) | `VOLUMETRIC_CLOUDS` | 1000m (晴) / 800m (雨) | 体积光线步进，真实3D密度场 |
| 卷云 (Cirrus) | `CIRRUS_CLOUDS` | 7000m | 平面投影，半透明薄云 |
| 卷积云 (Cirrocumulus) | `CIRROCUMULUS_CLOUDS` | 7000m | 平面投影，带自身阴影 |

云渲染在 `program/Deferred1.glsl` 中执行，输出到 `colortex2`（RGB = 散射颜色，A = 透射率），随后在 `deferred5.fsh` 中与天空和场景合成。

## 二、体积云光线步进 (Volumetric Cloud Ray Marching)

### 2.1 射线-云层求交

首先通过球体求交确定光线在云层中的行进范围。考虑到地球曲率，使用 `RaySphereIntersection` 函数：

```glsl
vec3 planeOrigin = vec3(0.0, planetRadius + eyeAltitude, 0.0);
vec2 bottomIntersection = RaySphereIntersection(planeOrigin, worldDir, planetRadius + cloudProperties.altitude);
vec2 topIntersection = RaySphereIntersection(planeOrigin, worldDir, planetRadius + cloudProperties.maxAltitude);
```

云层被视为两个球壳之间的区域（底部球半径 = planetRadius + altitude，顶部 = planetRadius + maxAltitude）。根据相机位于云层之上或之下，选择不同的交点作为起止距离。

### 2.2 步进参数

```glsl
uint raySteps = CLOUD_CUMULUS_SAMPLES;  // 默认 32 步
raySteps = uint(mix(raySteps, uint(raySteps * 0.6), abs(worldDir.y))); // 步数衰减

float rayLength = clamp(endLength - startLength, 0.0, 2e4) * rcp(raySteps);
```

关键优化：
- **步数衰减**：当视线接近水平时（`abs(worldDir.y)` 较小），使用全部步数；当视线接近垂直时，步数减少到 60%，因为垂直穿越云层的距离更短。
- **最大距离限制**：`clamp(..., 0.0, 2e4)` 将最大光线行进距离限制在 20000 格，防止极端角度下的性能问题。
- **抖动采样**：起始位置添加 dither 偏移 `startLength + rayLength * dither`，使用 R1 准随机序列减少带状伪影。

### 2.3 行星曲率修正

```glsl
void GetPlanetCurvePosition(inout vec3 p) {
    p.y = length(p + vec3(0.0, planetRadius, 0.0)) - planetRadius;
}
```

对射线步进的每一步位置和步进向量应用行星曲率修正，确保在大尺度上云层的高度计算正确。

### 2.4 早期退出

```glsl
if (transmittance < minTransmittance) break;  // minTransmittance = 0.05
```

当累积透射率低于 5% 时提前终止，避免对不可见区域的无效计算。

## 三、云密度函数与噪声塑造

### 3.1 核心密度函数 `CloudVolumeDensity`

密度计算分为以下几个阶段：

**阶段一：局部覆盖度检测**

```glsl
float localCoverage = texture(noisetex, worldPos.xz * 2e-7 - wind.xz * 2e-3).y;
localCoverage = saturate(fma(localCoverage, 3.0, wetness - 0.4)) * 0.5 + 0.5;
if (localCoverage < 0.1) return 0.0;
```

使用大尺度 2D 噪声确定云的宏观分布模式。`wetness` 参数使雨天时覆盖度增加。阈值 0.1 提供快速剔除。

**阶段二：多八度 FBM 噪声**

```glsl
float density = noiseDetail * 0.03, weight = 0.5;
for (uint i = 0u; i < steps; ++i, weight *= octWeight) {
    density += weight * Get3DNoiseSmooth(position);
    position = position * octScale - wind;
}
```

- 5 个八度（主采样）/ 3 个八度（光照采样）
- 权重衰减 `octWeight = 0.5`，频率缩放 `octScale = 3.0`
- 每层添加风偏移，产生不同尺度的运动
- `Get3DNoiseSmooth` 使用 3 次 Hermite 插值 (`curve()`) 在 2D 噪声纹理上模拟 3D 噪声

**阶段三：高度衰减**

```glsl
float normalizedHeight = saturate((worldPos.y - cloudProperties.altitude) * rcp(cloudProperties.thickness));
float heightAttenuation = saturate(normalizedHeight * 6.6) * saturate(oneMinus(normalizedHeight) * (2.0 + wetness));
```

这是塑造云形状的关键：
- 底部：`saturate(normalizedHeight * 6.6)` 产生快速上升的底部轮廓
- 顶部：`saturate(oneMinus(normalizedHeight) * (2.0 + wetness))` 产生较缓的顶部衰减
- 雨天时顶部衰减更慢（wetness 增大系数），云层更平坦

**阶段四：覆盖度重映射与最终密度**

```glsl
density = cloudProperties.coverage == 1.0 ? density : saturate((density - 1.0 + cloudProperties.coverage) * rcp(cloudProperties.coverage));
density *= heightAttenuation * 1.9;
density -= heightAttenuation * 0.9 + normalizedHeight * 0.5 + 0.1;
return saturate(density * 3.0 * cloudProperties.density);
```

覆盖度参数控制云的"雕刻"程度——coverage 越高，越多噪声值被保留为有效密度。最终减法产生类似 `remap` 的效果，使云体边缘更清晰。

### 3.2 3D 噪声实现

```glsl
float Get3DNoiseSmooth(in vec3 position) {
    vec3 p = floor(position);
    vec3 b = curve(position - p);  // Hermite smoothstep
    vec2 uv = p.xy + b.xy + 97.0 * p.z;  // Z 轴偏移 97.0 避免对齐
    vec2 rg = texture(noisetex, (uv + 0.5) * noiseTexturePixelSize).xy;
    return mix(rg.x, rg.y, b.z);  // Z 方向插值
}
```

这是一个巧妙的伪 3D 噪声方案：
- 利用 256x256 的 2D 噪声纹理
- Z 轴通过偏移 UV 坐标 97 个像素来模拟（97 是质数，避免模式重复）
- 使用双通道 (x, y) 进行 Z 方向插值
- 三线性插值使用 Hermite 曲线 (`curve = x^2 * (3 - 2x)`) 实现平滑过渡

### 3.3 噪声细节函数 `GetNoiseDetail`

```glsl
float GetNoiseDetail(in vec3 worldDir) {
    worldDir *= 48.0;
    float pnoise = Get3DNoise(worldDir - wind);
    pnoise += Get3DNoise(worldDir * 2.0) * ...;  // 5 个八度
    return pnoise - 0.15;
}
```

这是一个方向相关的噪声函数，用于根据视线方向调整密度细节。远离相机的区域使用更高的细节值，近处使用较低值以节省性能：

```glsl
float density = CloudVolumeDensity(cloudProperties, rayPos, 5u, mix(noiseDetail, 1.0, exp2(-dist * 0.001f)));
```

距离越远，`noiseDetail` 权重越高，产生更丰富的细节；近距离则趋于 1.0（简化）。

## 四、云光照模型

### 4.1 Beer-Lambert 透射率

透射率遵循 Beer-Lambert 定律：

```glsl
float stepTransmittance = fastExp(-density * 0.12 * rayLength);
transmittance *= stepTransmittance;
```

其中 `fastExp` 是 `exp2(x * 1.4427)` 的近似，比标准 `exp()` 更快。消光系数 0.12 是经验调参值。

### 4.2 多散射近似

系统使用 4 个散射波瓣模拟多次散射，每个波瓣使用不同的光学深度缩放：

```glsl
float sunlightEnergy = fastExp(-sunlightOD * 2.0) * phases.x;   // 主前向散射
sunlightEnergy    += fastExp(-sunlightOD * 0.8) * phases.y;      // 次前向
sunlightEnergy    += fastExp(-sunlightOD * 0.3) * phases.z;      // 更宽散射
sunlightEnergy    += fastExp(-sunlightOD * 0.1) * phases.w;      // 全局照明近似
```

光学深度系数递减（2.0, 0.8, 0.3, 0.1）模拟了光线在云中多次散射后能量衰减的累积效果。这是一种廉价的多散射近似，避免了真正的多次弹射计算。

### 4.3 相函数 (Phase Function)

使用三组相函数的加权组合：

```glsl
phases.x = HenyeyGreensteinPhase(LdotV, cloudForwardG) * 0.7
         + HenyeyGreensteinPhase(LdotV, cloudBackwardG) * cloudBackwardWeight
         + CornetteShanksPhase(LdotV, 0.9) * cloudProperties.cloudPeakWeight;
```

- **Henyey-Greenstein 前向瓣**：`g = 0.6 - wetness * 0.2`，晴天更强的前向散射
- **Henyey-Greenstein 后向瓣**：`g = -0.4 + wetness * 0.2`，产生银边效应
- **Cornette-Shanks 前向峰值**：`g = 0.9`，产生强烈的太阳周围亮晕

雨天时 `g` 值趋近零，散射更各向同性（云看起来更"平"）。

### 4.4 Powder Sugar 效应

```glsl
float powder = oneMinus(fastExp(-density * 36.0)) * 0.82;
powder /= 1.0 - powder;
```

Powder 效应模拟光线在云体边缘的增强散射。当密度较低时（云边缘），powder 值较高，增强边缘亮度；密度高时趋近饱和。这产生了云体边缘发光的视觉效果。

### 4.5 太阳光学深度采样 `CloudVolumeSunLightOD`

```glsl
float CloudVolumeSunLightOD(in CloudProperties cloudProperties, in vec3 rayPos, in float lightNoise) {
    float rayLength = cloudProperties.thickness * (0.2 / float(CLOUD_CUMULUS_SUNLIGHT_SAMPLES));
    vec4 rayStep = vec4(worldLightVector, 1.0) * rayLength;

    for (uint i = 0u; i < CLOUD_CUMULUS_SUNLIGHT_SAMPLES; ++i, rayPos += rayStep.xyz) {
        rayStep *= 2.0;  // 指数增长步长
        float density = CloudVolumeDensity(cloudProperties, rayPos + rayStep.xyz * lightNoise, 5u, 1.0);
        if (density < 1e-4) continue;
        opticalDepth += density;
    }
    return opticalDepth * rayLength * 0.12;
}
```

关键设计：
- **指数增长步长**：`rayStep *= 2.0` 使每一步的距离翻倍，近处精确、远处粗糙
- **抖动偏移**：`lightNoise` 避免带状伪影
- **仅 4 步**（默认）：但因指数增长覆盖了较大的距离范围
- 0.12 的缩放系数与主透射率计算保持一致

天光采样 `CloudVolumeSkyLightOD` 类似，但方向向上 (`vec3(0.0, 1.0, 0.0)`)，仅 2 步。

### 4.6 最终散射合成

```glsl
vec3 scattering = scatteringSun * 22.0 * cloudProperties.sunlighting * (moonlit ? moonIlluminance : sunIlluminance);
scattering += scatteringSky * 0.15 * cloudProperties.skylighting * skyIlluminance;
```

- 太阳光乘以 22.0 的强度系数
- 天光贡献约 15% 的权重
- 夜间自动切换为月光，应用 `DoNightEye` 暗视效果
- 闪电、极光等额外光源叠加

## 五、平面云 (Planar Clouds) vs 体积云

### 5.1 卷云 (Cirrus) - `PlanarSample0`

两种实现模式（`CIRRUS_CLOUDS == 1` 或 `== 2`）：

**模式 1**：FBM + 黄金角旋转

```glsl
const float goldenAngle = TAU / (PHI1 + 1.0);
const mat2 goldenRotate = mat2(cos(goldenAngle), -sin(goldenAngle), ...);
float noise = GetCloudsNoise(position);
for (uint i = 1u; i < 6u; ++i, amplitude *= 0.43) {
    position = goldenRotate * 3.2 * (position - wind.xz);
    noise += GetCloudsNoise(position * (1.0 + vec2(-0.35, 0.05) * sqrt(i))) * amplitude;
}
```

使用黄金角旋转（~137.5 度）避免方向性伪影，振幅衰减 0.43 产生更柔和的细节。

**模式 2**：各向异性 FBM

```glsl
for (uint i = 1u; i < 6u; ++i) {
    weight *= 0.5;
    position *= vec2(2.0, 2.2 + sqrt(i));  // 各向异性缩放
    noise += texture(noisetex, position - curve(noise) * 0.3 * weight - wind.xz * 4e-2).x * weight;
}
```

Y 方向缩放更大，产生拉伸的卷云纤维质感。`curve(noise)` 反馈产生扭曲效果。

### 5.2 卷积云 (Cirrocumulus) - `PlanarSample1` / `CloudPlanarDensity`

```glsl
float CloudPlanarDensity(in vec2 worldPos) {
    vec2 curl = texture(noisetex, position * 0.05).xy * 0.04;
    curl += texture(noisetex, position * 0.1).xy * 0.02;
    position += curl;
    // ...
    return cube(saturate(noise * 4.0));
}
```

使用 curl 噪声扰动产生有机的云形态。卷积云有自身阴影：

```glsl
for (uint i = 0u; i < 3u; ++i, rayPos += rayStep.xy) {
    rayStep *= 2.0;
    float density = CloudPlanarDensity(rayPos + rayStep.xy * lightNoise);
    opticalDepth += density * rayStep.z;
}
```

### 5.3 对比总结

| 特性 | 体积云 | 平面云 |
|------|--------|--------|
| 渲染方式 | 3D 光线步进 | 2D 纹理投影 |
| 密度场 | 3D FBM 噪声 | 2D 多层纹理 |
| 光照 | 独立的太阳/天光光学深度采样 | 简化的光学深度 + 相函数 |
| 自身阴影 | 有 (4步) | 有 (3步，仅卷积云) |
| 高度 | 可配置厚度层 | 单一平面 |
| 性能开销 | 高 (32步主采样) | 低 (无光线步进) |
| 视觉效果 | 厚实的积云/积雨云 | 薄纱般的高空云 |

## 六、云动画与天气系统

### 6.1 风场动画

```glsl
vec3 wind = vec3(2e-3, 2e-4, 1e-3) * worldTimeCounter * CLOUDS_SPEED;
```

三轴风速不同（X: 2e-3, Y: 2e-4, Z: 1e-3），产生非均匀运动。`CLOUDS_SPEED` 可配置（0-200）。Y 方向风速极慢，云几乎不垂直移动。

噪声采样时多层叠加风偏移：

```glsl
position = position * octScale - wind;  // 每个八度添加风
```

更高八度的噪声移动更快（因 `octScale` 缩放后叠加 `wind`），产生湍流感。

### 6.2 动态天气系统

天气参数在 `deferred.vsh` 中计算：

```glsl
vec2 weatherMap = mix(RandWeather(worldDay), RandWeather(worldDay + 1), curve(fract(float(worldTime) * rcp(24000.0))));
cloudDynamicWeather.x = curve(remap(0.25, 0.4, weatherMap.x)) * 0.5;  // 卷积云覆盖
cloudDynamicWeather.y = sqr(1.0 - remap(0.65, 0.8, weatherMap.y)) * 0.5;  // 卷云覆盖
cloudDynamicWeather.z = remap(0.4, 0.55, weatherMap.x * 2.0 - weatherMap.y);  // 积云强度
```

- 基于 `worldDay` 的哈希生成每日天气
- 使用 `worldTime` 在日间平滑过渡
- 三个分量分别控制不同云层的出现概率

### 6.3 晴雨过渡

`GetGlobalCloudProperties` 函数通过 `wetness` 在晴天/雨天预设间插值：

| 参数 | 晴天 | 雨天 |
|------|------|------|
| 高度 | 1000m | 800m |
| 厚度 | 1400m | 3000m |
| 覆盖度 | 1.0 | 1.2 |
| 密度 | 1.0 | 1.0 |
| 太阳光强度 | 1.0 | 0.3 |
| 天光强度 | 1.0 | 0.3 |
| 噪声缩放 | 4e-4 | 4.6e-4 |
| 峰值权重 | 0.1 | 0.8 |

## 七、性能优化策略

### 7.1 时间性超分辨率 (Temporal Upscaling)

```glsl
#define TEMPORAL_UPSCALING 2  // [2 3 4]
const int cloudsRenderFactor = TEMPORAL_UPSCALING * TEMPORAL_UPSCALING;

ivec2 cloudTexel = texel * TEMPORAL_UPSCALING + checkerboardOffset[frameCounter % cloudsRenderFactor];
```

云渲染在降低的分辨率下执行（默认 1/4 分辨率），使用棋盘格模式在多帧间累积。每帧只渲染 1/4 的像素，通过 TAA 重建完整图像。

### 7.2 深度剔除

```glsl
if (depthMax4x4(coord) >= 1.0) {
    // 只有天空像素才渲染云
}
```

使用 4x4 深度最大值检测，只有当区域内所有像素都是天空时才执行云渲染，避免对有物体遮挡的区域做无用计算。

### 7.3 密度阈值快速跳过

```glsl
if (density < 1e-4) continue;        // 主循环
if (localCoverage < 0.1) return 0.0;  // 覆盖度检测
if (density < 1e-6) return 0.0;       // 最终检测
```

多层阈值检测，在不同阶段尽早跳过空区域。

### 7.4 自适应噪声精度

光照采样使用较少的噪声八度（3 步 vs 主采样的 5 步），因为光照对细节不敏感：

```glsl
// 主采样
float density = CloudVolumeDensity(cloudProperties, rayPos, 5u, noiseDetail);
// 光照采样
float density = CloudVolumeDensity(cloudProperties, rayPos, 5u, 1.0);
```

### 7.5 阴影采样的平滑版本

```glsl
float CloudVolumeDensitySmooth(in CloudProperties cloudProperties, in vec3 worldPos) {
    // 使用 GetShadow3DNoiseSmooth 替代 Get3DNoiseSmooth
    // 固定 4 个八度
}
```

阴影用的密度函数使用更平滑的噪声变体，减少阴影中的高频噪声。

## 八、云阴影系统

云阴影在 `deferred5.fsh` 中计算，影响场景中的直接光照：

```glsl
float CloudShadow(in vec3 worldPos, in CloudProperties cloudProperties) {
    float cloudDensity = 0.0;
    // 体积云阴影：在云层两个高度采样
    vec3 checkPos = RaySphereIntersection(checkOrigin, worldLightVector,
        checkRadius + 0.15 * cloudProperties.thickness).y * worldLightVector + worldPos;
    cloudDensity += CloudVolumeDensitySmooth(cloudProperties, checkPos);

    checkPos = RaySphereIntersection(checkOrigin, worldLightVector,
        checkRadius + 0.5 * cloudProperties.thickness).y * worldLightVector + worldPos;
    cloudDensity += CloudVolumeDensitySmooth(cloudProperties, checkPos);

    // 平面云阴影
    vec2 checkPos1 = RaySphereIntersection(checkOrigin, worldLightVector,
        planetRadius + CLOUD_PLANE_ALTITUDE).y * worldLightVector.xz + worldPos.xz;
    cloudDensity += CloudPlanarDensity(checkPos1) * 10.0;

    return exp2(-cloudDensity * cloudDensity * 2e2);
}
```

- 在云层底部 15% 和中部 50% 处各采样一次
- 平面云阴影单独叠加
- 阴影强度 = `exp2(-density^2 * 200)`，产生锐利的阴影边缘
- 太阳高度角衰减：低角度时阴影淡出
- 最终阴影值乘入 `sunlightMult`，影响整个场景光照

## 九、大气与场景集成

### 9.1 大气透视

```glsl
float atmosFade = fastExp(-length(rayPos) * (0.2 + 0.1 * wetness) * 1e-4);
scattering = scattering * atmosFade + skyRadiance * oneMinus(transmittance) * oneMinus(atmosFade);
```

远处的云逐渐融入天空颜色，模拟大气散射衰减。`FULL_AERIAL_PERSPECTIVE` 模式下使用完整的 `GetSkyRadianceToPoint` 计算精确的大气透视。

### 9.2 场景合成

在 `deferred5.fsh` 中：

```glsl
vec4 cloudData = texelFetch(colortex1, texel, 0);
sceneData = sceneData * cloudData.a + cloudData.rgb;
// 太阳/月亮也被云遮挡
sunmoon *= cloudData.a;
```

云的透射率 (`cloudData.a`) 用于：
1. 混合云散射和天空辐射
2. 遮挡太阳和月亮
3. 通过云阴影影响地面光照

### 9.3 月光与夜间处理

```glsl
bool moonlit = worldSunVector.y < -0.04;
vec3 scattering = scatteringSun * 22.0 * cloudProperties.sunlighting * (moonlit ? moonIlluminance : sunIlluminance);
```

夜间自动切换为月光，应用暗视效果 (`DoNightEye`) 将低亮度场景转换为蓝灰色调。

## 十、独特技术亮点

1. **伪 3D 噪声**：使用 2D 纹理 + Z 偏移 97 像素的方案，以极低的纹理采样成本实现 3D 噪声效果，避免了 3D 纹理的内存开销。

2. **指数增长光照步长**：太阳光采样使用 `rayStep *= 2.0` 的指数增长，在仅 4 步内覆盖较大距离范围，近处精度高、远处精度低，符合人眼感知。

3. **三相函数组合**：HG 前向 + HG 后向 + CS 峰值的三重组合，在单次计算中同时捕捉各向异性散射、银边效应和太阳亮晕。

4. **天气系统哈希**：使用 `worldDay` 作为种子的哈希函数生成天气，配合 `worldTime` 的曲线插值实现跨日平滑过渡，无需额外纹理。

5. **行星曲率修正**：对光线步进应用 `GetPlanetCurvePosition`，在极端视角（如高空俯瞰）下保持云层形状的正确性。

6. **Powder 效应的有理近似**：`powder / (1 - powder)` 形式在低密度时线性增长、高密度时趋于饱和，精确模拟了光线在云体边缘的增强散射。
