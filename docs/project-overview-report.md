**日期：** 2026年6月4日

**仓库：** https://github.com/Gongcai/mecraft

---

### 项目定位

Mecraft 是一个从零构建的桌面端体素沙盒游戏，旨在还原 Minecraft 的核心体验并提供高性能体素引擎架构。项目采用 C++17 + OpenGL 4.5，实现了程序化地形生成、动态区块加载、物理碰撞、动态光照、3D 空间音频以及完整的混合延迟渲染管线，并支持 ENet 多人联机。

### 模块架构

项目 `src/` 目录包含 22 个子模块，按代码量排序前三为：

- **renderer（渲染器）** — 24,854 行，占 34%。包含 16 个独立渲染 Pass、阴影系统、地形网格、子渲染器等，实现了完整的混合延迟渲染管线。
- **ui（用户界面）** — 15,244 行，占 21%。基于 ImGui + 自研 UI 框架，包含 20+ 种控件、HUD、物品栏、主菜单等完整界面系统。
- **world（世界系统）** — 10,614 行，占 14%。涵盖区块管理、地形生成、流体模拟、光照传播、昼夜/天气系统等。

其余模块包括 ECS 实体系统、游戏逻辑、网络传输、存档系统、音频引擎、物理碰撞、粒子系统等，合计约 22,954 行。

### 渲染管线

项目实现了参考 DerivativeMain shader pack 的完整渲染管线，覆盖从 GBuffer 到最终后处理的 14 个阶段：

`SkyCapture → GBuffer → Velocity → Shadow (CSM/PCSS) → SSAO → Deferred Lighting (FromSH) → SSR → Cloud → Scene Composite → Volumetric Fog → TAA → Motion Blur → DoF → Water Composite → Post (Bloom/Tonemap)`

已完成特性包括：延迟渲染管线、4级级联阴影+PCSS、PBR BRDF、球谐天光、大气散射LUT、体积云、屏幕空间反射、SSAO、次表面散射、TAA抗锯齿、水体渲染、体积雾、HDR后处理链等。当前缺失全局光照（RSM/GI）和实体 GBuffer 两项。

### 近期开发动态

根据 Git 提交记录，项目近期的开发重心集中在以下方向：

1. **多人联机系统** — 实现了 ENet 网络传输、客户端/服务器架构、实体同步、区块票管理、方块交互同步等完整的多人游戏基础设施。
2. **存档系统** — 完成了区块序列化、玩家状态持久化、自动保存与掉落物恢复功能。
3. **渲染管线重构** — 正在进行 11 阶段的 Pass-Oriented 架构重构，Phase 1-7 已完成，Phase 8-9 进行中。

### 总体评价

Mecraft 是一个体量可观的个人/小团队项目，在约 2.5 个月内以约 9 万行代码实现了一个功能相当完整的体素引擎。渲染管线的完成度尤其突出，涵盖了现代游戏引擎中大多数关键渲染特性。项目架构清晰，模块划分合理，测试覆盖较广（54 个测试），且正在进行系统性的渲染管线重构以提升代码可维护性。后续主要挑战在于全局光照的实现、渲染管线重构的收尾，以及多人游戏稳定性的持续打磨。
