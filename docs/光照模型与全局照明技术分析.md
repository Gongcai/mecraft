# 光照模型与全局照明 (Lighting Model and Global Illumination)

## 1. 概述

DerivativeMain 使用延迟渲染管线（Deferred Rendering），主光照计算位于 `world0/deferred5.fsh`。该 pass 综合了方向光（太阳/月亮）、天空光、方块光、环境遮蔽和全局照明，采用基于物理的渲染（PBR）框架。材质数据在 `program/Gbuffers/Terrain.frag` 中编码并输出到多个 G-buffer 纹理中，随后在延迟 pass 中解码并用于光照计算。

---

## 2. PBR 材质模型

### 2.1 Material 结构体 (`lib/Head/Material.inc`)

```
struct Material {
    float roughness;       // 粗糙度
    float isMetal;         // 金属标志 (0.0 或 1.0)
    float f0;              // 基础反射率
    float emissiveness;    // 自发光强度
    bool  hasReflections;  // 是否有反射
    bool  isRough;         // 是否为粗糙表面
};
```

### 2.2 材质数据解码

材质数据从 specular 贴图中解码，支持两种纹理格式：

**格式 0（LabPBR 标准）：**
- `specTex.r`：光滑度（smoothness），粗糙度 = `(1 - smoothness)^2`
- `specTex.g`：当值 > 229/255 时判定为金属，f0 = 0.91；否则 f0 = specTex.g
- `specTex.a`：自发光强度（a == 1.0 时视为无自发光），经过 `pow(emissiveness, 2.2)` 的 gamma 曲线处理

**格式 1（简化的 PBR 格式）：**
- `roughness = specTex.r`
- `isMetal = specTex.g`（连续值）
- `f0 = specTex.g * 0.96 + 0.04`（金属度到反射率的线性映射）
- `emissiveness = specTex.b`

### 2.3 G-Buffer 编码布局

在 `Terrain.frag` 中，数据按如下方式写入 G-buffer：

| 输出 | 内容 |
|------|------|
| `colortex6` (location 0) | albedo RGB（sRGB 空间） |
| `colortex3.xy` | 法线（八面体编码，2 通道） |
| `colortex3.z` | `PackUnorm2x8(specular.rg)` —— 粗糙度 + f0/金属度 |
| `colortex3.w` | `PackUnorm2x8(specular.ba)` —— 自发光 + SSS 参数 |
| `colortex7.xy` | 光照图 (mcLightmap)，带抖动量化 |
| `colortex7.z` | 材质 ID（float，`materialIDs * rcp(255)`） |
| `colortex7.a` | 视差阴影（可选） |

### 2.4 法线编码

采用**八面体映射编码**（Octahedral Normal Encoding），将 3D 法线压缩为 2 个通道：

```glsl
vec2 EncodeNormal(in vec3 n) {
    n.xy /= abs(n.x) + abs(n.y) + abs(n.z);
    if (n.z <= 0.0)
        n.xy = (vec2(1.0) - abs(n.yx)) * (step(0.0, n.xy) * 2.0 - 1.0);
    return n.xy * 0.5 + 0.5;
}
```

解码时从 2D 映射回 3D 并归一化。这种编码在保持精度的同时只占用 2 个通道。

## 3. BRDF 实现 (`lib/Surface/BRDF.glsl`)

### 3.1 菲涅尔项 (Fresnel)

实现了三种菲涅尔计算：

1. **Schlick 近似**（空气-电介质界面）：`F = (1 - cosθ)^5 + (1 - (1 - cosθ)^5) * f0`，用于镜面 BRDF
2. **精确电介质菲涅尔**（基于 f0）：从反射率反推 IOR，再用 Fresnel 方程精确求解
3. **精确电介质菲涅尔**（基于 IOR）：直接用折射系数计算，处理了全内反射（cosR < 0 时返回 1.0）

### 3.2 微表面分布函数 — GGX (Trowbridge-Reitz)

```glsl
float DistributionGGX(in float NdotH, in float alpha2) {
    return alpha2 * rPI / sqr(1.0 + (NdotH * alpha2 - NdotH) * NdotH);
}
```

使用 `alpha2 = roughness^2` 作为粗糙度参数，这是标准的 GGX/Trowbridge-Reitz 法线分布函数。

### 3.3 几何遮蔽项 — Smith GGX

实现了高度相关的 Smith GGX 可见性函数（Height-Correlated Smith GGX）：

```glsl
float V2SmithGGX(in float NdotV, in float NdotL, in float alpha2) {
    float ggxl = NdotL * sqrt(alpha2 + (NdotV - NdotV * alpha2) * NdotV);
    float ggxv = NdotV * sqrt(alpha2 + (NdotL - NdotL * alpha2) * NdotL);
    return 0.5 / (ggxl + ggxv);
}
```

这是遮蔽-阴影联合项 `G / (4 * NdotV * NdotL)` 的高效实现形式，直接返回 V = G/(4*NdotV*NdotL)。

### 3.4 漫反射 BRDF — Hammon Diffuse

未使用标准 Lambert 漫反射，而是采用了 **Stephen Hammon 的漫反射模型**（GDC 2017），该模型考虑了粗糙表面的次表面多次散射：

```glsl
vec3 DiffuseHammon(LdotV, NdotV, NdotL, NdotH, roughness, albedo) {
    float facing = max0(LdotV) * 0.5 + 0.5;
    float singleSmooth = 1.05 * (1 - (1-NdotL)^5) * (1 - (1-NdotV)^5);
    float singleRough = facing * (0.45 - 0.2 * facing) * (rcp(NdotH) + 2.0);
    float single = mix(singleSmooth, singleRough, roughness) * rPI;
    float multi = 0.1159 * roughness;
    return (multi * albedo + single) * NdotL;
}
```

- **smooth 分量**：基于 Fresnel 逆项的光滑表面漫反射
- **rough 分量**：基于 facing 项的粗糙表面漫反射
- **multi 分量**：粗糙度驱动的多次散射近似，与 albedo 相乘

通过 roughness 在 smooth 和 rough 之间插值，平滑过渡。

### 3.5 镜面 BRDF — Cook-Torrance

```glsl
float SpecularBRDF(LdotH, NdotV, NdotL, NdotH, alpha2, f0) {
    float F = FresnelSchlick(LdotH, f0);
    float D = DistributionGGX(NdotH, alpha2);
    float V = V2SmithGGX(NdotV, NdotL, alpha2);
    return min(NdotL * D * V * F, 4.0);
}
```

标准 Cook-Torrance 微表面镜面反射：`F * D * V`，结果钳制到 4.0 防止萤火虫像素。

## 4. 方向光/日光计算 (`lib/Lighting/SunLighting.glsl`)

### 4.1 次表面散射 (SSS)

```glsl
vec3 CalculateSubsurfaceScattering(albedo, sssAmount, sssDepth, LdotV) {
    vec3 coeff = albedo * inversesqrt(GetLuminance(albedo) + 1e-6);
    coeff = oneMinus(0.75 * saturate(coeff)) * (28.0 / sssAmount);

    vec3 sss = fastExp(0.375 * coeff * sssDepth) * HenyeyGreensteinPhase(-LdotV, 0.6);
    sss    += fastExp(0.125 * coeff * sssDepth) * (0.33 * HenyeyGreensteinPhase(-LdotV, 0.35) + 0.17 * rPI);
    return sss * sssAmount * PI;
}
```

- 散射系数基于 albedo 的亮度归一化，模拟不同颜色的散射深度差异
- **双层散射模型**：
  - 外层：较大衰减系数（0.375）+ 高各向异性（g=0.6）的 Henyey-Greenstein 相位函数 —— 模拟前向散射
  - 内层：较小衰减系数（0.125）+ 低各向异性（g=0.35）+ 各向同性分量（0.17/π）—— 模拟深层扩散

### 4.2 假弹射光 (Fake Bounced Light)

当 GI 未启用时的简化替代方案：

```glsl
float CalculateFakeBouncedLight(in vec3 normal) {
    normal.y = -normal.y;
    vec3 bounceVector = normalize(worldLightVector + vec3(0.0, 1.0, 0.0));
    float bounce = saturate(dot(normal, bounceVector) * 0.4 + 0.6);
    return bounce * (2.0 - bounce) * 3e-2;
}
```

将法线 Y 翻转后与"太阳+上方"的中间方向做点积，模拟来自地面的反弹光。

### 4.3 云阴影

- **体积云阴影**：在两个高度层采样云密度
- **平面云阴影**：在 7000m 高度采样云层密度
- 密度通过 `exp2(-density^2 * 200)` 转换为透射率
- 天气湿度过高时阴影变深（`mix(1.0, 0.03, wetness)`）

## 5. 方块光/点光源计算 (`lib/Lighting/BlockLighting.glsl`)

### 5.1 方块光衰减

```glsl
void GetBlocklightFalloff(inout float blocklight) {
    blocklight = rcp(sqr(16.0 - 15.0 * blocklight)) + sqr(blocklight) * 0.05;
    blocklight = remap(rcp(sqr(16.0)), 1.0, blocklight);
}
```

这不是简单的物理衰减（1/r²），而是 Minecraft 光照图的非线性映射：
- 第一项 `rcp(sqr(16 - 15*light))` 提供近距离的快速衰减
- 第二项 `sqr(light) * 0.05` 提供远距离的残余亮度
- 使用 `remap` 将结果归一化到 [0, 1] 范围

最终方块光颜色 = `blocklightColor * TORCHLIGHT_BRIGHTNESS`，其中 `blocklightColor` 通过 **Blackbody 辐射** 从色温计算：

```glsl
blocklightColor = Blackbody(float(TORCHLIGHT_COLOR_TEMPERATURE));  // 默认 3000K
```

Blackbody 函数实现了 Planck 辐射定律，通过 RGB 三通道的主波长（610nm, 549nm, 468nm）近似计算黑体辐射光谱。

### 5.2 自发光系统 (Emission)

基于材质 ID 的多层级自发光系统，包含约 16 种不同的发光模式：

| 材质 ID | 方块类型 | 发光特征 |
|---------|---------|---------|
| 20, 36 | 完全发光方块 | 基于 albedo 亮度 |
| 21 | 火把类 | 红色通道检测（r > 0.8），4x blocklightColor |
| 22, 15 | 火焰 | 6x blocklightColor * albedo^3 |
| 23 | 萤石类 | 2.5x blocklightColor * albedo^3 |
| 24 | 海晶灯 | 2x albedo^3，无光照源遮蔽 |
| 25 | 红石 | 基于高度和红色通道的条件发光，红石色调 (2.1, 0.9, 0.9) |
| 26 | 灵魂火 | 蓝色通道检测，带偏移的亮度 |
| 27 | 紫水晶 | 光照图驱动的自适应亮度 |
| 28 | 萤光莓 | 颜色饱和度驱动，暖色调 (28, 25, 21) |
| 30 | 信标核心 | 基于局部坐标的中心区域检测 |
| 31 | Sculk | 微弱蓝色发光 |
| 32 | 发光地衣 | 红色通道区分发光类型 |
| 33 | 部分发光 | 30x albedo^3，基于颜色阈值 |
| 34 | 中心发光 | 基于 XZ 局部坐标的中心检测 |
| 57, 58 | 矿石 | 颜色空间检测高亮矿粒并赋予发光 |

### 5.3 手持光源

```glsl
float falloff = rcp(dotSelf(worldPos) + 1.0);  // 1/(r² + 1) 衰减
falloff *= fma(NdotV, 0.8, 0.2);               // 视角依赖，正面更亮
```

- 距离衰减使用 `1/(r² + 1)`，避免除零且比物理衰减更柔和
- 视角加权：法线对齐观察方向时更亮（NdotV * 0.8 + 0.2）

### 5.4 矿石发光检测

不使用材质 ID，而是通过**颜色空间分析**自动检测矿石纹理：

```glsl
float isOre = saturate((max(max(dot(albedoRaw, vec3(2,-1,-1)),
    dot(albedoRaw, vec3(-1,2,-1))), dot(albedoRaw, vec3(-1,-1,2))) - 0.1) * rcp(0.3));
```

通过检测颜色通道间的对比度（某一通道显著高于其他两个通道）来识别矿粒的高亮像素。

## 6. 环境遮蔽 (`lib/Lighting/AmbientOcclusion.glsl`)

### 6.1 螺旋 SSAO

使用**黄金角旋转采样**（Golden Angle Rotation）的屏幕空间环境遮蔽：

```glsl
const float goldenAngle = TAU / (PHI1 + 1.0);  // ≈ 137.508°
const mat2 goldenRotate = mat2(cos(goldenAngle), -sin(goldenAngle),
                                sin(goldenAngle),  cos(goldenAngle));
```

核心算法：
1. 使用 golden angle 旋转矩阵逐步旋转采样方向
2. 每步正反两个方向采样（双边采样）
3. 对每个采样点计算法线对齐和距离衰减
4. 最终遮蔽 = `max0(1.0 - total * rSteps * SSAO_STRENGTH)^1.5`

采样半径自适应于深度。

**可配置参数：**
- `SSAO_SAMPLES`: 1 ~ 64（默认 6）
- `SSAO_STRENGTH`: 0.05 ~ 10.0（默认 1.0）

## 7. 全局照明 (`lib/Lighting/GlobalIllumination.glsl`)

### 7.1 Reflective Shadow Map (RSM) 方法

使用阴影贴图作为反射阴影映射来近似全局照明：

1. 将着色点投影到阴影贴图空间
2. 在阴影贴图中以螺旋模式采样周围区域
3. 对每个采样点计算入射方向、漫反射、弹射方向和反照率
4. 使用天空光照图进行加权
5. 累积所有采样的贡献

衰减模型：
```glsl
float falloff = rcp(sampleDist + radiusAdd);  // radiusAdd = sqrt(GI_RADIUS² / GI_SAMPLES)
```

**可配置参数：**
- `GI_SAMPLES`: 4 ~ 256（默认 16）
- `GI_RADIUS`: 2 ~ 500（默认 30）
- `GI_BRIGHTNESS`: 0.5 ~ 100.0（默认 1.0）

### 7.2 空间滤波

在 `deferred5.fsh` 中对 GI 结果进行双边空间滤波：

- 16 个采样点的 4x4 偏移模式
- 距离权重：`exp2(-distance * 4.0 * NdotV)`
- 法线权重：`pow16(max0(dot(prevNormal, normal)))`
- 空间权重：`exp2(-dotSelf(offset) * 0.1)`

## 8. 天空光照

### 8.1 球谐光照 (Spherical Harmonics)

天空光使用二阶球谐函数（L2 SH）表示：

```glsl
// 顶点着色器中：25 个采样点投影到 SH
for (i = 0..5; j = 0..5) {
    vec3 rayDir = /* 球面均匀分布 */;
    vec3 skyCol = texture(colortex5, ProjectSky(rayDir)).rgb;
    skySHR += ToSH(skyCol.r, rayDir);
    skySHG += ToSH(skyCol.g, rayDir);
    skySHB += ToSH(skyCol.b, rayDir);
}
```

在片元着色器中通过 `FromSH()` 重建任意法线方向的天空光。

## 10. 光源合成顺序

在 `deferred5.fsh` 的 `main()` 中，光照按以下顺序叠加：

```
1. sceneData = 0
2. sceneData += 天空光（SH 重建 + 天顶加权 + 湿度/闪电调制）
3. sceneData += BASIC_BRIGHTNESS + nightVision * 0.1
4. 若 GI 启用：
     sceneData += GI * GI_BRIGHTNESS * sunlightMult * 0.25
   否则：
     sceneData += fakeBounce * mcLightmap.g² * sunlightMult
5. sceneData *= AO（SSAO 或 GI 附带的 AO）
6. sceneData += 方块光（BlockLighting.glsl 中所有光源）
7. sceneData += shadow * diffuse  （阳光直接漫反射）
8. sceneData *= albedo             （乘以反照率）
9. sceneData *= (1 - isMetal)      （金属表面无漫反射）
10. sceneData += shadow * specular  （阳光镜面高光）
```

关键点：
- **金属表面**在漫反射阶段被抑制（`*= oneMinus(isMetal)`），因为金属的反射完全由镜面项贡献
- 阳光直接光 = `64.0 * waterTint * SUNLIGHT_INTENSITY * directIlluminance * cloudShadow`
- `directIlluminance` 来自大气渲染的预计算天空捕捉纹理

## 11. 光衰减模型总结

| 光源类型 | 衰减模型 |
|---------|---------|
| 方块光 (mcLightmap) | `1/(16 - 15*light)² + light² * 0.05`，非物理的 Minecraft 风格 |
| 手持光源 | `1/(r² + 1) * (NdotV * 0.8 + 0.2)` |
| 阴影 PCF | PCSS 软阴影：blocker search -> 自适应半径 -> PCF |
| SSS | 指数衰减 `exp(-coeff * depth)`，双层系数 |
| GI (RSM) | `1/(dist² + step²)` 距离衰减 |
| 天空光 | SH 重建 + mcLightmap.g 线性调制 |
| 环境光 (BASIC) | 常量，无衰减 |

## 12. 独特技术与设计亮点

1. **Hammon 漫反射 BRDF**：比标准 Lambert 更准确地模拟粗糙表面的漫反射，考虑了观察方向和粗糙度的关系。

2. **八面体法线编码**：使用高效的 2 通道编码而非传统的 3 通道存储，节省 G-buffer 带宽。

3. **彩色阴影支持**：通过比较 `shadowtex0`（不透明深度）和 `shadowtex1`（含透明深度）来检测半透明物体阴影。

4. **基于颜色分析的矿石发光**：不依赖材质 ID，通过颜色通道对比度自动识别矿石纹理中的高亮矿粒。

5. **Blackbody 光源色温**：方块光颜色通过 Planck 辐射定律从物理色温计算。

6. **RSM 全局照明 + 双边空间滤波**：在阴影贴图空间采样间接光照，配合边缘保持的空间滤波降低噪声。

7. **多级 SSS 模型**：使用 Henyey-Greenstein 相位函数的双层指数衰减，区分表层前向散射和深层扩散。

8. **自适应阴影偏移**：法线偏移基于世界空间距离和 NdotL 自适应。

9. **次表面散射与阳光的耦合**：有 SSS 的表面阳光强度降低 50%，避免过度照明。

10. **Nether 特殊处理**：下界中方块光乘以金属遮罩，亮度提升 10 倍，模拟下界岩浆的强反射环境。
