# 延迟渲染管线架构 (Deferred Rendering Pipeline Architecture)

## 1. 概述

DerivativeMain 是一个基于 Iris/OptiFabric 的 Minecraft 着色器包，由 HaringPro 开发。它实现了一套完整的延迟渲染管线（Deferred Rendering Pipeline），将场景几何信息先写入 G-Buffer，再通过多个延迟通道（deferred pass）和合成通道（composite pass）逐步计算光照、反射、雾效和后处理。管线支持主世界（Overworld）、下界（Nether）、末地（End）三个维度，并集成了 Distant Horizons（DH）远景模组。

GLSL 版本：450 compatibility。

---

## 2. 缓冲区格式与精度

| 缓冲区 | 格式 | 用途 | 清除行为 |
|---------|------|------|----------|
| `colortex0` | RGBA16F | GI/AO 时间累积数据；空间滤波输入/输出 | `false`（保留历史帧） |
| `colortex1` | RGBA16F | 体积雾/光数据（半分辨率）；天空时间混合数据 | `false` |
| `colortex2` | RGBA16F | 反射数据（SSR 输出 + 滤波）；云渲染数据 | `false` |
| `colortex3` | RGBA16 | 不透明场景最终颜色（TAA 输出后写入）；半透明法线+反照率 | 默认清除 |
| `colortex4` | R11F_G11F_B10F | 延迟光照结果（不透明直接+间接光照）；Bloom 降采样链 | `false` |
| `colortex5` | RGBA16F | 天空捕获贴图（辐照度 + 天气数据）；TAA 历史帧；曝光值 | `false` |
| `colortex6` | RGB8 | G-Buffer 反照率（sRGB 线性化）；Bloom 雾透射率 | 默认清除 |
| `colortex7` | RGB8（POM 时 RGBA8） | 光照贴图 + 材质 ID；POM 阴影（alpha 通道） | `true` |

**精度选择策略**：
- RGBA16F 用于需要高动态范围的中间数据
- R11F_G11F_B10F 用于场景颜色缓冲，节省带宽
- RGB8 用于低频数据（反照率、光照贴图）
- RGBA16 用于需要打包多个 unorm 数据的 G-Buffer

## 3. G-Buffer 布局

### 3.1 不透明几何体（gbuffers_terrain）

输出 `DRAWBUFFERS:673`，即写入 colortex6、colortex7、colortex3：

| 缓冲区 | 通道 | 内容 |
|--------|------|------|
| colortex6 | RGB | 反照率（原始 sRGB 纹理颜色 * 顶点 tint） |
| colortex7 | R, G | MC 光照贴图（方块光 + 天空光），带抖动误差分散 |
| colortex7 | B | 材质 ID（整数编码为 unorm） |
| colortex7 | A | POM 视差阴影值（可选） |
| colortex3 | XY | 编码法线（Octahedron 编码，2 分量） |
| colortex3 | Z | PackUnorm2x8(roughness, f0) |
| colortex3 | W | PackUnorm2x8(specular_b, specular_a) |

### 3.2 水体/半透明几何体（gbuffers_water）

输出 `DRAWBUFFERS:723`，即写入 colortex7、colortex2、colortex3：

| 缓冲区 | 通道 | 内容 |
|--------|------|------|
| colortex7 | RG | 光照贴图（带抖动） |
| colortex7 | B | 材质 ID |
| colortex2 | RGBA | 屏幕空间反射数据 |
| colortex3 | XY | 编码法线 |
| colortex3 | ZW | 半透明反照率 |

**关键差异**：水体在 G-Buffer 阶段就预先计算了屏幕空间反射（SSR），将结果直接写入 colortex2。

## 4. 完整管线执行顺序

### 4.1 G-Buffer 阶段

所有 `gbuffers_*` 着色器在此阶段执行，将几何信息写入 G-Buffer。

### 4.2 延迟通道（Deferred Passes）

#### Deferred0 — 天空捕获与辐照度预计算

- 输出：`DRAWBUFFERS:45`
- 功能：
  - 顶点着色器预计算太阳/月亮/天空辐照度
  - 片段着色器渲染天空穹顶（255x256 equirectangular）
  - 特定像素行存储辐照度数据

#### Deferred1 — 体积云与平面云

- 输出：`DRAWBUFFERS:2`
- 功能：
  - 时间超分辨率（2x2/3x3/4x4 棋盘格）
  - 渲染体积积云和平面云
  - 输出 `vec4(scattering, transmittance)`

#### Deferred2 — 天空数据时间混合（仅 Overworld）

- 输出：`DRAWBUFFERS:01`
- 功能：
  - GI/AO 时间累积
  - 天空/云层时间混合（Catmull-Rom 重采样）

#### Deferred3/4 — 空间滤波（GI/AO 降噪）

- 输出：`DRAWBUFFERS:0`
- 功能：双边空间滤波，MC 1.16.5+ 使用计算着色器版本

#### Deferred5 — 主光照计算（管线核心）

- 输出：`DRAWBUFFERS:04`
- 功能：
  - 天空/云层合成
  - 太阳/月亮渲染
  - 直接光照（PCF 软阴影 + SSS + Cook-Torrance BRDF）
  - 间接光照（SH 天空光 + GI + 假反弹光）
  - AO 应用
  - 方块光

#### Deferred6 — 屏幕空间反射（SSR）

- 输出：`DRAWBUFFERS:2`
- 功能：
  - 粗糙反射：GGX VNDF 采样
  - 屏幕空间光线步进
  - 天空反射回退

#### Deferred7/8 — 反射空间滤波

- 输出：`DRAWBUFFERS:2`
- 功能：双边滤波，MC 1.16.5+ 使用计算着色器版本

### 4.3 合成通道（Composite Passes）

#### Composite — 半透明合成 + 体积雾

- 输出：`DRAWBUFFERS:14`
- 功能：折射、反射合成、水雾、体积雾/光（半分辨率）

#### Composite1 — 折射 + 反射 + 雾效合成

- 输出：`DRAWBUFFERS:4` 或 `DRAWBUFFERS:46`
- 功能：折射、彩色玻璃吸收、反射合成、雾效（维度独立）

#### Composite2 — 景深（DoF）

- 条件启用：`DOF_ENABLED`
- 功能：物理 CoC + 金色角旋转采样

#### Composite3 — 时间抗锯齿（TAA）+ 运动向量

- 输出：`DRAWBUFFERS:25`
- 功能：运动向量计算、YCoCgR 方差裁剪、Reinhard 域混合

#### Composite10 — Bloom 多级降采样

- 条件启用：`BLOOM_ENABLED`
- 功能：tiled mipmap 方案，7 级降采样

#### Composite12/13 — Bloom 水平/垂直模糊

- 功能：9-tap 高斯模糊

#### Composite14 — 运动模糊

- 条件启用：`MOTION_BLUR`

#### Composite15 — 色调映射 + 后处理 + 最终输出

- 输出：`DRAWBUFFERS:3`
- 功能：Bloom 合成、Purkinje 偏移、曝光、色调映射（4 种算法）、暗角、电影效果

#### Final — CAS 锐化 + 最终输出到屏幕

- 功能：CAS 锐化 / Catmull-Rom 上采样 + Bayer 抖动

## 5. 缓冲区翻转（Buffer Flipping）

```
flip.deferred6.colortex0 = false
flip.composite15.colortex0 = true
flip.composite1.colortex5 = true
```

实现双缓冲的时间累积模式，避免显式的 ping-pong 纹理管理。

## 6. 计算着色器通道

### 6.1 Deferred4 — GI/AO 空间滤波

- Workgroup 大小：8x8
- 渲染分辨率：`vec2(0.5, 0.5)`（半分辨率）
- 共享内存：`shared vec4 sharedLight[10][10]`
- 使用 `imageLoad`/`imageStore` 直接操作 colortex0

### 6.2 Deferred8 — 反射滤波

- Workgroup 大小：32x32
- 渲染分辨率：`vec2(1.0, 1.0)`（全分辨率）

**版本条件切换**：MC 1.16.5+ 使用计算着色器版本，旧版本回退到片段着色器。

## 7. 维度差异

### 7.1 主世界（Overworld / world0）

**完整管线**，包含所有通道：大气散射、体积云、天空光照、直接光照、GI、SSAO、体积雾、天气系统、极光。

### 7.2 下界（Nether / world-1）

**精简管线**：
- 禁用 composite 通道（无体积雾）
- 无 GI，仅 SSAO
- 光照模型简化：无直接光照/阴影
- 雾效：基于生物群系的自定义雾色
- `BASIC_BRIGHTNESS_NETHER = 0.06`

### 7.3 末地（End / world1）

**中等复杂度管线**：
- 支持 GI + SSAO
- 自定义天空：指数衰减的末地黄/紫色渐变
- `DARK_END` 模式：Boss 战期间天空变为极暗的紫黑色
- `BASIC_BRIGHTNESS_END = 0.4`

---

## 8. Distant Horizons 集成

DH 远景模组通过条件编译 `#if defined DISTANT_HORIZONS` 集成：

- **深度处理**：所有需要深度的通道都检查 DH 深度
- **DH 专用函数**：`ScreenToViewSpaceDH()`、`ReprojectDH()`、`GetDepthLinearDH()` 等
- **通道支持**：云渲染、时间混合、主光照、体积雾、折射、TAA 均支持 DH 深度
- **DH 阴影**：可选的 DH 阴影支持

## 9. 混合模式总结

| 通道 | 混合方式 | 说明 |
|------|----------|------|
| G-Buffer（不透明） | `off` | 直接覆盖 |
| G-Buffer（半透明 colortex6） | Alpha 混合 | `SRC_ALPHA ONE_MINUS_SRC_ALPHA` |
| 天气粒子 | 加法混合 | `ONE ONE ONE ONE` |
| 护甲闪光 | 颜色乘法 | `SRC_COLOR ONE ZERO ONE` |
| 反射合成（半透明） | 着色器内 Alpha 混合 | `sceneData = sceneData * a + rgb` |
| 反射合成（不透明） | 着色器内加法混合 | `sceneData += reflection` |
| 体积雾 | 着色器内透射率混合 | `sceneData *= VFData.a; sceneData += VFData.rgb` |

## 10. 性能优化策略

### 10.1 分辨率分层

| 数据 | 分辨率 | 原因 |
|------|--------|------|
| GI/AO | 1/2 分辨率 | 高频细节少，时间累积可补偿 |
| 体积雾/光 | 1/2 分辨率 | 低频效果，空间上采样足够 |
| 云渲染 | 1/(NxN) 分辨率 | 时间超分辨率 |
| Bloom | 1/2 ~ 1/128 分辨率 | 多级降采样链 |
| 天空捕获 | 255x256 | 天空是低频数据 |

### 10.2 条件通道禁用

通过 `shaders.properties` 的 `program.*.enabled` 根据功能开关禁用通道。

### 10.3 早期退出

- 云渲染：`if (transmittance < minTransmittance) break;`
- SSR：`if (NdotL < 1e-6) return vec4(0.0);`
- 反射滤波：`if (!material.hasReflections) return;`

### 10.4 计算着色器优化

- Shared memory 减少全局内存带宽
- 适当的 workgroup 大小
- `workGroupsRender` 控制执行范围

### 10.5 自定义 Uniform 优化

`shaders.properties` 中使用 Iris 的 `variable.*` 语法预计算常用值。

## 11. 独特架构决策

### 11.1 双通道延迟光照分离

deferred5 将光照结果写入 colortex4，而材质数据写入 colortex0。后续反射通道可直接读取材质属性。

### 11.2 水体预计算反射

水面反射在 G-Buffer 阶段就预先计算，避免延迟阶段额外开销。

### 11.3 天空辐照度预计算

deferred0 的顶点着色器预计算所有辐照度数据，避免每个片段重复积分。

### 11.4 Octahedron 法线编码

2 分量编码保持精度同时减少 G-Buffer 带宽。

### 11.5 PackUnorm2x8 打包

两个 unorm 值打包到单个 float，节省一半显存带宽。

### 11.6 Bloom 雾（Bloomy Fog）

独特的 `BLOOMY_FOG` 特性：将 Bloom 数据与雾透射率混合，模拟光在雾中的前向散射。

### 11.7 分辨率自适应

`Final.glsl` 检测 `MC_RENDER_QUALITY`，等于 1.0 时执行 CAS 锐化，否则执行上采样。

## 12. 数据流图

```
G-Buffer 阶段:
  gbuffers_terrain -> colortex6(albedo) + colortex7(lightmap/matID) + colortex3(normal/specular)
  gbuffers_water   -> colortex7(lightmap/matID) + colortex2(SSR) + colortex3(normal/albedo)

Deferred 阶段:
  deferred0  -> colortex4(transmittance) + colortex5(sky map + irradiance)
  deferred1  -> colortex2(clouds, 半分辨率)
  deferred2  -> colortex0(GI/AO temporal) + colortex1(sky temporal)
  deferred3/4-> colortex0(GI/AO spatial filtered)
  deferred5  -> colortex4(scene lighting) + colortex0(specular data)
  deferred6  -> colortex2(SSR for opaque)
  deferred7/8-> colortex2(reflection filtered)

Composite 阶段:
  composite    -> colortex1(volumetric fog) + colortex4(scene + water fog)
  composite1   -> colortex4(refraction + reflection + fog) + colortex6(bloom fog)
  composite2   -> colortex4(DoF)
  composite3   -> colortex2(motion vectors) + colortex5(TAA result + exposure)
  composite10  -> colortex4(bloom downsample)
  composite12  -> colortex4(bloom horizontal blur)
  composite13  -> colortex4(bloom vertical blur)
  composite14  -> colortex2(motion blur)
  composite15  -> colortex3(tonemapped + graded)

Final 阶段:
  final        -> screen(CAS + dither)
```

## 13. 总结

DerivativeMain 的延迟渲染管线是一个精心设计的多通道架构，具有以下核心特点：

1. **物理准确性**：基于物理的 BRDF、大气散射、菲涅尔方程
2. **时间复用**：GI/AO 时间累积、天空时间混合、TAA、云渲染时间超分辨率
3. **分辨率分层**：不同效果使用不同分辨率，在质量和性能间取得平衡
4. **维度适配**：三个维度共享核心代码，通过条件编译定制光照和雾效
5. **模组集成**：Distant Horizons、Physics Ocean 的无缝集成
6. **灵活配置**：丰富的宏开关和参数滑块，支持从低端到高端的画质调节
