# Xbox 手柄快速测试指南

## 前置条件

1. 已连接 Xbox 手柄（USB 或蓝牙）
2. 手柄驱动已正确安装（Windows 通常自动识别）
3. 游戏已编译最新版本

## 手柄布局映射

### Gameplay 模式（游戏中）

```
        [LB] Sprint          [RB] Attack
         |                    |
    [LT] Use Item        [RT] (未使用)
         
    左摇杆: 移动           右摇杆: 视角
    (按下R3): 蹲下
    
         [Back]              [Start]
      切换视角                 菜单
      
       [D-Pad]              [Y] 背包
    ↑  武器槽2
  ←   →  武器槽1/3           [X]   [B]
    ↓                            
                            [A] 跳跃
```

### UI 模式（菜单中）

```
       [D-Pad]             [Y]
    ↑  ↓  ←  →  导航
                           [X]   [B] 取消/返回
                          
                           [A] 确认
```

## 基础功能测试

### 1. 连接检测测试
- 启动游戏前连接手柄
- 或启动后热插拔手柄
- 游戏应自动识别

### 2. 移动测试（Gameplay）
- **左摇杆**: 前后左右移动
  - 向上推：前进（对应 W 键）
  - 向下拉：后退（对应 S 键）
  - 向左推：左移（对应 A 键）
  - 向右推：右移（对应 D 键）
- **验证**: 摇杆应有约 15% 的死区，轻微触碰不应移动

### 3. 视角测试（Gameplay）
- **右摇杆**: 控制视角
  - 左右推：水平旋转视角
  - 上下推：垂直旋转视角（默认反向）
- **验证**: 
  - 摇杆回中后视角停止移动
  - Y 轴反向（向上推视角向上看）

### 4. 动作按键测试（Gameplay）

| 按键 | 功能 | 键盘对应 | 测试方法 |
|------|------|----------|----------|
| **A** | 跳跃 | Space | 按下应跳起 |
| **B** | (未绑定) | - | - |
| **X** | (未绑定) | - | - |
| **Y** | 打开背包 | E | 应打开/关闭背包界面 |
| **LB** | 冲刺 | Left Ctrl | 按住移动速度加快 |
| **RB** | 攻击 | 左键 | 持续攻击 |
| **Start** | 菜单 | Esc | 打开暂停菜单 |
| **Back** | 切换视角 | F5 | 第一/第三人称切换 |
| **R3** (右摇杆按下) | 蹲下 | Left Shift | 按住降低高度 |

### 5. 快捷栏测试（Gameplay）
- **D-Pad 左**: 选择武器槽 1
- **D-Pad 上**: 选择武器槽 2
- **D-Pad 右**: 选择武器槽 3
- **验证**: HUD 中高亮应切换

### 6. UI 导航测试
1. 按 **Start** 打开菜单
2. 使用 **D-Pad** 上下左右导航
3. 按 **A** 确认选择
4. 按 **B** 返回/取消
5. 按 **Start** 或 **B** 关闭菜单

### 7. 混合输入测试
- 同时使用键盘和手柄
- 左手键盘 WASD，右手手柄右摇杆
- 或反过来：左手手柄左摇杆，右手鼠标
- **验证**: 两者应同时工作

## 常见问题排查

### 问题：手柄无响应
**检查步骤**：
1. 确认手柄已连接（Windows 设备管理器中可见）
2. 测试手柄在其他游戏/应用中是否工作
3. 重启游戏
4. 尝试不同 USB 口（避免 USB hub）

### 问题：摇杆漂移
**解决方法**：
1. 检查手柄物理状态（清洁摇杆）
2. 如果持续漂移，需要在代码中增大死区：
   - 编辑 `src/engine/input/InputManager.h`
   - 修改 `kStickDeadZone` 从 0.15 增加到 0.2 或 0.25

### 问题：按键映射错误
**可能原因**：
- 手柄不是标准 XInput 设备
- GLFW 无法正确识别手柄型号

**解决方法**：
1. 确认使用的是 Xbox 品牌手柄或兼容手柄
2. 更新手柄固件
3. 检查 GLFW 版本（需要 3.3+）

### 问题：视角反向
**解决方法**：
- 编辑 `assets/config/keybindings.txt`
- 找到这一行：
  ```
  Axis Gameplay LookY Gamepad RStickY Invert
  ```
- 删除 `Invert` 改为：
  ```
  Axis Gameplay LookY Gamepad RStickY
  ```

## Debug 日志

如果需要调试手柄输入，可以在代码中添加：

```cpp
// 在 InputManager::update() 中
if (m_gamepadConnected) {
    std::cout << "Gamepad: LStickX=" << m_gamepadAxes[GLFW_GAMEPAD_AXIS_LEFT_X] 
              << " LStickY=" << m_gamepadAxes[GLFW_GAMEPAD_AXIS_LEFT_Y] << std::endl;
}
```

## 高级测试

### 测试配置热重载
1. 游戏运行中修改 `keybindings.txt`
2. （如果支持）游戏应自动重新加载配置
3. 否则需要重启游戏

### 测试多设备冲突
1. 同时按键盘和手柄的相同功能键
2. 两者都应触发（OR 逻辑）
3. 不应有延迟或卡顿

### 测试上下文切换
1. Gameplay 模式：测试移动和攻击
2. 按 **Start** 进入 UI 模式
3. 验证移动摇杆不再控制角色
4. D-Pad 应控制菜单导航
5. 退出菜单后恢复 Gameplay 控制

## 性能检查

- 手柄输入不应影响帧率
- 使用任务管理器检查 CPU 使用无明显增加
- 输入延迟应小于 1 帧（约 16ms @ 60fps）

## 成功标准

✅ 所有按键都有响应  
✅ 摇杆移动流畅无死角  
✅ 死区合适无漂移  
✅ UI 导航正常  
✅ 键鼠和手柄可以混用  
✅ 热插拔不崩溃  

如果以上全部通过，手柄支持已成功集成！
