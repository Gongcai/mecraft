# 体积光与体积雾系统 (Volumetric Light and Fog System)

## 概述

DerivativeMain 的体积光/体积雾系统是一套基于屏幕空间光线步进的多层次渲染方案，涵盖地面体积雾、体积光（丁达尔效应）、水下光束、末地雾等多个子系统。系统在半分辨率下渲染，通过深度感知的空间上采样恢复全分辨率，并与 TAA 时间超采样协同工作。

---

## 1. 渲染管线位置

体积雾/光在管线中的执行位置：

```
composite.fsh (world0/world1)
  ├── 半分辨率渲染（左下 1/4 屏幕）
  ├── CalculateVolumetricFog() —— 地面体积雾 + 体积光
  ├── UnderwaterVolumetricLight() —— 水下体积光
  └── 输出到 colortex1 (RGBA16F)

composite1.fsh
  ├── 空间上采样（深度感知双边滤波）
  └── 与场景合成（透射率混合）
```

## 2. 雾密度计算

### 2.1 四种密度模式 (`FOG_TYPE`)

| 类型 | 特征 | 八度数 | 性能 |
|------|------|--------|------|
| 0 (Low) | 简单指数高度衰减 | 0 | 最高 |
| 1 (Medium) | 高度 + 2层 3D 噪声 + 风动画 | 2 | 高 |
| 2 (High) | 4层 FBM，频率倍增 3.2 | 4 | 中 |
| 3 (Ultra) | 5层 FBM，频率倍增 4.0 | 5 | 低 |

**Low 模式**：
```glsl
float fogDensity = exp2(min((SEA_LEVEL + 28.0 - rayPosition.y) * 0.15, 0.2));
```
纯指数高度衰减，海平面以上 28m 为基准，每升高一格密度减半。

**Medium 模式**：
```glsl
float fogDensity = exp2(min((SEA_LEVEL + 28.0 - rayPosition.y) * 0.15, 0.2));
rayPosition *= 0.07;
rayPosition += volFogWind;
float noise = Get3DNoiseSmooth(rayPosition) * 4.0;
noise -= Get3DNoiseSmooth(rayPosition * 4.0 + volFogWind);
fogDensity = saturate(noise * 4.0 * fogDensity - 5.0) * 1.4;
if (BiomeSandstorm < 5e-3) fogDensity = fogDensity * (1.0 - timeNoon) + timeNoon;
```
两层噪声叠加：基础层（缩放 0.07）和细节层（缩放 0.28），中午时密度最低（晴天无雾）。

**High 模式**：
```glsl
for (uint i = 0u; i < 4u; ++i) {
    noise += Get3DNoiseSmooth(position) * weight;
    position = position * 3.2 + volFogWind * (1.0 + float(i));
    weight *= 0.4;
}
```
4 层 FBM，频率倍增 3.2（非标准的 2.0，产生更自然的频谱分布），权重衰减 0.4。

**Ultra 模式**：
```glsl
for (uint i = 0u; i < 5u; ++i) {
    noise += Get3DNoiseSmooth(position) * weight;
    position = position * 4.0 + volFogWind * (1.0 + float(i));
    weight *= 0.35;
}
```
5 层 FBM，频率倍增 4.0，权重衰减 0.35，最高质量。

### 2.2 风动画

```glsl
vec3 volFogWind = vec3(worldTimeCounter * 0.004, 0.0, worldTimeCounter * 0.002);
```

X 方向风速是 Z 方向的 2 倍，产生非均匀运动。每一层噪声叠加不同的风偏移，高层噪声移动更快，产生湍流感。

### 2.3 生物群系特殊效果

```glsl
// 沙尘暴
if (BiomeSandstorm > 5e-3) {
    fogDensity *= 1.0 + BiomeSandstorm * 5.0;
    fogColor = mix(fogColor, vec3(0.8, 0.6, 0.3), BiomeSandstorm);
}

// 绿色生物群系偏移
fogColor = mix(fogColor, fogColor * vec3(0.8, 1.0, 0.7), BiomeGreen * 0.3);
```

## 3. 散射模型

### 3.1 相函数组合

系统使用三种相函数的加权组合：

```glsl
// Rayleigh（空气分子）
float rayleighPhase = RayleighPhase(LdotV);

// Henyey-Greenstein（气溶胶，前向 + 后向）
float hgForward = HenyeyGreensteinPhase(LdotV, 0.6);
float hgBackward = HenyeyGreensteinPhase(LdotV, -0.3);

// Cornette-Shanks（更精确的前向峰值）
float csPhase = CornetteShanksPhase(LdotV, 0.8);

// 最终相函数
float phase = rayleighPhase * 0.05 + (hgForward * 0.7 + hgBackward * 0.3 + csPhase * 0.2);
```

### 3.2 多重散射近似

High/Ultra 模式下的 4 级多重散射：

```glsl
float sunlightEnergy = fastExp(-sunlightOD * 2.0) * phases.x;   // 主前向散射
sunlightEnergy    += fastExp(-sunlightOD * 0.8) * phases.y;      // 次前向
sunlightEnergy    += fastExp(-sunlightOD * 0.3) * phases.z;      // 更宽散射
sunlightEnergy    += fastExp(-sunlightOD * 0.1) * phases.w;      // 全局照明近似
```

光学深度系数递减（2.0, 0.8, 0.3, 0.1），模拟光线在雾中多次散射后能量衰减的累积效果。

### 3.3 Powder Effect

```glsl
// Per-step Powder
float powder = oneMinus(fastExp(-density * 36.0)) * 0.82;
powder /= 1.0 - powder;

// Per-sample Optical Depth Powder
float samplePowder = oneMinus(fastExp(-sunlightOD * 2.0));
```

Powder 效应在两个层级实现：
1. **Per-step**：每步的密度 Powder，增强雾体边缘亮度
2. **Per-sample**：沿太阳方向的光学深度 Powder，模拟光在雾中的前向增强

### 3.4 太阳光学深度采样

```glsl
float stepSize = 5.0;
for (uint j = 0u; j < 4u; ++j, checkPos += worldLightVector * stepSize) {
    sunlightOD += CalculateFogDensity(checkPos) * stepSize;
    stepSize *= 1.5;  // 指数增长：5.0, 7.5, 11.25, 16.875
}
```

指数增长步长在仅 4 步内覆盖约 40 格的距离范围，近处精度高、远处精度低。

## 4. 体积光（丁达尔效应）

### 4.1 空气密度

```glsl
float airDensity = VOLUMETRIC_LIGHT_STRENGTH + wetness * BiomeSandstorm;
airDensity *= RayleighPhase(LdotV) * (3.0 / far);
```

- 基础强度由 `VOLUMETRIC_LIGHT_STRENGTH` 控制
- 雨天/沙尘暴时密度增加
- Rayleigh 相函数使前向/后向散射更强
- 除以 `far` 进行距离归一化

### 4.2 阴影采样

```glsl
vec3 shadowProjPos = WorldPosToShadowProjPos(rayPosition);
float shadow = step(shadowProjPos.z, texelFetch(shadowtex1, shadowTexel, 0).x);
```

每步采样阴影贴图，确定当前点是否被阳光直接照射。支持彩色阴影：

```glsl
#ifdef COLORED_SHADOWS
    float shadow0 = step(shadowProjPos.z, texelFetch(shadowtex0, shadowTexel, 0).x);
    if (shadow != shadow0) {
        shadowColor = texelFetch(shadowcolor0, shadowTexel, 0).rgb;
    }
#endif
```

### 4.3 云阴影集成

```glsl
#ifdef VOLUMETRIC_FOG_CLOUD_SHADOWS
    float cloudShadow = CloudShadow(rayPosition, cloudProperties);
    shadow *= cloudShadow;
#endif
```

体积雾中的每一步都受云阴影影响，使雾中的光束随云的移动而变化。

## 5. 水下体积光

### 5.1 水体吸收

```glsl
const vec3 coeff = waterAbsorption + 0.02;
vec3 stepTransmittance = fastExp(-coeff * stepLength);
```

水体吸收系数 `waterAbsorption` 是 RGB 三通道的独立值，红光吸收最强、蓝光最弱，产生水下的蓝绿色调。

### 5.2 折射光方向

```glsl
vec3 lightVector = refract(worldLightVector, vec3(0, -1, 0), 1.0 / WATER_REFRACT_IOR);
```

阳光进入水面后折射，使用 Snell 定律计算折射方向。IOR 默认 1.33。

### 5.3 双 Henyey-Greenstein 相位函数

```glsl
float phase = HenyeyGreensteinPhase(LdotV, 0.8) + HenyeyGreensteinPhase(LdotV, 0.6);
```

两个前向散射瓣（g=0.8 和 g=0.6）叠加，模拟水中光束的各向异性散射特性。

### 5.4 水深衰减

```glsl
float waterDepth = abs(shadowcolor1.w * 512.0 - 128.0 - shadowPosition.y - eyeAltitude);
sampleShadow *= fastExp(-coeff * 0.4 * max(waterDepth, 8.0));
```

水深从阴影贴图的 `shadowcolor1.w` 中解码，用于衰减水面以下的光束强度。

## 6. 末地体积雾 (`VolumetricFogEnd.glsl`)

### 6.1 密度计算

```glsl
float fogDensity = exp2(-abs(rayPosition.y) * 0.01);  // 以 Y=0 为中心
rayPosition *= 0.02;
float noise = Get3DNoiseSmooth(rayPosition) * 4.0;
noise += Get3DNoiseSmooth(rayPosition * 2.0) * 2.0;
noise += Get3DNoiseSmooth(rayPosition * 4.0);
noise += Get3DNoiseSmooth(rayPosition * 8.0) * 0.5;
fogDensity = saturate(noise * fogDensity - 3.0) * 2.0;
```

末地雾以 Y=0 为中心，4 层 FBM 噪声叠加。

### 6.2 Dark End 模式

```glsl
#ifdef DARK_END
    if (isDarkEnd) {
        fogDensity *= 3.0;  // 密度增加 3 倍
        fogColor = vec3(0.1, 0.0, 0.2);  // 深紫色
    }
#endif
```

Boss 战期间（Dark End 模式），雾密度大幅增加，颜色变为深紫色，营造压抑氛围。

### 6.3 DH 支持

```glsl
#ifdef DISTANT_HORIZONS
    steps = max(steps, 90u);  // DH 模式下增加到 90 步
#endif
```

Distant Horizons 模组启用时，步数增加到 90 以覆盖更远的渲染距离。

## 7. 空间上采样

### 7.1 深度感知双边滤波

```glsl
vec4 SpatialUpscale(sampler2D tex, vec2 coord, float linearDepth) {
    vec4 result = vec4(0.0);
    float totalWeight = 0.0;

    for (int i = -1; i <= 1; i++) {
        for (int j = -1; j <= 1; j++) {
            vec2 offset = vec2(i, j) * screenPixelSize * 2.0;
            float sampleDepth = GetDepthLinear(texel + ivec2(i, j) * 2);
            float sigmaZ = 64.0 / linearDepth;
            float weight = exp2(-abs(sampleDepth - linearDepth) * sigmaZ);
            result += texture(tex, coord + offset) * weight;
            totalWeight += weight;
        }
    }
    return result / totalWeight;
}
```

- 4 邻域采样（3x3 十字形）
- 深度差异权重：`exp2(-|Δz| * 64/z)`，深度越接近权重越大
- 交替采样偏移：`frameCounter % 2` 在两帧间交替使用不同的采样位置，进一步减少带宽

### 7.2 DH 深度支持

```glsl
#ifdef DISTANT_HORIZONS
    float dhDepth = GetDepthLinearDH(texel);
    if (depth >= 1.0 && dhDepth < 1.0) {
        linearDepth = dhDepth;
    }
#endif
```

当原版深度缓冲为天空（>= 1.0）但 DH 深度有效时，使用 DH 深度进行上采样。

## 8. 与场景合成

### 8.1 透射率混合

```glsl
vec4 VFData = texture(colortex1, screenCoord);
sceneData *= VFData.a;           // 乘以雾透射率（衰减）
sceneData += VFData.rgb;         // 加上雾散射颜色
```

标准的 Beer-Lambert 透射率混合：先衰减原始场景，再叠加雾的散射贡献。

### 8.2 Bloom 雾透射率

```glsl
#ifdef BLOOMY_FOG
    fogTransmittance = VFData.a;  // 存储到 colortex6
#endif
```

雾透射率被传递到后处理管线，用于 Bloom 阶段的光晕效果——雾越浓，Bloom 扩散越强。

### 8.3 边界雾集成

```glsl
#ifdef BORDER_FOG
    float borderFog = 1.0 - exp2(-sqr(pow4(length(worldPos.xz) / far)) * BORDER_FOG_FALLOFF);
    borderFog *= oneMinus(saturate(worldDir.y * 3.0));
    sceneData = mix(sceneData, skyRadiance, borderFog);
#endif
```

边界雾在渲染距离边缘将场景渐变为天空颜色，向上的视线方向雾效减弱。

## 9. 性能优化总结

| 优化策略 | 描述 |
|---------|------|
| 半分辨率渲染 | 体积雾在 1/2 分辨率下渲染，节省 75% 像素计算 |
| 深度感知上采样 | 双边滤波恢复全分辨率，保持深度边缘清晰 |
| R1 准随机抖动 | 使用黄金比例的准随机序列减少带状伪影 |
| TAA 时间累积 | 多帧累积进一步平滑噪声 |
| 早期退出 | 空区域和高透射率区域提前终止 |
| 自适应步数 | 根据深度和视角动态调整步数 |
| 预计算阴影空间增量 | 避免每步重新计算阴影投影 |
| 云阴影集成 | 利用已有的云阴影数据，无需额外采样 |
| 交替采样偏移 | 两帧间交替采样位置，等效双倍采样 |

## 10. 独特技术亮点

1. **四级多重散射近似**：通过不同光学深度系数的指数衰减叠加，廉价地模拟了光线在雾中的多次散射。

2. **双层级 Powder Effect**：per-step 和 per-sample 两个层级的 Powder 效应，分别增强雾体边缘和光束前向散射。

3. **指数增长光照步长**：太阳光采样使用 `stepSize *= 1.5` 的指数增长，在有限步数内覆盖较大距离范围。

4. **Bloom 雾**：将雾透射率传递到后处理管线，使 Bloom 效果受雾密度调制，模拟光在雾中的扩散。

5. **生物群系感知**：沙尘暴、绿色生物群系等环境因素影响雾的颜色和密度。

6. **末地 Dark End 模式**：Boss 战期间雾密度和颜色动态变化，增强游戏氛围。

7. **水下光束的物理折射**：使用 Snell 定律计算阳光进入水面后的折射方向，配合水体吸收系数实现逼真的水下光束效果。
